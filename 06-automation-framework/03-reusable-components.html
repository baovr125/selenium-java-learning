2. BasePage

java
package pages;

import org.openqa.selenium.*;
import org.openqa.selenium.support.ui.*;

import java.time.Duration;
import java.util.List;

public abstract class BasePage {
    protected final WebDriver driver;
    protected final WebDriverWait wait;

    protected BasePage(WebDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(15));
    }

    // --- chờ ---
    protected WebElement waitVisible(By by) {
        return wait.until(ExpectedConditions.visibilityOfElementLocated(by));
    }
    protected WebElement waitClickable(By by) {
        return wait.until(ExpectedConditions.elementToBeClickable(by));
    }
    protected void waitInvisible(By by) {
        wait.until(ExpectedConditions.invisibilityOfElementLocated(by));
    }
    protected void waitCount(By by, int expected) {
        wait.until(ExpectedConditions.numberOfElementsToBe(by, expected));
    }
    protected void waitText(By by, String expected) {
        wait.until(ExpectedConditions.textToBe(by, expected));
    }

    // --- hành động ---
    protected void click(By by)               { waitClickable(by).click(); }
    protected void type(By by, String text)   { WebElement el = waitVisible(by); el.clear(); el.sendKeys(text); }
    protected String text(By by)              { return waitVisible(by).getText().trim(); }
    protected String value(By by)             { return waitVisible(by).getAttribute("value"); }
    protected boolean isPresent(By by)        { return !driver.findElements(by).isEmpty(); }
    protected List<WebElement> all(By by)     { return driver.findElements(by); }

    protected void hover(By by) {
        new org.openqa.selenium.interactions.Actions(driver).moveToElement(waitVisible(by)).perform();
    }
}

Điểm mấu chốt:

  • Wait nằm trong BasePage ⇒ Page và Test không phải lo đồng bộ hoá.
  • protected — chỉ Page con dùng; test không gọi thẳng.
  • Lấy By (không lưu WebElement) ⇒ ít stale.
  • Dùng đúng 🧩 các ExpectedConditions của dự án (visibilityOfElementLocated, elementToBeClickable, invisibilityOfElementLocated, numberOfElementsToBe, textToBe).

3. DriverFactory

java
package core;

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.chrome.ChromeOptions;
import org.openqa.selenium.edge.EdgeDriver;
import org.openqa.selenium.firefox.FirefoxDriver;

public final class DriverFactory {
    private DriverFactory() {}

    public static WebDriver create(String browser, boolean headless) {
        return switch (browser.toLowerCase()) {
            case "chrome" -> {
                ChromeOptions o = new ChromeOptions();
                if (headless) { o.addArguments("--headless=new", "--window-size=1920,1080"); }
                yield new ChromeDriver(o);
            }
            case "firefox" -> new FirefoxDriver();
            case "edge"    -> new EdgeDriver();
            default -> throw new IllegalArgumentException("Browser không hỗ trợ: " + browser);
        };
    }
}

Mẫu thiết kế: Factory. Lợi ích: thêm browser ở một nơi; BaseTest chỉ gọi DriverFactory.create(...). switch expression + yield là Java 14+ (🧩 dự án release 21 hỗ trợ). Selenium Manager tự tải driver tương ứng cho Firefox/Edge.

4. ThreadLocal driver (để chạy song song)

java
public abstract class BaseTest {
    private static final ThreadLocal<WebDriver> DRIVER = new ThreadLocal<>();

    protected WebDriver driver() { return DRIVER.get(); }

    @BeforeMethod public void setup() {
        DRIVER.set(DriverFactory.create(Config.browser(), Config.headless()));
        driver().manage().window().maximize();
    }
    @AfterMethod public void tearDown() {
        if (driver() != null) { driver().quit(); DRIVER.remove(); }
    }
}

Mỗi luồng có WebDriver riêng. Nhớ DRIVER.remove().

5. Utility: bảng

Rút từ 🧩 Exercise03:

java
public final class TableUtils {
    private TableUtils() {}

    /** Đọc text mọi ô trong một hàng, bỏ n cột cuối (ví dụ cột Action). */
    public static List<String> rowTexts(WebElement row, int skipLastColumns) {
        List<WebElement> cells = row.findElements(By.tagName("td"));
        List<String> data = new ArrayList<>();
        for (int i = 0; i < cells.size() - skipLastColumns; i++) {
            data.add(cells.get(i).getText().trim());
        }
        return data;
    }
}

6. Utility: cuộn bằng JavaScript

Rút từ 🧩 Exercise07:

java
public final class ScrollUtils {
    private ScrollUtils() {}

    public static void toBottom(WebDriver driver) {
        ((JavascriptExecutor) driver).executeScript(
            "window.scrollTo(0, document.body.scrollHeight);"
          + "window.dispatchEvent(new Event('scroll'));");
    }
    public static long scrollY(WebDriver driver) {
        return ((Number) ((JavascriptExecutor) driver).executeScript("return window.scrollY;")).longValue();
    }
}

7. Utility: chụp ảnh

java
public final class Screenshots {
    private Screenshots() {}

    public static Path take(WebDriver driver, String name) {
        try {
            File src = ((TakesScreenshot) driver).getScreenshotAs(OutputType.FILE);
            Path dir = Path.of("target", "screenshots");
            Files.createDirectories(dir);
            return Files.copy(src.toPath(), dir.resolve(name + ".png"), StandardCopyOption.REPLACE_EXISTING);
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }
}

9. Listener (kết nối chụp ảnh với TestNG)

java
public class TestListener implements ITestListener {
    @Override public void onTestFailure(ITestResult result) {
        Object instance = result.getInstance();
        if (instance instanceof BaseTest bt && bt.driver() != null) {
            Screenshots.take(bt.driver(), result.getName());
        }
    }
}

Đăng ký trong testng.xml:

xml
<listeners><listener class-name="listeners.TestListener"/></listeners>

⚠️ Thứ tự: onTestFailure chạy trước @AfterMethod ⇒ driver còn sống để chụp ảnh.

10. Tiêu chí: khi nào kéo code ra dùng chung?

text
Lặp lần 1 → để yên.   Lặp lần 2 → cân nhắc.   Lặp lần 3 → refactor thành component.

Đừng trừu tượng hoá sớm: một helper dùng đúng 1 nơi nên ở lại private (như 🧩 assertSameElement).

✅ Best Practices

  1. Wait đặt trong BasePage/helper, test không gọi Thread.sleep.
  2. Helper nhỏ, một việc, tên là động từ.
  3. Không để static giữ trạng thái driver.
  4. Không log bí mật.
  5. Có test (hoặc ít nhất ví dụ dùng) cho helper phức tạp.

⚠️ Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
Helper quá "thông minh" nuốt lỗi try/catch rỗng Để exception lan, hoặc ném lại rõ ràng
Utility giữ static WebDriver Không song song được Truyền driver làm tham số
BasePage phình to Nhét mọi thứ Tách Waits, JsUtils, component
Screenshot trong @AfterMethod sau quit() Driver đã đóng Chụp trước quit()

💼 Interview Corner

1. What reusable components would you add first?

  • 🇻🇳 Dịch: Thành phần dùng lại nào thêm trước?
  • Suggested answer (EN): A BasePage with wait, click and type helpers, a DriverFactory, a Config class and a screenshot helper hooked into a listener.
  • Giải thích (VI): Theo giá trị/công sức.
  • Follow-up: How do you avoid over-engineering?

2. Why should a driver factory exist?

  • 🇻🇳 Dịch: Vì sao cần DriverFactory?
  • Suggested answer (EN): It centralizes browser creation and options, supports several browsers and headless mode from configuration, and keeps BaseTest clean.
  • Giải thích (VI): Pattern Factory.
  • Follow-up: How does it relate to polymorphism?
