1. Khái niệm

.gitignore liệt kê mẫu đường dẫn mà Git bỏ qua (file sinh ra, cache, file cá nhân). Nó chỉ tác dụng với file chưa được theo dõi (untracked).

2. Syntax

Nội dung .gitignore thật của dự án Selenium1:

gitignore
target/
test-output/
.mvn/repository/
.idea/
*.iml
.classpath
.project
.settings/
.vscode/excel-pq-symbols/
bash
git check-ignore -v target .mvn/repository    # in ra quy tắc nào khớp
git ls-files .mvn                             # file thực sự được theo dõi trong .mvn
git rm -r --cached target                     # ngừng theo dõi thư mục đã lỡ commit (giữ file trên đĩa)
git ls-files --stage mvnw                     # xem mode: 100755 (thực thi) hay 100644
git update-index --chmod=+x mvnw              # đặt bit thực thi trong Git
git ls-files --eol mvnw mvnw.cmd              # xem line ending trong index/working tree

3. Ví dụ (đã chạy thật trên repo thử)

Ví dụ 1 — .gitignore chặn đúng file sinh ra

bash
git check-ignore -v target .mvn/repository
text
.gitignore:2:target/	target
.gitignore:6:.mvn/repository/	.mvn/repository

Sau git add pom.xml mvnw mvnw.cmd .mvn/wrapper/ .mvn/maven.config .gitignore, lệnh git ls-files .mvn chỉ có:

text
.mvn/maven.config
.mvn/wrapper/maven-wrapper.properties

→ .mvn/repository/ (123 jar) không bị đưa lên.

Ví dụ 2 — Phát hiện thật: mvnw bị commit không có bit thực thi trên Windows

bash
git ls-files --stage mvnw
text
100644 bd8896bf2217b46faa0291585e01ac1a3441a958 0	mvnw

100644 = không thực thi. Người dùng Linux/macOS/CI sẽ gặp Permission denied: ./mvnw. Cách sửa (đã kiểm chứng):

bash
git update-index --chmod=+x mvnw
git ls-files --stage mvnw
text
100755 bd8896bf2217b46faa0291585e01ac1a3441a958 0	mvnw

Ví dụ 3 — Cảnh báo LF will be replaced by CRLF và .gitattributes

Với core.autocrlf=true (mặc định phổ biến trên Windows), Git in:

text
warning: in the working copy of 'mvnw', LF will be replaced by CRLF the next time Git touches it

Nếu mvnw thành CRLF thì Linux báo /bin/sh^M: bad interpreter. Giải pháp: ép line ending bằng .gitattributes (commit file này):

gitattributes
/mvnw      text eol=lf
/mvnw.cmd  text eol=crlf
bash
git add .gitattributes
git add --renormalize mvnw mvnw.cmd
git ls-files --eol mvnw mvnw.cmd
text
i/lf    w/lf    attr/text eol=lf      	mvnw
i/lf    w/crlf  attr/text eol=crlf    	mvnw.cmd

(i/ = index, w/ = working tree, attr/ = thuộc tính áp dụng.) mvnw luôn LF, mvnw.cmd luôn CRLF.

4. Ứng dụng với dự án Selenium Maven (Real-world)

File / thư mục Commit? Lý do
pom.xml, testng.xml, src/ ✅ Mã nguồn và cấu hình
mvnw, mvnw.cmd, .mvn/wrapper/, .mvn/maven.config ✅ Khoá phiên bản Maven; cấu hình chung
.gitignore, .gitattributes ✅ Quy tắc chung
target/, test-output/ ❌ Sinh ra khi build/test
.mvn/repository/ ❌ Local Repository riêng của dự án (123 jar)
.idea/, *.iml, .classpath, .project, .settings/ ❌ File IDE cá nhân
config.properties chứa mật khẩu thật ❌ Dùng biến môi trường/secret của CI
Ảnh chụp màn hình lỗi (target/screenshots/) ❌ Nằm trong target/

Checklist trước khi push: git status (không có target/), git diff --staged (đúng nội dung), .\mvnw.cmd clean test (xanh).

💼 Interview Corner

1. What should and should not be committed in a Selenium Maven project?

  • 🇻🇳 Dịch: Nên/không nên commit gì?
  • Suggested answer (EN): Commit source, pom.xml, testng.xml, mvnw, mvnw.cmd, .mvn/wrapper, shared config and .gitignore; do not commit target, test-output, the local repository, IDE files or secrets.
  • Giải thích (VI): Đã có trong .gitignore của dự án.
  • Follow-up: What if someone committed target?

2. Why make mvnw executable in Git?

  • 🇻🇳 Dịch: Vì sao mvnw cần quyền thực thi?
  • Suggested answer (EN): Linux and macOS need the executable bit (mode 100755) to run ./mvnw; committing from Windows gives 100644, so I set it with git update-index --chmod=+x, and keep LF endings with .gitattributes.
  • Giải thích (VI): Đã tái hiện.
  • Follow-up: What error do CRLF line endings cause?

📌 Lesson Summary

Kiến thức cần nhớ

  • .gitignore chỉ tác dụng với file chưa theo dõi
  • Commit cấu hình + mã nguồn; không commit file sinh ra/bí mật
  • mvnw cần 100755 và LF

Method / lệnh cần biết

  • check-ignore -v, ls-files --stage, update-index --chmod=+x, ls-files --eol, rm --cached

Điểm dễ nhầm lẫn

  • .mvn toàn bộ ≠ .mvn/wrapper/ + maven.config
  • mvnw (LF) ≠ mvnw.cmd (CRLF)
  • Ignore không gỡ file đã theo dõi
