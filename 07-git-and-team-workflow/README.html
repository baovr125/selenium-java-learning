  • Working in Team (quy trình 9 bước) — từ clone đến đồng đội pull.

Hai phát hiện thật khi thử trên Windows

  1. mvnw được commit với mode 100644 (không thực thi) ⇒ Linux/CI báo Permission denied ⇒ sửa bằng git update-index --chmod=+x mvnw.
  2. Cảnh báo LF will be replaced by CRLF ⇒ dùng .gitattributes (/mvnw text eol=lf, /mvnw.cmd text eol=crlf).
