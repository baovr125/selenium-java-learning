1. Khái niệm

Automation cần đọc cấu hình (browser, URL, timeout), dữ liệu test (CSV/JSON) và ghi kết quả/ảnh/log. Java hiện đại dùng java.nio.file (Path, Files) — ngắn gọn và an toàn hơn File cũ.

Nhu cầu Công cụ
Đọc toàn bộ file văn bản Files.readString(path), Files.readAllLines(path)
Ghi file Files.writeString(path, text), Files.write(path, lines)
Kiểm tra/ tạo thư mục Files.exists, Files.createDirectories
Cấu hình dạng key=value java.util.Properties
File trong src/test/resources getResourceAsStream (đọc từ classpath)

2. Syntax

java
Path p = Path.of("target", "data.txt");                  // đường dẫn (không phụ thuộc OS)
Files.createDirectories(p.getParent());                  // tạo thư mục cha
Files.writeString(p, "hello");                           // ghi
String s = Files.readString(p);                          // đọc
List<String> lines = Files.readAllLines(p);              // đọc từng dòng
boolean ok = Files.exists(p);                            // tồn tại?
Files.deleteIfExists(p);                                 // xoá nếu có

Properties props = new Properties();
props.load(inputStream);                                 // nạp key=value
props.getProperty("browser", "chrome");                  // lấy giá trị, có mặc định

Hầu hết method của Files ném IOException (checked) → cần try/catch hoặc throws (Exception Handling).

3. Ví dụ code

Ví dụ 1 — Ghi rồi đọc file

java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public class Main {
    public static void main(String[] args) throws IOException {
        Path dir = Files.createTempDirectory("lab");              // thư mục tạm
        Path file = dir.resolve("result.txt");

        Files.write(file, List.of("testLogin=PASS", "testDropdown=FAIL"));
        System.out.println(Files.exists(file));

        List<String> lines = Files.readAllLines(file);
        System.out.println(lines.size() + " dòng");
        for (String line : lines) {
            String[] kv = line.split("=");
            System.out.println(kv[0] + " -> " + kv[1]);
        }

        Files.deleteIfExists(file);
        System.out.println(Files.exists(file));
        Files.deleteIfExists(dir);
    }
}
output
true
2 dòng
testLogin -> PASS
testDropdown -> FAIL
false

Ví dụ 2 — Properties (cấu hình)

java
import java.io.IOException;
import java.io.StringReader;
import java.util.Properties;

public class Main {
    public static void main(String[] args) throws IOException {
        String content = """
                base.url=https://the-internet.herokuapp.com
                browser=chrome
                timeout.seconds=15
                headless=false
                """;
        Properties props = new Properties();
        props.load(new StringReader(content));           // trong dự án: nạp từ file config.properties

        String browser = props.getProperty("browser", "chrome");
        int timeout = Integer.parseInt(props.getProperty("timeout.seconds", "15"));
        boolean headless = Boolean.parseBoolean(props.getProperty("headless", "false"));
        String missing = props.getProperty("proxy", "(không có)");

        System.out.println(browser + " " + timeout + " " + headless);
        System.out.println(props.getProperty("base.url"));
        System.out.println(missing);
    }
}
output
chrome 15 false
https://the-internet.herokuapp.com
(không có)

Properties luôn trả String: tự chuyển kiểu bằng Integer.parseInt, Boolean.parseBoolean.

Ví dụ 3 — Config với thứ tự ưu tiên -D > file > mặc định

java
import java.util.Properties;

public class Main {
    static final Properties FILE = new Properties();
    static {
        FILE.setProperty("browser", "chrome");        // giả lập nội dung config.properties
        FILE.setProperty("timeout.seconds", "15");
    }

    static String get(String key, String defaultValue) {
        return System.getProperty(key, FILE.getProperty(key, defaultValue));
    }

    public static void main(String[] args) {
        System.out.println(get("browser", "chrome"));          // lấy từ "file"
        System.setProperty("browser", "firefox");              // giả lập: mvnw test -Dbrowser=firefox
        System.out.println(get("browser", "chrome"));          // -D thắng
        System.out.println(get("headless", "false"));          // chỉ có mặc định
    }
}
output
chrome
firefox
false

Ví dụ 4 — Đọc CSV đơn giản thành dữ liệu test

java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) throws IOException {
        Path csv = Files.createTempFile("login", ".csv");
        Files.writeString(csv, """
                username,password,expected
                tomsmith,SuperSecretPassword!,You logged into a secure area!
                tomsmith,wrong,Your password is invalid!
                """);

        List<String[]> rows = new ArrayList<>();
        List<String> lines = Files.readAllLines(csv);
        for (int i = 1; i < lines.size(); i++) {               // bỏ dòng tiêu đề
            rows.add(lines.get(i).split(",", 3));
        }
        for (String[] r : rows) {
            System.out.println(r[0] + " | " + r[2]);
        }
        Object[][] dataProvider = rows.toArray(new Object[0][]);   // dạng @DataProvider
        System.out.println("bộ dữ liệu: " + dataProvider.length);
        Files.deleteIfExists(csv);
    }
}
output
tomsmith | You logged into a secure area!
tomsmith | Your password is invalid!
bộ dữ liệu: 2

(Dữ liệu có dấu phẩy trong giá trị cần thư viện CSV thật — Apache Commons CSV/OpenCSV; xem Test Data.)

Ví dụ 5 — try-with-resources với BufferedReader

java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.StringReader;

public class Main {
    public static void main(String[] args) throws IOException {
        try (BufferedReader br = new BufferedReader(new StringReader("line1\nline2\nline3"))) {
            String line;
            int n = 0;
            while ((line = br.readLine()) != null) {
                n++;
                System.out.println(n + ": " + line);
            }
        }                                                       // br tự đóng ở đây
    }
}
output
1: line1
2: line2
3: line3

5. Lỗi thường gặp

Lỗi Nguyên nhân Cách sửa
NoSuchFileException/FileNotFoundException Sai đường dẫn / sai thư mục làm việc Dùng đường dẫn tương đối từ gốc dự án hoặc classpath
getResourceAsStream trả null File không nằm trong src/test/resources / chưa test-compile Đặt đúng vị trí; chạy mvnw test-compile
Tiếng Việt lỗi font khi đọc Mã hoá Files.readString(path, StandardCharsets.UTF_8)
IOException chưa xử lý Checked exception throws IOException / try-catch
Quên đóng stream Rò rỉ tài nguyên try-with-resources
Integer.parseInt(null) khi key thiếu getProperty trả null Truyền giá trị mặc định
Commit file chứa mật khẩu thật Cấu hình nhạy cảm Biến môi trường/secret CI; thêm file vào .gitignore
Đường dẫn \ cứng trên Windows Không chạy trên Linux Path.of("a", "b")

💼 Interview Corner

1. How do you read configuration in a test framework?

  • 🇻🇳 Dịch: Đọc cấu hình trong framework thế nào?
  • Suggested answer (EN): I load a config.properties file from the classpath into Properties, allow command line overrides with System.getProperty, and give defaults so the tests run right after cloning.
  • Giải thích (VI): Không hard-code URL, browser, timeout.
  • Follow-up: Where would you keep secrets?

2. Why use try-with-resources when reading files?

  • 🇻🇳 Dịch: Vì sao dùng try-with-resources khi đọc file?
  • Suggested answer (EN): It closes the stream automatically, even when an exception occurs, avoiding resource leaks.
  • Giải thích (VI): Tương tự driver.quit() trong finally/@AfterMethod.
  • Follow-up: What interface must the resource implement?
