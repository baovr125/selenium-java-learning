Cài đặt môi trường

➡️ Java: Getting Started (Introduction, Syntax, Output, Comments)

Mục tiêu: máy của bạn chạy được .\mvnw.cmd test. Không cần cài Maven vì dự án có Maven Wrapper. Liên quan: Trước · Sau: Khởi tạo dự án · Maven Wrapper

🎯 Learning Objectives

Sau bài này bạn có thể:

  • Cài và kiểm tra JDK (≥ 21) cùng Chrome
  • Phân biệt JAVA_HOME, PATH, JDK và JRE
  • Chạy mvnw.cmd -version và test kiểm tra môi trường mà không cần cài Maven

📋 Prerequisites

  • Không cần kiến thức lập trình trước

1. Danh sách cần có

Thành phần Bắt buộc? Phiên bản Ghi chú
JDK (không phải chỉ JRE) ✅ 21 trở lên Dự án --release 21. Máy tác giả: JDK 25.0.1 vẫn biên dịch được
Google Chrome ✅ Bản mới Selenium Manager tự tải ChromeDriver khớp
Internet ✅ lần đầu Tải Maven, thư viện, ChromeDriver, và truy cập website test
Maven ❌ mvnw/mvnw.cmd tự tải Maven 3.9.16
Git Nên có 2.x Làm việc nhóm
IDE Nên có VS Code / IntelliJ IDEA / Eclipse

2. Cài và kiểm tra JDK

  1. Tải JDK 21 (hoặc mới hơn): Eclipse Temurin, Microsoft Build of OpenJDK, Oracle JDK...
  2. Kiểm tra:
powershell
java -version
javac -version
  • javac báo "not recognized" ⇒ bạn mới cài JRE, cần cài JDK.
  • Phiên bản phải ≥ 21, nếu thấy 1.8 hay 11, 17 ⇒ biên dịch sẽ lỗi release version 21 not supported.
  1. (Nên làm) Đặt JAVA_HOME:
powershell
# Thay đường dẫn cho đúng máy bạn
[Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Java\jdk-25", "User")

Đóng và mở lại terminal rồi kiểm tra:

powershell
echo $env:JAVA_HOME

🔎 Thực tế trên máy này: JAVA_HOME trống nhưng mvnw.cmd vẫn chạy bình thường vì java có trong PATH (đã kiểm chứng: .\mvnw.cmd -version in Java version: 25.0.1). Tuy vậy vẫn nên đặt JAVA_HOME: nhiều công cụ (IDE, CI, script) kỳ vọng nó, và nó giúp chọn đúng JDK khi máy có nhiều phiên bản.

3. Cài Chrome

Cài từ trang chính thức. Xem phiên bản tại chrome://version. Không cần tải chromedriver.exe.

4. Kiểm tra Maven Wrapper (không cần cài Maven)

Mở PowerShell tại thư mục dự án (nơi có pom.xml):

powershell
cd B:\Fresher\Selenium1
.\mvnw.cmd -version

Kết quả mong đợi (rút gọn, đã chạy thật):

text
Apache Maven 3.9.16 (...)
Maven home: C:\Users\<tên>\.m2\wrapper\dists\apache-maven-3.9.16\<hash>
Java version: 25.0.1, vendor: Oracle Corporation, runtime: C:\Program Files\Java\jdk-25

Lần chạy đầu tiên trên máy mới, wrapper sẽ in Downloading ... apache-maven-3.9.16-bin.zip rồi giải nén vào C:\Users\<tên>\.m2\wrapper\dists\. Các lần sau dùng lại, không tải nữa.

Nếu muốn dùng Maven cài sẵn để so sánh: tải bản Binary zip từ trang Apache Maven, giải nén, thêm bin vào PATH, kiểm tra mvn -version. Trong dự án này không bắt buộc, và nên dùng mvnw để cả nhóm cùng phiên bản.

5. Chọn IDE

IDE Cách mở dự án
VS Code Cài Extension Pack for Java; mở thư mục; có sẵn .vscode/tasks.json (Ctrl+Shift+B chạy test của file đang mở)
IntelliJ IDEA File → Open chọn pom.xml → Open as Project; Maven tự import
Eclipse Import → Existing Maven Projects

Dù dùng IDE nào, hãy kiểm chứng bằng dòng lệnh .\mvnw.cmd test — kết quả này mới là chuẩn chung của nhóm/CI.

6. Kiểm tra toàn bộ môi trường

powershell
java -version            # >= 21
.\mvnw.cmd -version      # Maven 3.9.16
.\mvnw.cmd test "-Dtest=EnvironmentCheckTest"   # mở Chrome, kiểm tra title "The Internet"

Kết quả mong đợi của lệnh cuối (đã chạy thật):

text
[INFO] Running tests.EnvironmentCheckTest
[INFO] Tests run: 1, Failures: 0, Errors: 0, Skipped: 0, ...
[INFO] BUILD SUCCESS

Cảnh báo SLF4J: Failed to load class "org.slf4j.impl.StaticLoggerBinder" là bình thường (TestNG kéo slf4j-api nhưng chưa có logging binding).

7. Lỗi môi trường thường gặp

Triệu chứng Nguyên nhân Cách xử lý
'javac' is not recognized Chỉ có JRE hoặc JDK chưa trong PATH Cài JDK, thêm %JAVA_HOME%\bin vào PATH
release version 21 not supported JDK < 21 Cài JDK ≥ 21, đặt JAVA_HOME đúng
SessionNotCreatedException Chrome quá cũ / Selenium Manager không tải được driver Cập nhật Chrome; kiểm tra Internet/proxy
.\mvnw.cmd không nhận ra Đang đứng sai thư mục cd vào thư mục chứa mvnw.cmd; trong PowerShell phải có .\
Tiếng Việt hiện ? Console không phải UTF-8 chcp 65001 hoặc chạy qua run-test.ps1
Wrapper không tải được Maven Mạng/proxy/firewall chặn repo.maven.apache.org Xem maven/08

✅ Knowledge Check

Câu 1. JDK khác JRE ở điểm nào?

  • A. JRE có javac, JDK thì không
  • B. Hai thứ giống hệt nhau
  • C. JDK có trình biên dịch javac, JRE chỉ để chạy
  • D. JDK chỉ dùng cho Android
Xem đáp án

Đáp án: C. JDK = JRE + công cụ phát triển (javac...). Để biên dịch test cần JDK.

Câu 2. Dự án chạy được .\mvnw.cmd dù JAVA_HOME trống vì sao?

  • A. Wrapper tự cài JDK
  • B. Maven dùng java có trong PATH
  • C. Chrome cung cấp Java
  • D. Không thể chạy được
Xem đáp án

Đáp án: B. Khi JAVA_HOME trống, Maven tìm java trong PATH (đã kiểm chứng). Nhưng nếu JAVA_HOME được đặt sai thì lỗi.

Câu 3. Có cần tải chromedriver.exe thủ công cho dự án Selenium 4.52.0?

  • A. Có, bắt buộc
  • B. Chỉ cần với Firefox
  • C. Chỉ trên Linux
  • D. Không, Selenium Manager tự tải
Xem đáp án

Đáp án: D. Từ Selenium 4.6, Selenium Manager tự phát hiện Chrome và tải driver khớp (cần Internet).

💼 Interview Corner

1. Do you need to install Maven to run a Maven project?

  • 🇻🇳 Dịch: Có cần cài Maven để chạy dự án Maven không?
  • Suggested answer (EN): Not if the project has the Maven Wrapper. mvnw downloads the pinned Maven version automatically. You still need a JDK and, the first time, internet access.
  • Giải thích (VI): Wrapper thay việc cài Maven nhưng không thay JDK.
  • Follow-up: What does the wrapper store, and where?

2. What is the difference between JDK and JRE?

  • 🇻🇳 Dịch: JDK khác JRE thế nào?
  • Suggested answer (EN): The JDK contains the compiler and development tools such as javac plus the runtime; the JRE only contains what is needed to run Java programs.
  • Giải thích (VI): Làm automation cần JDK vì phải biên dịch code test.
  • Follow-up: Which one does Maven need to compile?

📌 Lesson Summary

Kiến thức cần nhớ

  • Cần JDK ≥ 21 (dự án --release 21); JDK mới hơn vẫn biên dịch được
  • mvnw thay việc cài Maven, không thay JDK
  • Selenium Manager tự tải driver nên cần Internet lần đầu

Method / lệnh cần biết

  • java -version, javac -version, .\mvnw.cmd -version
  • $env:JAVA_HOME, Test-Path

Điểm dễ nhầm lẫn

  • JAVA_HOME trống (OK) ≠ JAVA_HOME sai (lỗi)
  • JRE ≠ JDK
  • Maven ≠ Maven Wrapper
