1. Khái niệm

Toán tử (operator) thực hiện phép tính/so sánh trên giá trị. String là chuỗi ký tự — kiểu dữ liệu bạn dùng nhiều nhất trong automation (text, URL, locator, thông báo).

Nhóm Toán tử Ví dụ
Số học + - * / % 7 % 2 → 1
Gán = += -= *= /= x += 5
Tăng/giảm ++ -- i++
So sánh == != > < >= <= age >= 18 → boolean
Logic && (và), \|\| (hoặc), ! (phủ định) a && !b

Thứ tự ưu tiên: () → ! ++ -- → * / % → + - → so sánh → && → || → gán. Khi không chắc, dùng ngoặc ().

java

3. Ví dụ code

Ví dụ 1 — Toán tử

java
public class Main {
    public static void main(String[] args) {
        int rows = 4;
        rows += 1;                          // 5
        rows++;                             // 6
        System.out.println(rows + " " + (rows % 4) + " " + (rows / 4));
        System.out.println(10 + 5 * 2);
        System.out.println((10 + 5) * 2);

        boolean hasRows = rows > 0;
        boolean allPassed = false;
        System.out.println(hasRows && allPassed);
        System.out.println(hasRows || allPassed);
        System.out.println(!allPassed);
    }
}
output
6 2 1
20
30
false
true
true

Ví dụ 3 — equals vs ==

java
public class Main {
    public static void main(String[] args) {
        String a = new String("Login");
        String b = new String("Login");
        System.out.println(a == b);              // false: so sánh THAM CHIẾU
        System.out.println(a.equals(b));         // true: so sánh NỘI DUNG
        System.out.println("login".equalsIgnoreCase("LOGIN"));
        String maybeNull = null;
        System.out.println("Login".equals(maybeNull));   // false, không lỗi (gọi equals trên hằng)
    }
}
output
false
true
true
false

Quy tắc: luôn so sánh chuỗi bằng equals. Đặt hằng ở bên trái ("Login".equals(x)) để tránh NullPointerException.

Ví dụ 4 — StringBuilder, Math

java
public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 3; i++) {
            sb.append("Row").append(i);
            if (i < 3) sb.append(" | ");
        }
        System.out.println(sb);

        System.out.println(Math.max(3, 9));
        System.out.println(Math.min(3, 9));
        System.out.println(Math.abs(-5));
        System.out.println(Math.pow(2, 10));
        System.out.println(Math.round(2.6));
        System.out.println(Math.floor(2.9) + " " + Math.ceil(2.1));
    }
}
output
Row1 | Row2 | Row3
9
3
5
1024.0
3
2.0 3.0

StringBuilder nối chuỗi trong vòng lặp hiệu quả hơn + (không tạo nhiều String tạm).

Ví dụ 5 — Boolean trong kiểm tra trạng thái

java
public class Main {
    public static void main(String[] args) {
        boolean displayed = true, enabled = false;
        boolean canType = displayed && enabled;
        System.out.println("canType = " + canType);
        System.out.println("ready? " + (displayed && !enabled ? "visible but disabled" : "other"));
    }
}
output
canType = false
ready? visible but disabled

✅ Knowledge Check

Câu 1. Cách đúng để so sánh nội dung hai String?

  • A. a == b
  • B. a.equals(b)
  • C. a = b
  • D. a.compare(b)
Xem đáp án

Đáp án: B. == so sánh tham chiếu; equals so sánh nội dung.

Câu 2. "Login".equals(x) có ưu điểm gì so với x.equals("Login")?

  • A. Không ném NullPointerException khi x là null
  • B. Nhanh hơn
  • C. Phân biệt hoa-thường
  • D. Không có
Xem đáp án

Đáp án: A. Gọi equals trên hằng luôn an toàn.

Câu 3. 10 + 5 * 2 bằng?

  • A. 30
  • B. 25
  • C. Lỗi
  • D. 20
Xem đáp án

Đáp án: D. Nhân trước cộng: 5 * 2 = 10, cộng 10 → 20.

💼 Interview Corner

1. Why compare strings with equals() instead of ==?

  • 🇻🇳 Dịch: Vì sao so sánh chuỗi bằng equals() thay vì ==?
  • Suggested answer (EN): == compares references and may be false for two strings with the same content, while equals() compares the characters.
  • Giải thích (VI): Trong assertion luôn dùng Assert.assertEquals hoặc equals.
  • Follow-up: Why does "a" == "a" sometimes return true?

2. Why do we call trim() on getText() results?

  • 🇻🇳 Dịch: Vì sao trim() kết quả getText()?
  • Suggested answer (EN): getText() may include leading or trailing whitespace or newlines, so trimming avoids false assertion failures.
  • Giải thích (VI): Dự án Exercise03 dùng getText().trim() khi đọc ô bảng.
  • Follow-up: What does getText() return for a hidden element?
