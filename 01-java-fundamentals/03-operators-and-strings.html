1. Khái niệm

Toán tử (operator) thực hiện phép tính/so sánh trên giá trị. String là chuỗi ký tự — kiểu dữ liệu bạn dùng nhiều nhất trong automation (text, URL, locator, thông báo).

Nhóm Toán tử Ví dụ
Số học + - * / % 7 % 2 → 1
Gán = += -= *= /= x += 5
Tăng/giảm ++ -- i++
So sánh == != > < >= <= age >= 18 → boolean
Logic && (và), \|\| (hoặc), ! (phủ định) a && !b

Thứ tự ưu tiên: () → ! ++ -- → * / % → + - → so sánh → && → || → gán. Khi không chắc, dùng ngoặc ().

2.1. Toán tử — hành vi cần nhớ

Toán tử Làm chính xác gì Ví dụ → kết quả Bẫy
/ Chia. Hai số nguyên → kết quả nguyên (cắt phần dư) 7 / 2 → 3; 7 / 2.0 → 3.5 Chia số nguyên cho 0 → ArithmeticException
% Phần dư của phép chia 7 % 2 → 1; 10 % 5 → 0 Dùng kiểm tra chẵn/lẻ: n % 2 == 0
+ với chuỗi Nối chuỗi "a" + 1 → "a1"; "2" + 3 → "23" Cộng số trước: 1 + 2 + "x" → "3x", còn "x" + 1 + 2 → "x12"
i++ / ++i Tăng 1. i++ dùng giá trị cũ rồi tăng; ++i tăng rồi dùng int i=5; int a=i++; → a=5, i=6 Tránh viết x = x++
+= Cộng rồi gán x += 5 ≡ x = x + 5
== So sánh giá trị (số) hoặc địa chỉ (đối tượng) 5 == 5 → true Không dùng == để so sánh String

\|\| Hoặc, ngắn mạch: vế trái true thì bỏ vế phải a \|\| b

2.2. Từng method của String

String là bất biến: mọi method bên dưới không sửa chuỗi gốc mà trả về chuỗi mới — nhớ gán kết quả lại (s = s.trim();).

length()

  • Làm gì: đếm số ký tự (kể cả khoảng trắng). Trả về: int.
  • Ví dụ: "abc".length() → 3. Lưu ý có dấu ngoặc (), khác mảng (arr.length).

charAt(int index)

  • Làm gì: lấy ký tự ở vị trí index (đếm từ 0). Trả về: char.
  • Ví dụ: "abc".charAt(1) → 'b'. Chỉ số ngoài phạm vi → StringIndexOutOfBoundsException.

trim() / strip()

  • Làm gì: bỏ khoảng trắng đầu và cuối (không đụng khoảng trắng ở giữa). Trả về: String.
  • Ví dụ: " a b ".trim() → "a b".
  • Khác nhau: strip() (Java 11+) hiểu cả khoảng trắng Unicode; trim() chỉ bỏ ký tự điều khiển ASCII. Hay dùng với getText().

equals(String other) / equalsIgnoreCase(String other)

  • Làm gì: so sánh nội dung hai chuỗi. equalsIgnoreCase bỏ qua hoa/thường. Trả về: boolean.
  • Ví dụ: "Abc".equals("abc") → false; "Abc".equalsIgnoreCase("abc") → true.
  • Lưu ý: viết "hằng".equals(biến) để tránh NullPointerException khi biến là null.

contains(String s)

  • Làm gì: kiểm tra chuỗi có chứa đoạn s không. Trả về: boolean.
  • Ví dụ: "You logged in".contains("logged") → true. Phân biệt hoa/thường.

startsWith(String s) / endsWith(String s)

  • Làm gì: kiểm tra chuỗi bắt đầu / kết thúc bằng s. Trả về: boolean.
  • Ví dụ: driver.getCurrentUrl().endsWith("/secure").

substring(int begin) / substring(int begin, int end)

  • Làm gì: cắt chuỗi con. Có end thì lấy từ begin đến trước end (nửa mở [begin, end)). Trả về: String.
  • Ví dụ: "abcdef".substring(1, 4) → "bcd"; "abcdef".substring(2) → "cdef".
  • Lưu ý: chỉ số sai → StringIndexOutOfBoundsException.

indexOf(String s)

  • Làm gì: tìm vị trí đầu tiên xuất hiện s. Trả về: int, -1 nếu không có.
  • Ví dụ: "a-b-c".indexOf("-") → 1. lastIndexOf tìm từ cuối.

replace(String a, String b)

  • Làm gì: thay mọi a bằng b (không dùng regex). Trả về: String mới.
  • Ví dụ: "$50.00".replace("$", "") → "50.00". (replaceAll dùng regex.)

split(String regex)

  • Làm gì: tách chuỗi theo dấu phân cách (là regex). Trả về: String[].
  • Ví dụ: "a,b,c".split(",") → {"a","b","c"}; "1.5".split("\\.") (dấu . phải escape vì là regex).
  • Lưu ý: split(",", 3) giới hạn số phần tử (dùng khi dữ liệu có dấu phẩy).

toUpperCase() / toLowerCase()

  • Làm gì: đổi hết chữ hoa/thường. Trả về: String.
  • Ví dụ: 🧩 Ex8 so tiêu đề bằng getText().toUpperCase() vì CSS hiển thị chữ HOA.

isEmpty() / isBlank()

  • Làm gì: isEmpty() — độ dài bằng 0; isBlank() (Java 11+) — rỗng hoặc chỉ toàn khoảng trắng. Trả về: boolean.
  • Ví dụ: "".isEmpty() → true; " ".isEmpty() → false; " ".isBlank() → true.

String.join(sep, items...) / repeat(n) / compareTo(s)

  • String.join(", ", "a", "b") → "a, b" (nối nhiều chuỗi bằng dấu phân cách).
  • "ab".repeat(3) → "ababab" (Java 11+).
  • "a".compareTo("b") → số âm (a đứng trước b theo thứ tự từ điển); 0 nếu bằng nhau.
Muốn Dùng Không dùng
So hai chuỗi bằng nhau a.equals(b) a == b
Chuỗi có chứa từ khoá s.contains(x) s.equals(x) (đòi bằng cả chuỗi)
Bỏ khoảng trắng thừa của getText() s.trim() —
Kiểm tra chuỗi rỗng/chỉ khoảng trắng s.isBlank() s == ""

2.3. StringBuilder — nối chuỗi nhiều lần

  • Làm gì: bộ đệm chuỗi có thể sửa (khác String bất biến) — nhanh hơn khi nối nhiều lần trong vòng lặp.

Method Làm gì Ví dụ → kết quả

Ví dụ 3 — equals vs ==

java
public class Main {
    public static void main(String[] args) {
        String a = new String("Login");
        String b = new String("Login");
        System.out.println(a == b);              // false: so sánh THAM CHIẾU
        System.out.println(a.equals(b));         // true: so sánh NỘI DUNG
        System.out.println("login".equalsIgnoreCase("LOGIN"));
        String maybeNull = null;
        System.out.println("Login".equals(maybeNull));   // false, không lỗi (gọi equals trên hằng)
    }
}
output
false
true
true
false

Quy tắc: luôn so sánh chuỗi bằng equals. Đặt hằng ở bên trái ("Login".equals(x)) để tránh NullPointerException.

Ví dụ 4 — StringBuilder, Math

java
public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= 3; i++) {
            sb.append("Row").append(i);
            if (i < 3) sb.append(" | ");

        System.out.println(Math.min(3, 9));

        System.out.println(Math.round(2.6));
        System.out.println(Math.floor(2.9) + " " + Math.ceil(2.1));
    }
}

Ví dụ 5 — Boolean trong kiểm tra trạng thái

💼 Interview Corner

1. Why compare strings with equals() instead of ==?

  • 🇻🇳 Dịch: Vì sao so sánh chuỗi bằng equals() thay vì ==?
  • Suggested answer (EN): == compares references and may be false for two strings with the same content, while equals() compares the characters.
  • Giải thích (VI): Trong assertion luôn dùng Assert.assertEquals hoặc equals.
  • Follow-up: Why does "a" == "a" sometimes return true?

2. Why do we call trim() on getText() results?

  • 🇻🇳 Dịch: Vì sao trim() kết quả getText()?
  • Suggested answer (EN): getText() may include leading or trailing whitespace or newlines, so trimming avoids false assertion failures.
  • Giải thích (VI): Dự án Exercise03 dùng getText().trim() khi đọc ô bảng.
  • Follow-up: What does getText() return for a hidden element?
