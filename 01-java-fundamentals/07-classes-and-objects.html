1. Khái niệm

OOP (Object-Oriented Programming) tổ chức chương trình thành các đối tượng, mỗi đối tượng gồm dữ liệu (attributes) và hành vi (methods).

  • Class = bản thiết kế (ví dụ LoginPage).
  • Object = thực thể tạo từ class bằng new (ví dụ new LoginPage(driver)).

Selenium cho bạn nhiều đối tượng sẵn: WebDriver, WebElement, Actions, Select. Khi viết Page Object Model, bạn tự tạo class cho mỗi trang.

2. Syntax

java
public class User {                           // class
    private String name;                      // attribute (field), private = đóng gói
    private int age;

    public User(String name, int age) {       // constructor: tên = tên class, không có kiểu trả về
        this.name = name;                     // this: đối tượng hiện tại
        this.age = age;
    }

    public String getName() {                 // method
        return name;
    }
}

User u = new User("Tom", 30);                 // tạo object
System.out.println(u.getName());              // gọi method qua object

2.1. Từng từ khoá và khái niệm làm gì

new

  • Làm gì: tạo một đối tượng mới trong bộ nhớ từ class rồi gọi constructor của nó. Trả về tham chiếu tới đối tượng đó.
  • Ví dụ: LoginPage page = new LoginPage(driver);
  • Lưu ý: mỗi lần new là một đối tượng riêng. Khai báo LoginPage page; mà chưa new thì page là null → NullPointerException khi dùng.

Constructor

  • Làm gì: method đặc biệt chạy một lần khi new để đặt trạng thái ban đầu của đối tượng. Tên trùng tên class, không có kiểu trả về (kể cả void).
  • Ví dụ:
java
public LoginPage(WebDriver driver) { this.driver = driver; }
  • Lưu ý: không viết constructor nào thì Java tự thêm constructor rỗng; đã viết constructor có tham số thì constructor rỗng không còn tự có. Thêm void vào là biến nó thành method thường.

this

  • Làm gì: tham chiếu tới chính đối tượng đang chạy. Dùng khi tham số trùng tên field: this.name = name; (vế trái là field, vế phải là tham số).
  • this(...): gọi constructor khác của cùng class (phải là dòng đầu tiên).
  • Lưu ý: quên this thì name = name; chỉ gán tham số cho chính nó, field vẫn rỗng.

static

  • Làm gì: gắn thành viên với class, không phải từng đối tượng. Dùng được mà không cần new.
  • Ví dụ: Duration.ofSeconds(15), Assert.assertEquals(...), main(String[] args).
  • Lưu ý: method static không dùng được this và không gọi trực tiếp member non-static (non-static ... cannot be referenced from a static context). Field static dùng chung cho mọi đối tượng — nguy hiểm khi chạy song song (xem static WebDriver).

final

  • Làm gì: "không được đổi". Áp dụng ở ba nơi:
Gắn vào Nghĩa
biến / field Chỉ được gán một lần; thường dùng cho hằng số private static final String LOGIN_URL
method Class con không được ghi đè
class Không được kế thừa (ví dụ String)

public / protected / private / (mặc định)

  • Làm gì: quyết định ai được truy cập một thành viên (xem bảng ở mục 2). Quy tắc thực dụng: field private, method cần dùng ngoài thì public, thành viên cho class con protected.

Getter và Setter

  • Làm gì: method public để đọc (getName()) / gán (setName(...)) một field private — cho phép kiểm tra dữ liệu trước khi gán (đóng gói).

record (Java 16+)

  • Làm gì: khai báo class dữ liệu bất biến gọn: public record LoginData(String user, String pass) {} — Java tự tạo constructor, getter (user()), equals, hashCode, toString.

toString()

  • Làm gì: method mọi đối tượng có; quyết định chuỗi hiện khi System.out.println(obj) hoặc nối chuỗi. Mặc định in dạng ClassName@hash — thường ghi đè để in nội dung dễ đọc.
Field Method Constructor
Là gì Biến thuộc đối tượng Hành vi Khởi tạo ban đầu
Có kiểu trả về? Có (kiểu dữ liệu) Có Không

3. Ví dụ code

Ví dụ 1 — Class TestResult

java
class TestResult {
    String name;                    // field mặc định (package-private)
    boolean passed;

    void print() {
        System.out.println(name + " -> " + (passed ? "PASS" : "FAIL"));
    }
}

public class Main {
    public static void main(String[] args) {
        TestResult r = new TestResult();
        r.name = "testLoginSuccess";
        r.passed = true;
        r.print();

        TestResult r2 = new TestResult();   // object thứ hai, dữ liệu riêng
        r2.name = "testDropdown";
        r2.print();
    }
}
output
testLoginSuccess -> PASS
testDropdown -> FAIL

(passed mặc định false.)

Ví dụ 2 — Constructor, this, private + getter

java
class LoginData {
    private final String username;
    private final String password;

    LoginData(String username, String password) {
        this.username = username;
        this.password = password;
    }

    String getUsername() { return username; }
    boolean isPasswordEmpty() { return password.isEmpty(); }
}

public class Main {
    public static void main(String[] args) {
        LoginData valid = new LoginData("tomsmith", "SuperSecretPassword!");
        LoginData empty = new LoginData("nobody", "");
        System.out.println(valid.getUsername() + " " + valid.isPasswordEmpty());
        System.out.println(empty.getUsername() + " " + empty.isPasswordEmpty());
        // valid.password = "x";   // ❌ password là private
    }
}
output
tomsmith false
nobody true

Ví dụ 3 — static và non-static

java
class Counter {
    static int totalClicks = 0;     // dùng chung cho mọi object
    int myClicks = 0;               // riêng từng object

    void click() {
        myClicks++;
        totalClicks++;
    }

    static String describe() {      // method static: không truy cập myClicks
        return "tổng click = " + totalClicks;
    }
}

public class Main {
    public static void main(String[] args) {
        Counter a = new Counter();
        Counter b = new Counter();
        a.click(); a.click(); b.click();
        System.out.println(a.myClicks + " " + b.myClicks);
        System.out.println(Counter.describe());
    }
}
output
2 1
tổng click = 3

Ví dụ 4 — Mô phỏng một Page Object (không cần Selenium)

java
class FakeDriver {                                   // thay cho WebDriver, chỉ để học cú pháp
    String currentUrl = "";
    void get(String url) { currentUrl = url; System.out.println("get " + url); }
    void type(String locator, String text) { System.out.println("type " + locator + " = " + text); }
    void click(String locator) { System.out.println("click " + locator); }
}

class LoginPage {
    private final FakeDriver driver;                 // field private
    private final String usernameInput = "#username";
    private final String passwordInput = "#password";
    private final String loginButton = "button[type='submit']";

    LoginPage(FakeDriver driver) { this.driver = driver; }   // constructor nhận driver

    LoginPage open() {
        driver.get("https://example.com/login");
        return this;
    }

    void loginAs(String user, String pass) {
        driver.type(usernameInput, user);
        driver.type(passwordInput, pass);
        driver.click(loginButton);
    }
}

public class Main {
    public static void main(String[] args) {
        FakeDriver driver = new FakeDriver();
        new LoginPage(driver).open().loginAs("tomsmith", "SuperSecretPassword!");
    }
}
output
get https://example.com/login
type #username = tomsmith
type #password = SuperSecretPassword!
click button[type='submit']

Đây chính là hình dạng của Page Object: field private (locator), constructor nhận driver, method theo hành vi nghiệp vụ, trả this/page tiếp theo.

💼 Interview Corner

1. What is the difference between a class and an object?

  • 🇻🇳 Dịch: Class khác object thế nào?
  • Suggested answer (EN): A class is a blueprint that defines attributes and methods; an object is an instance created with new.
  • Giải thích (VI): LoginPage là class; new LoginPage(driver) là object.
  • Follow-up: What does this refer to?

2. Why is protected WebDriver driver used in BaseTest?

  • 🇻🇳 Dịch: Vì sao driver là protected?
  • Suggested answer (EN): Subclasses in other packages, like the test classes, need to use it, while it stays hidden from unrelated classes; package-private would not be visible across packages.
  • Giải thích (VI): Đúng với dự án: base.BaseTest và tests.Exercise....
  • Follow-up: What if it were private?

📌 Lesson Summary

Kiến thức cần nhớ

  • Class = bản thiết kế, object = thực thể (new)
  • Constructor khởi tạo; this là object hiện tại
  • private giấu dữ liệu; static thuộc class

Method / lệnh cần biết

  • new, this, static, final, private/protected/public

Điểm dễ nhầm lẫn

  • static ≠ instance
  • Quên this. khi tham số trùng tên field
  • Constructor không có kiểu trả về

Lời giải Exercise 3
java
class CheckboxPage {
    static int totalClicks = 0;
    private boolean checked;

    CheckboxPage(boolean initial) { this.checked = initial; }

    void ensureChecked() {
        if (!checked) {
            checked = true;
            totalClicks++;
        }
    }

    boolean isChecked() { return checked; }
}

public class Main {
    public static void main(String[] args) {
        CheckboxPage page = new CheckboxPage(false);
        page.ensureChecked();
        page.ensureChecked();
        System.out.println(page.isChecked() + " clicks=" + CheckboxPage.totalClicks);
    }
}
output
true clicks=1
