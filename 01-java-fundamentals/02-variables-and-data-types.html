1. Khái niệm

Biến (variable) là "chiếc hộp có tên" để lưu dữ liệu. Mỗi biến có kiểu (type) quyết định loại dữ liệu và dung lượng.

Java có hai nhóm kiểu:

Nhóm Ví dụ Đặc điểm
Primitive (nguyên thủy) int, long, double, boolean, char, byte, short, float Lưu giá trị trực tiếp; viết thường; không có method
Non-primitive (tham chiếu) String, WebDriver, WebElement, List, mảng Lưu tham chiếu tới đối tượng; viết hoa chữ đầu; có method; có thể null

2. Syntax

java
int age = 22;              // kiểu  tên  =  giá trị;
String name = "Tester";
boolean isActive = true;
final int MAX_RETRY = 3;   // hằng số: gán một lần
Thành phần Ý nghĩa
int Kiểu dữ liệu (số nguyên 32-bit)
age Tên biến (camelCase, bắt đầu bằng chữ/_/$, không chứa khoảng trắng)
= Phép gán
22 Giá trị (literal)
final Không cho gán lại; hằng số đặt tên UPPER_SNAKE_CASE

Bảng kiểu thường dùng:

Kiểu Kích thước Ví dụ giá trị Dùng trong automation
int 32 bit 4, -10 số dòng bảng, số phần tử
long 64 bit 100L window.scrollY, thời gian (ms)
double 64 bit 50.75 giá tiền (thực tế dùng BigDecimal)
boolean true/false true isDisplayed(), isSelected()
char 16 bit 'A' ký tự đơn
String tham chiếu "tomsmith" text, URL, locator

3. Ví dụ code

Ví dụ 1 — Khai báo, in, đổi giá trị

java
public class Main {
    public static void main(String[] args) {
        String username = "tomsmith";
        int attempts = 1;
        boolean loggedIn = false;
        final String LOGIN_URL = "https://the-internet.herokuapp.com/login";

        attempts = attempts + 1;     // đổi giá trị
        loggedIn = true;
        // LOGIN_URL = "x";          // ❌ lỗi biên dịch: final

        System.out.println(username + " attempts=" + attempts + " loggedIn=" + loggedIn);
        System.out.println(LOGIN_URL);
    }
}
output
tomsmith attempts=2 loggedIn=true
https://the-internet.herokuapp.com/login

Ví dụ 2 — Nhiều biến, số nguyên và số thực

java
public class Main {
    public static void main(String[] args) {
        int rows = 4, columns = 5;                // khai báo nhiều biến cùng kiểu
        double due = 50.00;
        long big = 3_000_000_000L;                // phải có L khi vượt int
        char grade = 'A';
        System.out.println(rows * columns);       // 20
        System.out.println(due / 3);
        System.out.println(big + 1);
        System.out.println(grade);
        System.out.println(7 / 2);                // chia hai số nguyên → 3
        System.out.println(7 / 2.0);              // 3.5
    }
}
output
20
16.666666666666668
3000000001
A
3
3.5

Lưu ý: 7 / 2 là phép chia số nguyên nên bỏ phần thập phân. Số thực có sai số nhỏ (16.666666666666668) — đừng so sánh double bằng == khi cần chính xác.

Ví dụ 3 — Type casting

java
public class Main {
    public static void main(String[] args) {
        int a = 9;
        double widening = a;              // tự động (nhỏ → lớn): 9.0
        double price = 9.78;
        int narrowing = (int) price;      // thủ công (lớn → nhỏ): cắt phần thập phân → 9
        long y = 120L;
        int safe = (int) y;

        Object scrollY = 120L;            // JavaScript trả về Number dạng Object
        long fromObject = ((Number) scrollY).longValue();   // cách an toàn trong Selenium

        System.out.println(widening + " " + narrowing + " " + safe + " " + fromObject);

        String text = "42";
        int parsed = Integer.parseInt(text);       // String → int
        String back = String.valueOf(parsed + 1);  // int → String
        System.out.println(parsed + 1 + " " + back);
    }
}
output
9.0 9 120 120
43 43
Loại Cú pháp Mất dữ liệu?
Widening (tự động) double d = intValue; Không
Narrowing (thủ công) int i = (int) doubleValue; Có (cắt thập phân, tràn số)
String → số Integer.parseInt("42"), Double.parseDouble("1.5") Ném NumberFormatException nếu sai
Số → String String.valueOf(42) hoặc "" + 42 Không

Ví dụ 4 — var (tuỳ chọn)

java
public class Main {
    public static void main(String[] args) {
        var count = 10;           // trình biên dịch suy ra int
        var title = "Home";       // String
        System.out.println(count + " " + title);
    }
}
output
10 Home

⚠️ Với WebDriver đừng viết var driver = new ChromeDriver(); — biến sẽ có kiểu ChromeDriver, mất lợi ích "khai báo bằng interface" (OOP concepts).

💼 Interview Corner

1. What is the difference between primitive and reference types?

  • 🇻🇳 Dịch: Primitive và reference type khác nhau thế nào?
  • Suggested answer (EN): Primitives such as int and boolean store the value directly and have no methods; reference types such as String and WebElement store a reference to an object, have methods, and can be null.
  • Giải thích (VI): Điều này giải thích NullPointerException và vì sao so sánh chuỗi phải dùng equals.
  • Follow-up: What is autoboxing?

2. What does final mean for a variable?

  • 🇻🇳 Dịch: final với biến nghĩa là gì?
  • Suggested answer (EN): A final variable can be assigned only once, so it behaves as a constant; constants are named in UPPER_SNAKE_CASE, like private static final String LOGIN_URL.
  • Giải thích (VI): Dự án dùng private static final String LOGIN_URL ở mọi Exercise.
  • Follow-up: What about a final object reference — is the object immutable?

📌 Lesson Summary

Kiến thức cần nhớ

  • Primitive: int, long, double, boolean, char; Non-primitive: String, WebElement, List...
  • Ép kiểu thu hẹp có thể mất dữ liệu
  • final = gán một lần (hằng số)

Method / lệnh cần biết

  • Integer.parseInt, Double.parseDouble, String.valueOf, (int) x, ((Number) x).longValue()

Điểm dễ nhầm lẫn

  • 7 / 2 = 3 (chia nguyên), 7 / 2.0 = 3.5
  • == (so sánh) ≠ = (gán)
  • Không dùng var cho WebDriver
