1. Khái niệm

Collection là cấu trúc dữ liệu lưu nhiều phần tử, số lượng linh hoạt (khác mảng cố định). Ba loại chính:

Loại Đặc điểm Hiện thực hay dùng Ví dụ Selenium
List Có thứ tự, cho phép trùng, truy cập theo chỉ số ArrayList List<WebElement> từ findElements
Set Không trùng, thường không đảm bảo thứ tự HashSet Set<String> từ getWindowHandles()
Map Cặp key → value, key không trùng HashMap Dữ liệu test, cấu hình

Collection chỉ chứa đối tượng (không chứa int trực tiếp) → dùng wrapper class: Integer, Double, Boolean, Character. Java tự đổi qua lại (autoboxing/unboxing).

2. Syntax

java
List<String> names = new ArrayList<>();       // <String>: generics — chỉ chứa String
names.add("user1");  names.get(0);  names.size();  names.contains("user1");  names.remove("user1");

Set<String> handles = new HashSet<>();
handles.add("A");  handles.add("A");          // lần 2 bị bỏ qua (không trùng)

Map<String, String> user = new HashMap<>();
user.put("username", "tomsmith");  user.get("username");  user.containsKey("password");
Method Ý nghĩa (List)
add(e), add(i, e) Thêm cuối / thêm tại vị trí
get(i), set(i, e) Lấy / đổi
remove(i) / remove(obj) Xoá theo chỉ số / theo giá trị
size(), isEmpty(), contains(e) Kích thước, rỗng, chứa
clear() Xoá hết
List.of(...) List bất biến (không add/remove được)

Map: put, get, getOrDefault(k, d), containsKey, remove, keySet(), values(), entrySet().

3. Ví dụ code

Ví dụ 1 — ArrayList

java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> captions = new ArrayList<>();
        captions.add("name: user1");
        captions.add("name: user2");
        captions.add("name: user3");

        System.out.println(captions.size() + " " + captions.get(0));
        captions.remove("name: user2");
        System.out.println(captions);
        System.out.println(captions.contains("name: user3") + " " + captions.isEmpty());

        for (String c : captions) {
            System.out.println("-> " + c);
        }
    }
}
output
3 name: user1
[name: user1, name: user3]
true false
-> name: user1
-> name: user3

Ví dụ 2 — Set loại phần tử trùng

java
import java.util.HashSet;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        Set<String> handles = new HashSet<>();
        handles.add("window-A");
        handles.add("window-B");
        handles.add("window-A");                 // trùng → bỏ qua
        System.out.println(handles.size());

        String main = "window-A";
        for (String h : handles) {
            if (!h.equals(main)) {
                System.out.println("tab mới: " + h);
            }
        }
    }
}
output
2
tab mới: window-B

Đây là mẫu chuyển sang tab mới: getWindowHandles() trả Set<String>, so sánh với handle chính.

Ví dụ 3 — HashMap làm dữ liệu test

java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        Map<String, String> user = new HashMap<>();
        user.put("username", "tomsmith");
        user.put("password", "SuperSecretPassword!");
        user.put("username", "tomsmith2");       // cùng key → ghi đè value

        System.out.println(user.get("username"));
        System.out.println(user.getOrDefault("email", "(không có)"));
        System.out.println(user.containsKey("password") + " " + user.size());

        for (Map.Entry<String, String> e : user.entrySet()) {
            if (e.getKey().equals("username")) {
                System.out.println(e.getKey() + " = " + e.getValue());
            }
        }
    }
}
output
tomsmith2
(không có)
true 2
username = tomsmith2

(Thứ tự duyệt HashMap không đảm bảo; nếu cần thứ tự chèn dùng LinkedHashMap.)

Ví dụ 4 — Wrapper class, autoboxing, sắp xếp

java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<Integer> durations = new ArrayList<>();   // Integer, không phải int
        durations.add(900);                             // autoboxing: int → Integer
        durations.add(120);
        durations.add(450);
        int first = durations.get(0);                   // unboxing
        Collections.sort(durations);
        System.out.println(durations + " first=" + first);
        System.out.println(Collections.max(durations));

        Integer n = Integer.valueOf("42");
        Boolean flag = Boolean.parseBoolean("true");
        System.out.println(n + 1 + " " + flag);
    }
}
output
[120, 450, 900] first=900
900
43 true

Ví dụ 5 — Iterator và xoá an toàn

java
import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> options = new ArrayList<>(List.of("Please select an option", "Option 1", "Option 2"));

        Iterator<String> it = options.iterator();
        while (it.hasNext()) {
            if (it.next().startsWith("Please")) it.remove();   // xoá an toàn khi đang duyệt
        }
        System.out.println(options);

        options.removeIf(s -> s.endsWith("2"));                 // cách ngắn gọn
        System.out.println(options);
    }
}
output
[Option 1, Option 2]
[Option 1]

4. Ứng dụng trong Selenium (Real-world)

java
List<WebElement> elements = driver.findElements(By.tagName("input"));   // nhiều WebElement → List

5. Lỗi thường gặp

Lỗi Nguyên nhân Cách sửa
IndexOutOfBoundsException get(i) với i >= size() Kiểm tra size()/isEmpty()
UnsupportedOperationException add/remove trên List.of(...)/Arrays.asList new ArrayList<>(...)
ConcurrentModificationException Xoá phần tử trong for-each Iterator.remove()/removeIf
NullPointerException ở map.get(k) rồi unboxing Key không tồn tại → null getOrDefault, kiểm tra null
list.remove(1) xoá nhầm theo chỉ số khi list Integer Overload remove(int) vs remove(Object) remove(Integer.valueOf(1))
Nhầm size() / length / length() Ba cú pháp khác nhau List size(), mảng length, String length()
Giả định thứ tự của HashSet/HashMap Không đảm bảo LinkedHashSet/LinkedHashMap/TreeMap
Lưu List<WebElement> lâu rồi dùng lại Phần tử stale Lấy dữ liệu chuỗi trước hoặc tìm lại

💼 Interview Corner

1. Why does findElements return a List and what happens if nothing matches?

  • 🇻🇳 Dịch: Vì sao findElements trả List, không thấy thì sao?
  • Suggested answer (EN): The number of matching elements is not known in advance, so a resizable List<WebElement> fits; if nothing matches it returns an empty list instead of throwing.
  • Giải thích (VI): Dùng findElements(by).isEmpty() để kiểm tra tồn tại.
  • Follow-up: How does an implicit wait affect it?

2. Difference between List, Set and Map?

  • 🇻🇳 Dịch: Khác nhau giữa List, Set, Map?
  • Suggested answer (EN): A List is ordered and allows duplicates, a Set contains no duplicates, and a Map stores unique keys mapped to values.
  • Giải thích (VI): getWindowHandles() trả Set<String>.
  • Follow-up: When would you use LinkedHashMap?
