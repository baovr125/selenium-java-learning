Cách học Phase 1

  1. Gõ lại ví dụ (đừng chỉ đọc), chạy bằng java Main.java (JDK 21+) hoặc IDE.
  2. Làm 3 bài tập cuối bài, mở lời giải ở cuối.
  3. Trả lời Knowledge Check, đọc Interview Corner.
  4. Khi đọc BaseTest.java hiểu từng dòng thì bạn đã sẵn sàng sang Phase 2.
