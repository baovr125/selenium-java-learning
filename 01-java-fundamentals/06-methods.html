1. Khái niệm

Method là khối code có tên, làm một việc, gọi lại nhiều lần. Nhờ method, bạn không lặp code và test đọc như kịch bản. Method chính là nền tảng của Reusable Method và Page Method (POM).

2. Syntax

java
public static int add(int a, int b) {      // kiểu_trả_về  tên(tham_số)
    return a + b;                           // trả về giá trị
}
void log(String msg) { ... }                // void: không trả về gì
int sum = add(2, 3);                        // gọi method
Thành phần Ý nghĩa
public static Modifier (xem Classes)
int Kiểu trả về (void nếu không trả)
add Tên method (động từ, camelCase)
(int a, int b) Tham số (parameters) khi định nghĩa; giá trị truyền vào khi gọi là arguments
return Trả giá trị và thoát method

2.1. Từng khái niệm về method

Chữ ký method (signature)

  • Là gì: tên + danh sách kiểu tham số (không tính kiểu trả về). Hai method trong cùng class phải có chữ ký khác nhau.
  • Ví dụ: add(int, int) và add(double, double) là hai method khác nhau.

Tham số (parameter) và đối số (argument)

  • Tham số: biến khai báo ở định nghĩa method: int add(int a, int b) — a, b là tham số.
  • Đối số: giá trị bạn truyền khi gọi: add(2, 3) — 2, 3 là đối số.
  • Truyền theo giá trị: Java luôn sao chép giá trị vào tham số. Sửa int/String bên trong method không đổi biến bên ngoài. Với đối tượng, bản sao là bản sao của tham chiếu — sửa nội dung đối tượng thì bên ngoài thấy, nhưng gán tham số sang đối tượng khác thì không ảnh hưởng.

return

  • Làm gì: trả giá trị về nơi gọi và thoát method ngay lập tức.
  • Quy tắc: kiểu giá trị phải khớp kiểu trả về; mọi nhánh (if/else) phải return, nếu không báo missing return statement.

void

  • Làm gì: method không trả giá trị. return; (không kèm giá trị) vẫn dùng được để thoát sớm.
  • Phân biệt: method làm việc (click(), void) và method lấy dữ liệu (getText(), trả String).

Overloading (nạp chồng)

  • Làm gì: cùng tên, khác tham số (khác số lượng hoặc khác kiểu). Java chọn method khớp với đối số khi gọi.
  • Ví dụ: findElement(By); sendKeys(CharSequence...); new WebDriverWait(driver, Duration) và new WebDriverWait(driver, Duration, Duration).
  • Lưu ý: chỉ khác kiểu trả về thì không phải overload (lỗi biên dịch).

Varargs Kiểu... tên

  • Làm gì: nhận số lượng đối số tuỳ ý của một kiểu; bên trong method nó là mảng.
  • Ví dụ: static void assertSameElement(String name, WebElement ref, WebElement... others) — gọi với 0, 1 hoặc nhiều WebElement.
  • Lưu ý: phải là tham số cuối cùng, và mỗi method chỉ có một.

Phạm vi biến (scope)

  • Làm gì: biến chỉ tồn tại trong khối { } khai báo nó. Hết khối là biến biến mất.
  • Phân biệt: biến cục bộ (trong method, phải gán giá trị trước khi dùng) và field (thuộc đối tượng/class, có giá trị mặc định).

Đệ quy

  • Làm gì: method tự gọi lại chính nó để giải bài toán nhỏ hơn.
  • Bắt buộc: có điều kiện dừng (base case); thiếu thì StackOverflowError.
Từ khoá Ở đâu Ý nghĩa
tham số định nghĩa method Biến nhận dữ liệu
đối số lời gọi method Giá trị truyền vào
return thân method Trả giá trị + thoát
void kiểu trả về Không trả gì
overload cùng class Cùng tên, khác tham số
varargs tham số cuối Số đối số tuỳ ý (là mảng)

3. Ví dụ code

Ví dụ 1 — Tham số và giá trị trả về

java
public class Main {
    static int countFailed(int total, int passed) {
        return total - passed;
    }

    static String verdict(int failed) {
        if (failed == 0) return "PASS";
        return "FAIL";
    }

    static void printLine(String label, String value) {      // void
        System.out.println(label + ": " + value);
    }

    public static void main(String[] args) {
        int failed = countFailed(10, 8);
        printLine("failed", String.valueOf(failed));
        printLine("verdict", verdict(failed));
    }
}
output
failed: 2
verdict: FAIL

Ví dụ 2 — Overloading (cùng tên, khác tham số)

java
public class Main {
    static String describe(String locator) {
        return "by id " + locator;
    }
    static String describe(String strategy, String locator) {
        return "by " + strategy + " " + locator;
    }
    static String describe(int index) {
        return "index " + index;
    }

    public static void main(String[] args) {
        System.out.println(describe("username"));
        System.out.println(describe("css", "#flash"));
        System.out.println(describe(2));
    }
}
output
by id username
by css #flash
index 2

Java chọn method theo số lượng và kiểu tham số; kiểu trả về không tham gia phân biệt. (Selenium: By.xpath(String), sendKeys(CharSequence...).)

Ví dụ 3 — Varargs

java
public class Main {
    static int countNulls(String name, Object... values) {   // values là mảng Object[]
        int n = 0;
        for (Object v : values) if (v == null) n++;
        System.out.println(name + " nhận " + values.length + " giá trị");
        return n;
    }

    public static void main(String[] args) {
        System.out.println(countNulls("a", 1, null, "x"));
        System.out.println(countNulls("b"));
    }
}
output
a nhận 3 giá trị
1
b nhận 0 giá trị
0

Ví dụ 4 — Scope (phạm vi biến)

java
public class Main {
    static int counter = 0;                 // biến của class: dùng được ở mọi method

    static void click() {
        int local = 10;                     // biến cục bộ: chỉ trong method này
        counter++;
        System.out.println("click #" + counter + " local=" + local);
    }

    public static void main(String[] args) {
        click();
        click();
        for (int i = 0; i < 1; i++) {
            int inLoop = 5;                 // chỉ tồn tại trong vòng for
            System.out.println(inLoop);
        }
        // System.out.println(inLoop);     // ❌ cannot find symbol
        // System.out.println(local);      // ❌ ngoài method
    }
}
output
click #1 local=10
click #2 local=10
5

Ví dụ 5 — Recursion (mức cơ bản)

java
public class Main {
    static int factorial(int n) {
        if (n <= 1) return 1;               // điều kiện dừng (BẮT BUỘC)
        return n * factorial(n - 1);        // tự gọi lại chính nó
    }

    public static void main(String[] args) {
        System.out.println(factorial(5));
    }
}
output
120

Recursion ít dùng trong test thông thường; ứng dụng thật: duyệt cây thư mục, duyệt cấu trúc lồng nhau. Luôn có điều kiện dừng để tránh StackOverflowError.

4. Ứng dụng trong Selenium (Real-world)

Dự án đã dùng method để tránh lặp và đặt tên cho hành vi — trích Exercise03_WebTablesTest.java:

java
private List<String> getRowData(By rowLocator) {         // tham số By, trả về List<String>
    WebElement row = driver.findElement(rowLocator);
    List<WebElement> cells = row.findElements(By.tagName("td"));
    List<String> data = new ArrayList<>();
    for (int i = 0; i < cells.size() - 1; i++) {
        data.add(cells.get(i).getText().trim());
    }
    return data;                                          // giá trị trả về
}

void vs trả giá trị click() (void) / getText() (String)
Method trả boolean isDisplayed() dùng trong điều kiện

5. Lỗi thường gặp

Lỗi Nguyên nhân Cách sửa
missing return statement Có nhánh không return Đảm bảo mọi nhánh trả giá trị
Gọi method non-static từ static main Không có đối tượng new Main().method() hoặc để method static
incompatible types ở giá trị trả về Trả sai kiểu Đúng kiểu khai báo
Sửa tham số String/int trong method mà bên ngoài không đổi Java truyền theo giá trị Trả giá trị mới bằng return
StackOverflowError Recursion thiếu điều kiện dừng Thêm base case
Method làm quá nhiều việc Khó tái sử dụng Tách method nhỏ, một việc
Biến cục bộ "không tồn tại" Dùng ngoài scope Khai báo ở scope phù hợp

💼 Interview Corner

1. What is method overloading and where does Selenium use it?

  • 🇻🇳 Dịch: Overloading là gì, Selenium dùng ở đâu?
  • Suggested answer (EN): Overloading means several methods with the same name but different parameters. Selenium uses it widely, for example sendKeys(CharSequence...) or the WebDriverWait constructors.
  • Giải thích (VI): Overloading là đa hình lúc biên dịch.
  • Follow-up: How is it different from overriding?

2. Why are small reusable methods important in test automation?

  • 🇻🇳 Dịch: Vì sao method nhỏ, dùng lại quan trọng?
  • Suggested answer (EN): They remove duplication, give names to behaviors, make tests readable and are the base of page object methods like loginAs(user, pass).
  • Giải thích (VI): Dự án: getRowData, clickAndVerifyToggled, scrollToBottom.
  • Follow-up: When do you extract a helper?

📌 Lesson Summary

Kiến thức cần nhớ

  • Method: kiểu trả về + tên + tham số + return
  • Overloading, varargs, scope, recursion (cơ bản)
  • Java truyền tham số theo giá trị

Method / lệnh cần biết

  • static, void, return, Type... values

Điểm dễ nhầm lẫn

  • Tham số (parameters) ≠ đối số (arguments)
  • Overloading ≠ Overriding
  • Biến cục bộ ≠ biến của class
