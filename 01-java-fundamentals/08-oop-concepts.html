1. Khái niệm

Bốn trụ cột OOP — và nơi bạn gặp chúng trong Selenium:

Trụ cột Ý nghĩa ngắn Trong Selenium
Encapsulation (đóng gói) Giấu dữ liệu, chỉ lộ hành vi cần thiết Locator private, method public trong Page
Inheritance (kế thừa) Class con dùng lại thành viên của class cha BaseTest, BasePage
Polymorphism (đa hình) Cùng một kiểu, nhiều hiện thực WebDriver driver = new ChromeDriver()
Abstraction (trừu tượng) Chỉ khai báo "làm gì", ẩn "làm thế nào" Interface WebDriver, abstract class BasePage

2. Syntax

java
class Dog extends Animal { ... }                       // kế thừa
class Dog extends Animal { @Override void sound() {} } // ghi đè method
abstract class Animal { abstract void sound(); }       // abstract: có method chưa hiện thực
interface Driver { void get(String url); }             // interface: hợp đồng
class ChromeLike implements Driver { ... }             // implements
Driver d = new ChromeLike();                           // đa hình: kiểu interface, đối tượng cụ thể
package pages;                                          // khai báo package ở dòng đầu file
import org.openqa.selenium.By;                         // dùng class của package khác
Khái niệm Từ khoá Ghi chú
Kế thừa extends Một class chỉ extends một class
Gọi constructor/method cha super(...), super.method()
Ghi đè @Override Cùng chữ ký; compiler kiểm tra giúp
Abstract class abstract Không new trực tiếp; có thể có field, constructor
Interface interface, implements Một class implements nhiều interface
Package package, import Gom class; thư mục khớp tên package

3. Ví dụ code

Ví dụ 1 — Encapsulation

java
class Account {
    private int attempts;                     // không cho sửa trực tiếp

    void recordFailure() { attempts++; }
    boolean isLocked() { return attempts >= 3; }
}

public class Main {
    public static void main(String[] args) {
        Account a = new Account();
        for (int i = 0; i < 3; i++) a.recordFailure();
        System.out.println("locked = " + a.isLocked());
        // a.attempts = 0;   // ❌ private: không thể phá luật bên trong
    }
}
output
locked = true

Ví dụ 2 — Inheritance (mô phỏng BaseTest)

java
class BaseTest {
    protected String driver;                         // field cho class con dùng

    void setup() {
        driver = "ChromeDriver";
        System.out.println("setup: mở " + driver);
    }
    void tearDown() {
        System.out.println("tearDown: quit " + driver);
    }
}

class LoginTest extends BaseTest {                   // kế thừa setup/tearDown/driver
    void testLogin() {
        System.out.println("test: dùng " + driver + " để đăng nhập");
    }
}

public class Main {
    public static void main(String[] args) {
        LoginTest t = new LoginTest();
        try {
            t.setup();                               // method của cha
            t.testLogin();                           // method của con
        } finally {
            t.tearDown();
        }
    }
}
output
setup: mở ChromeDriver
test: dùng ChromeDriver để đăng nhập
tearDown: quit ChromeDriver

Đây đúng là khuôn main() của các Exercise trong dự án.

Ví dụ 3 — Polymorphism + Interface

java
interface Browser {
    void open(String url);
}

class ChromeBrowser implements Browser {
    @Override public void open(String url) { System.out.println("Chrome mở " + url); }
}

class FirefoxBrowser implements Browser {
    @Override public void open(String url) { System.out.println("Firefox mở " + url); }
}

class BrowserFactory {
    static Browser create(String name) {
        return switch (name) {
            case "chrome" -> new ChromeBrowser();
            case "firefox" -> new FirefoxBrowser();
            default -> throw new IllegalArgumentException("Không hỗ trợ: " + name);
        };
    }
}

public class Main {
    public static void main(String[] args) {
        for (String name : new String[]{"chrome", "firefox"}) {
            Browser b = BrowserFactory.create(name);     // kiểu Browser, đối tượng cụ thể
            b.open("https://the-internet.herokuapp.com");
        }
    }
}
output
Chrome mở https://the-internet.herokuapp.com
Firefox mở https://the-internet.herokuapp.com

Code dùng Browser b không cần biết là Chrome hay Firefox — chính là cách WebDriver và DriverFactory hoạt động.

Ví dụ 4 — Abstract class (mô phỏng BasePage)

java
abstract class BasePage {
    protected final String name;

    protected BasePage(String name) { this.name = name; }

    protected void click(String locator) {                // hành vi dùng chung
        System.out.println("[" + name + "] chờ clickable rồi click " + locator);
    }

    abstract boolean isLoaded();                          // mỗi page tự định nghĩa
}

class LoginPage extends BasePage {
    LoginPage() { super("LoginPage"); }                   // gọi constructor cha

    @Override boolean isLoaded() { return true; }

    void submit() { click("button[type='submit']"); }
}

public class Main {
    public static void main(String[] args) {
        LoginPage p = new LoginPage();
        p.submit();
        System.out.println("loaded = " + p.isLoaded());
        // BasePage b = new BasePage("x");   // ❌ abstract không thể new
    }
}
output
[LoginPage] chờ clickable rồi click button[type='submit']
loaded = true

Ví dụ 5 — Interface vs Abstract class

Interface Abstract class
Mục đích Hợp đồng "làm được gì" Khung chung + một phần hiện thực
Field Chỉ hằng Field thường
Constructor Không Có
Kế thừa Implement nhiều interface extends một class
Selenium WebDriver, WebElement, JavascriptExecutor, TakesScreenshot, Alert BasePage, BaseTest (thường)

ChromeDriver implement cả WebDriver lẫn JavascriptExecutor, nên bạn ép kiểu (JavascriptExecutor) driver (như Exercise07).

Ví dụ 6 — Enum và Package

java
enum BrowserType { CHROME, FIREFOX, EDGE }      // tập hằng cố định, an toàn hơn String

public class Main {
    public static void main(String[] args) {
        BrowserType b = BrowserType.valueOf("FIREFOX");
        switch (b) {
            case CHROME -> System.out.println("chrome");
            case FIREFOX -> System.out.println("firefox");
            case EDGE -> System.out.println("edge");
        }
        System.out.println(java.util.Arrays.toString(BrowserType.values()));
    }
}
output
firefox
[CHROME, FIREFOX, EDGE]

Packages: dự án dùng package base; (BaseTest) và package tests; (các Exercise). Class con ở package khác phải import base.BaseTest;. Thư mục phải khớp: src/test/java/base/BaseTest.java. Quy ước: package viết thường (pages, utils, tests).

5. Lỗi thường gặp

Lỗi Nguyên nhân Cách sửa
cannot inherit from final Class đánh dấu final Không kế thừa class final
does not override abstract method Class con thiếu method abstract/interface Hiện thực đủ method
Quên @Override rồi gõ sai tên → thành method mới Không có kiểm tra Luôn thêm @Override
class X is public, should be declared in file X.java Khác tên file Mỗi public class một file
Lỗi package ... does not exist Sai import/thư mục Khớp package với thư mục
Kế thừa sâu nhiều tầng Khó hiểu Ưu tiên composition (Page có Header)

💼 Interview Corner

1. Explain polymorphism with a Selenium example.

  • 🇻🇳 Dịch: Giải thích đa hình bằng ví dụ Selenium.
  • Suggested answer (EN): A WebDriver reference can point to ChromeDriver, FirefoxDriver or EdgeDriver; calling driver.get(url) runs the implementation of the actual object, so the test code does not depend on the browser.
  • Giải thích (VI): Đa hình lúc chạy (runtime).
  • Follow-up: How does a DriverFactory use it?

2. Interface vs abstract class — when to use which?

  • 🇻🇳 Dịch: Khi nào dùng interface, khi nào abstract class?
  • Suggested answer (EN): Use an interface to define a contract that unrelated classes can implement, and an abstract class when subclasses share state or common behavior, like a BasePage with a driver and wait helpers.
  • Giải thích (VI): WebDriver là interface; BasePage thường là abstract class.
  • Follow-up: Can a class implement several interfaces?

📌 Lesson Summary

Kiến thức cần nhớ

  • 4 trụ cột: Encapsulation, Inheritance, Polymorphism, Abstraction
  • Interface = hợp đồng; abstract class = khung chung
  • Package gom class; khớp thư mục

Method / lệnh cần biết

  • extends, implements, super, @Override, abstract, package, import, enum

Điểm dễ nhầm lẫn

  • Overriding (con ghi đè cha) ≠ Overloading
  • Kế thừa sâu nhiều tầng khó bảo trì → ưu tiên composition
  • Quên @Override khiến typo thành method mới

Lời giải Exercise 2
java
interface Validator {
    boolean validate(String s);
}

class NotEmpty implements Validator {
    @Override public boolean validate(String s) { return !s.isEmpty(); }
}

class EndsWithSecure implements Validator {
    @Override public boolean validate(String s) { return s.endsWith("/secure"); }
}

public class Main {
    public static void main(String[] args) {
        Validator[] all = { new NotEmpty(), new EndsWithSecure() };
        for (Validator v : all) {
            System.out.println(v.getClass().getSimpleName() + " " + v.validate("https://x.com/secure"));
        }
    }
}
output
NotEmpty true
EndsWithSecure true

java
abstract class BaseTest {
    final void run() {
        System.out.println("setup");
        try {
            test();
        } finally {
            System.out.println("tearDown");
        }
    }
    abstract void test();
}

class LoginTest extends BaseTest {
    @Override void test() { System.out.println("login test"); }
}

class DropdownTest extends BaseTest {
    @Override void test() { System.out.println("dropdown test"); }
}

public class Main {
    public static void main(String[] args) {
        new LoginTest().run();
        new DropdownTest().run();
    }
}
