1. Khái niệm

Mảng lưu số lượng cố định phần tử cùng kiểu, truy cập theo chỉ số bắt đầu từ 0. Kích thước không đổi sau khi tạo — muốn danh sách co giãn dùng ArrayList (Collections).

Trong Selenium, bạn gặp mảng ở: String[] parts = text.split(","), Object[][] của @DataProvider, tham số WebElement... (varargs thực chất là mảng).

2. Syntax

java
String[] browsers = {"chrome", "firefox", "edge"};   // khai báo + gán
int[] counts = new int[3];                            // tạo mảng 3 phần tử, mặc định 0
browsers[0];                                          // truy cập phần tử đầu
browsers.length;                                      // số phần tử (KHÔNG có dấu ngoặc)
int[][] grid = {{1, 2, 3}, {4, 5, 6}};                // mảng 2 chiều
grid[1][2];                                           // hàng 1, cột 2 → 6
Thành phần Ý nghĩa
String[] Kiểu "mảng String"
new int[3] Tạo mảng; số: 0, boolean: false, đối tượng: null
arr.length Thuộc tính độ dài (khác list.size() và string.length())
chỉ số Từ 0 đến length - 1

3. Ví dụ code

Ví dụ 1 — Tạo, truy cập, duyệt

java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        String[] browsers = {"chrome", "firefox", "edge"};
        System.out.println(browsers[0] + " | " + browsers.length);
        browsers[1] = "safari";

        for (int i = 0; i < browsers.length; i++) {
            System.out.println(i + ": " + browsers[i]);
        }
        for (String b : browsers) {
            System.out.print(b.toUpperCase() + " ");
        }
        System.out.println();
        System.out.println(Arrays.toString(browsers));

        int[] counts = new int[3];
        counts[2] = 7;
        System.out.println(Arrays.toString(counts));
    }
}
output
chrome | 3
0: chrome
1: safari
2: edge
CHROME SAFARI EDGE 
[chrome, safari, edge]
[0, 0, 7]

Ví dụ 2 — Sắp xếp, tìm kiếm, Arrays

java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] durations = {900, 120, 450, 30};
        Arrays.sort(durations);
        System.out.println(Arrays.toString(durations));
        System.out.println(Arrays.binarySearch(durations, 450));   // chỉ số trong mảng ĐÃ sắp xếp

        String[] parts = "Smith,John,jsmith@gmail.com".split(",");
        System.out.println(parts.length + " phần, email = " + parts[2]);

        int max = durations[0];
        for (int d : durations) if (d > max) max = d;
        System.out.println("max = " + max);
    }
}
output
[30, 120, 450, 900]
2
3 phần, email = jsmith@gmail.com
max = 900

Ví dụ 3 — Mảng hai chiều (mô phỏng DataProvider)

java
public class Main {
    public static void main(String[] args) {
        Object[][] loginData = {
            {"tomsmith", "SuperSecretPassword!", true},
            {"tomsmith", "wrong",                false},
            {"nobody",   "x",                    false}
        };
        System.out.println("Số bộ dữ liệu: " + loginData.length);
        for (int i = 0; i < loginData.length; i++) {
            String user = (String) loginData[i][0];
            String pass = (String) loginData[i][1];
            boolean expectOk = (Boolean) loginData[i][2];
            System.out.println("Case " + (i + 1) + ": user=" + user + ", pass.length=" + pass.length() + ", expectOk=" + expectOk);
        }
    }
}
output
Số bộ dữ liệu: 3
Case 1: user=tomsmith, pass.length=20, expectOk=true
Case 2: user=tomsmith, pass.length=5, expectOk=false
Case 3: user=nobody, pass.length=1, expectOk=false

Ý nghĩa: mỗi hàng là một lần chạy test, mỗi cột là một tham số — đúng cấu trúc Object[][] mà @DataProvider của TestNG trả về (TestNG).

Ví dụ 4 — Mảng ↔ List

java
import java.util.Arrays;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        String[] arr = {"a", "b", "c"};
        List<String> list = Arrays.asList(arr);     // mảng → List (kích thước cố định)
        String[] back = list.toArray(new String[0]);
        System.out.println(list + " " + back.length);
    }
}
output
[a, b, c] 3

4. Ứng dụng trong Selenium (Real-world)

Kiến thức Ví dụ
String[] từ split Tách dòng dữ liệu CSV: line.split(",")
Object[][] @DataProvider trả bộ dữ liệu cho test đăng nhập
Varargs = mảng assertSameElement(String name, WebElement reference, WebElement... others) (Exercise01) — others là WebElement[]
Arrays.asList Arrays.asList("Smith", "John", "jsmith@gmail.com", "$50.00", "http://www.jsmith.com") so sánh với dữ liệu bảng (Exercise03)
java
@DataProvider(name = "invalid")
public Object[][] invalid() {
    return new Object[][] {
        {"tomsmith", "wrong-password", "Your password is invalid!"},
        {"nobody",   "SuperSecretPassword!", "Your username is invalid!"}
    };
}

Với dữ liệu từ web (findElements) hãy dùng List<WebElement>, không dùng mảng, vì số lượng phần tử không biết trước (Collections).

5. Lỗi thường gặp

Lỗi Nguyên nhân Cách sửa
ArrayIndexOutOfBoundsException Chỉ số -1 hoặc >= length Duyệt i < arr.length
Nhầm arr.length / arr.length() / list.size() Ba cú pháp khác nhau mảng: length; String: length(); List: size()
Không thể thêm phần tử vào mảng Kích thước cố định Dùng ArrayList
UnsupportedOperationException khi add vào Arrays.asList(...) List từ mảng có kích thước cố định new ArrayList<>(Arrays.asList(arr))
ClassCastException khi lấy từ Object[][] Ép sai kiểu Ép đúng kiểu ((String), (Boolean))
NullPointerException với new String[3] Phần tử mặc định null Gán giá trị trước khi dùng

✅ Knowledge Check

Câu 1. Mảng int[] a = new int[3]; có giá trị ban đầu là gì?

  • A. null
  • B. 0, 0, 0
  • C. Rác
  • D. Lỗi
Xem đáp án

Đáp án: B. Mảng số khởi tạo bằng 0 (boolean false, đối tượng null).

Câu 2. Lấy độ dài mảng a viết thế nào?

  • A. a.length
  • B. a.length()
  • C. a.size()
  • D. length(a)
Xem đáp án

Đáp án: A. Mảng: length (không ngoặc); String: length(); List: size().

Câu 3. Mỗi hàng của Object[][] trong @DataProvider tương ứng với?

  • A. Một tham số
  • B. Một class
  • C. Một lần chạy test
  • D. Một suite
Xem đáp án

Đáp án: C. Mỗi hàng = một lần chạy test; mỗi cột = một tham số.

💼 Interview Corner

1. What is the difference between an array and an ArrayList?

  • 🇻🇳 Dịch: Mảng khác ArrayList thế nào?
  • Suggested answer (EN): An array has a fixed size and can hold primitives; an ArrayList is resizable, holds objects and offers methods such as add and remove.
  • Giải thích (VI): findElements trả List vì số phần tử không biết trước.
  • Follow-up: How do you convert between them?

2. What does a TestNG DataProvider return and why?

  • 🇻🇳 Dịch: DataProvider của TestNG trả gì?
  • Suggested answer (EN): An Object[][] (or an iterator): each inner array is one set of arguments and the test runs once per row.
  • Giải thích (VI): Cấu trúc 2 chiều khớp với "nhiều lần chạy × nhiều tham số".
  • Follow-up: Can a DataProvider read from a CSV file?
