1. Khái niệm

Java là ngôn ngữ lập trình hướng đối tượng, biên dịch ra bytecode rồi chạy trên máy ảo Java (JVM). Selenium for Java, TestNG, Maven đều viết bằng Java — nên bạn cần Java để viết test.

Thuật ngữ Ý nghĩa Bạn dùng khi nào
JDK (Java Development Kit) Bộ công cụ để viết và biên dịch (javac) + chạy Cài trên máy làm automation
JRE Môi trường chạy (có trong JDK) Máy chỉ chạy chương trình
JVM Máy ảo thực thi bytecode .class Tự động, không thao tác trực tiếp

Luồng: Hello.java ──javac──► Hello.class (bytecode) ──java──► kết quả.

Cài đặt JDK và kiểm tra môi trường: xem Environment Setup.

2. Syntax: cấu trúc một chương trình Java

java
public class Hello {                          // 1. class: tên PHẢI trùng tên file (Hello.java)
    public static void main(String[] args) {  // 2. main: điểm bắt đầu chạy
        System.out.println("Hello, Tester!"); // 3. một câu lệnh (kết thúc bằng ;)
    }
}
Thành phần Ý nghĩa
public class Hello Khai báo class; tên file là Hello.java
public static void main(String[] args) Phương thức JVM gọi đầu tiên khi chạy bằng java
{ } Khối code
; Kết thúc câu lệnh
System.out.println(...) In ra console

Quy tắc cú pháp: Java phân biệt hoa-thường (System ≠ system); mỗi câu lệnh kết thúc bằng ;; tên class viết PascalCase, tên biến/method camelCase, hằng UPPER_SNAKE_CASE.

🧩 Trong dự án Selenium1, test chạy bằng TestNG nên không cần main; nhưng mỗi Exercise vẫn có main() để chạy trực tiếp (xem Exercise01_LoginTest.java).

3. Ví dụ code

Ví dụ 1 — Hello và Output

java
public class Main {
    public static void main(String[] args) {
        System.out.println("Open browser");   // in rồi xuống dòng
        System.out.print("Login ");            // in, KHÔNG xuống dòng
        System.out.print("success");
        System.out.println();                  // xuống dòng
        System.out.println(2 + 3);             // in số: 5
        System.out.println("2" + 3);           // nối chuỗi: 23
    }
}
output
Open browser
Login success
5
23

Giải thích: println = print + xuống dòng; print giữ nguyên dòng. 2 + 3 là phép cộng số; "2" + 3 là nối chuỗi (vì có một vế là String).

Ví dụ 2 — printf định dạng

java
import java.util.Locale;

public class Main {
    public static void main(String[] args) {
        String test = "Login";
        int passed = 3;
        double rate = 75.5;
        System.out.printf(Locale.US, "Test: %s | passed: %d | rate: %.1f%%%n", test, passed, rate);
    }
}
output
Test: Login | passed: 3 | rate: 75.5%
Mã định dạng Kiểu
%s chuỗi
%d số nguyên
%.1f số thực, 1 chữ số thập phân
%% ký tự %
%n xuống dòng (đúng với mọi hệ điều hành)

⚠️ Bẫy locale (đã gặp thật khi kiểm tra bài này): printf("%.1f", 75.5) in 75,5 trên máy đặt locale Việt/châu Âu và 75.5 trên máy locale Mỹ. Muốn kết quả giống nhau mọi máy (ví dụ khi assert/ghi log), truyền Locale.US làm tham số đầu như trong ví dụ.

Ví dụ 3 — Comments

java
public class Main {
    /**
     * Javadoc: mô tả class/method, hiện trong IDE khi rê chuột.
     */
    public static void main(String[] args) {
        // Comment một dòng: giải thích bước tiếp theo
        System.out.println("Step 1"); // comment cuối dòng

        /* Comment nhiều dòng:
           tạm tắt một đoạn code */
        // System.out.println("Step 2 (đã tắt)");
        System.out.println("Done");
    }
}
output
Step 1
Done

Cách nhanh (không cần Maven), JDK 11+ chạy thẳng file nguồn:

powershell

Output giúp bạn theo dõi test đang làm gì. Đây là cách dự án làm (trích Exercise01_LoginTest.java):

java

Khi test fail, dòng log này giúp biết giá trị thực tế. Về lâu dài, System.out được thay bằng logging (SLF4J) — xem Reusable Components.

Comments trong dự án: Javadoc mô tả mỗi test (/** ... */) và comment từng bước đánh số // 1., // 2. — một quy ước tốt để người khác đọc hiểu kịch bản.

💼 Interview Corner

1. What are JDK, JRE and JVM?

  • 🇻🇳 Dịch: JDK, JRE, JVM là gì?
  • Suggested answer (EN): The JVM runs bytecode, the JRE is the JVM plus libraries needed to run programs, and the JDK adds development tools like the compiler javac.
  • Giải thích (VI): Ba lớp lồng nhau: JDK ⊃ JRE ⊃ JVM.
  • Follow-up: Why is Java called platform independent?

2. What does public static void main(String[] args) mean?

  • 🇻🇳 Dịch: Ý nghĩa của public static void main(String[] args)?
  • Suggested answer (EN): It is the entry point: public so the JVM can call it, static so no object is needed, void because it returns nothing, and args holds command line arguments.
  • Giải thích (VI): Dự án Selenium chạy bằng TestNG nên không cần main, nhưng mỗi Exercise vẫn có main() để chạy trực tiếp.
  • Follow-up: Do TestNG tests need a main method?

📌 Lesson Summary

Kiến thức cần nhớ

  • class + main là khuôn tối thiểu; tên file = tên class public
  • println xuống dòng, print không; printf định dạng
  • Comment //, /* */, /** */
  • Dùng Locale.US khi cần kết quả printf giống nhau trên mọi máy

Method / lệnh cần biết

  • System.out.println/print/printf, javac, java
  • %s %d %.1f %% %n

Điểm dễ nhầm lẫn

  • print ≠ println
  • "2" + 3 ra 23 (nối chuỗi), 2 + 3 ra 5
  • JDK ≠ JRE ≠ JVM
