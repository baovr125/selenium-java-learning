1. Khái niệm

Control flow quyết định đoạn code nào chạy, chạy bao nhiêu lần. Có hai nhóm:

  • Rẽ nhánh: if/else, switch — chọn đường đi theo điều kiện.
  • Lặp: for, while, do-while, for-each — lặp lại một khối code.

Trong automation: kiểm tra trạng thái phần tử, duyệt danh sách WebElement, thử lại thao tác (retry), chọn hành vi theo browser.

2. Syntax

java
if (điều_kiện) { ... } else if (điều_kiện_2) { ... } else { ... }

String s = (điều_kiện) ? "A" : "B";                 // toán tử 3 ngôi

switch (browser) {                                  // switch kiểu mới (Java 14+)
    case "chrome" -> System.out.println("Chrome");
    case "firefox", "edge" -> System.out.println("Other");
    default -> System.out.println("Unknown");
}

for (int i = 0; i < 3; i++) { ... }                 // khởi tạo; điều kiện; bước nhảy
for (String s : list) { ... }                       // for-each
while (điều_kiện) { ... }
do { ... } while (điều_kiện);                       // chạy ÍT NHẤT 1 lần
Từ khoá Tác dụng
break Thoát vòng lặp/switch ngay
continue Bỏ phần còn lại của lượt này, sang lượt kế
return Thoát method

3. Ví dụ code

Ví dụ 1 — if/else if/else

java
public class Main {
    public static void main(String[] args) {
        boolean displayed = true;
        boolean enabled = false;

        if (displayed && enabled) {
            System.out.println("Có thể nhập");
        } else if (displayed) {
            System.out.println("Hiện nhưng bị khoá");
        } else {
            System.out.println("Không hiển thị");
        }

        int failed = 2;
        String result = (failed == 0) ? "PASS" : "FAIL";
        System.out.println(result);
    }
}
output
Hiện nhưng bị khoá
FAIL

Ví dụ 2 — switch

java
public class Main {
    public static void main(String[] args) {
        String browser = "firefox";
        switch (browser) {
            case "chrome" -> System.out.println("ChromeDriver");
            case "firefox" -> System.out.println("FirefoxDriver");
            case "edge" -> System.out.println("EdgeDriver");
            default -> throw new IllegalArgumentException("Không hỗ trợ: " + browser);
        }
        int day = 3;
        String name = switch (day) {            // switch trả về giá trị
            case 1, 7 -> "Cuối tuần";
            case 2, 3, 4, 5, 6 -> "Ngày làm việc";
            default -> "?";
        };
        System.out.println(name);
    }
}
output
FirefoxDriver
Ngày làm việc

Ví dụ 3 — Vòng lặp for, for-each, while, do-while

java
import java.util.List;

public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            System.out.println("Hover ảnh " + i);
        }

        List<String> names = List.of("user1", "user2", "user3");
        for (String n : names) {
            System.out.println("name: " + n);
        }

        int scroll = 0;
        while (scroll < 3) {
            scroll++;
        }
        System.out.println("Đã cuộn " + scroll + " lần");

        int tries = 5;
        do {
            System.out.println("Thử ít nhất 1 lần, tries=" + tries);
        } while (tries < 3);
    }
}
output
Hover ảnh 1
Hover ảnh 2
Hover ảnh 3
name: user1
name: user2
name: user3
Đã cuộn 3 lần
Thử ít nhất 1 lần, tries=5

Ví dụ 4 — break, continue, vòng lặp lồng nhau

java
public class Main {
    public static void main(String[] args) {
        int[] due = {50, 51, 100, 50};
        for (int i = 0; i < due.length; i++) {
            if (due[i] < 51) continue;               // bỏ qua giá trị nhỏ
            System.out.println("Hàng " + (i + 1) + " due=" + due[i]);
            if (due[i] == 100) break;                // dừng khi gặp 100
        }

        for (int row = 1; row <= 2; row++) {
            for (int col = 1; col <= 3; col++) {
                System.out.print("[" + row + "," + col + "] ");
            }
            System.out.println();
        }
    }
}
output
Hàng 2 due=51
Hàng 3 due=100
[1,1] [1,2] [1,3] 
[2,1] [2,2] [2,3]

Ví dụ 5 — Retry có giới hạn (mẫu rất hay gặp)

java
public class Main {
    static int calls = 0;

    static boolean clickSucceeds() {       // giả lập: 2 lần đầu thất bại (stale)
        calls++;
        return calls >= 3;
    }

    public static void main(String[] args) {
        final int MAX = 3;
        boolean done = false;
        for (int attempt = 1; attempt <= MAX && !done; attempt++) {
            done = clickSucceeds();
            System.out.println("attempt " + attempt + " -> " + done);
        }
        if (!done) throw new IllegalStateException("Hết lượt thử");
    }
}
output
attempt 1 -> false
attempt 2 -> false
attempt 3 -> true

5. Lỗi thường gặp

Lỗi Nguyên nhân Cách sửa
Vòng lặp vô hạn Quên cập nhật biến điều kiện (i++) Kiểm tra bước nhảy
ArrayIndexOutOfBoundsException i <= arr.length Dùng i < arr.length
if (a = b) Gán thay vì so sánh ==
Quên break trong switch kiểu cũ (case:) Chạy xuyên (fall-through) Dùng cú pháp mũi tên ->
ConcurrentModificationException Xoá phần tử khỏi list khi đang for-each Dùng Iterator.remove() hoặc removeIf
Retry vô hạn trong test while (true) không giới hạn Giới hạn số lần như Ví dụ 5
Dùng Thread.sleep trong vòng lặp để "chờ" Chậm và flaky WebDriverWait (Wait)

💼 Interview Corner

1. When would you use for-each instead of a classic for loop?

  • 🇻🇳 Dịch: Khi nào dùng for-each thay for thường?
  • Suggested answer (EN): When I only need each element and not its index, for example iterating over a List<WebElement>; I use the classic loop when I need the index or must modify the loop variable.
  • Giải thích (VI): Dự án: for (WebElement option : dropdown.getOptions()) và for (int i = 0; i < userFigures.size(); i++) (cần chỉ số).
  • Follow-up: What happens if you remove from a list inside for-each?

2. How would you implement a retry for a flaky click?

  • 🇻🇳 Dịch: Làm sao viết retry cho thao tác click chập chờn?
  • Suggested answer (EN): Use a bounded loop that catches a specific exception such as StaleElementReferenceException, retries up to N times and rethrows on the last attempt; better still, fix the synchronization with an explicit wait.
  • Giải thích (VI): Retry chỉ là biện pháp cuối; ưu tiên Wait đúng điều kiện.
  • Follow-up: Why is retry dangerous for hiding bugs?

📌 Lesson Summary

Kiến thức cần nhớ

  • if/else if/else, ? :, switch ->
  • for (có chỉ số), for-each (duyệt), while, do-while
  • break thoát, continue bỏ qua lượt

Method / lệnh cần biết

  • for (int i = 0; i < n; i++), for (T x : list), switch (x) { case A -> ... }

Điểm dễ nhầm lẫn

  • i < n (đúng) ≠ i <= n (vượt biên)
  • = ≠ == trong điều kiện
  • while kiểm tra trước, do-while kiểm tra sau
