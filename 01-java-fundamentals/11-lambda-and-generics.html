1. Khái niệm

  • Generics: viết List<String> để compiler kiểm tra kiểu lúc biên dịch, không cần ép kiểu.
  • Lambda: cách viết ngắn một hàm ẩn danh, truyền như tham số. Selenium dùng trong Wait: wait.until(d -> ...).
  • Functional interface: interface có đúng một method trừu tượng (Function, Predicate, Runnable) — lambda "khớp" với nó.
  • Annotation: thẻ @... gắn metadata cho class/method; framework (TestNG, JUnit) đọc để biết cách chạy.
  • Thread: luồng thực thi; chạy test song song cần mỗi luồng có WebDriver riêng.

2. Syntax

java
List<String> list = new ArrayList<>();          // generics + diamond <>
Function<WebDriver, Boolean> cond = d -> d.getTitle().equals("Home");   // lambda: (tham_số) -> biểu_thức
Predicate<String> notEmpty = s -> !s.isEmpty();
list.forEach(s -> System.out.println(s));       // lambda với forEach
list.stream().map(String::toUpperCase).toList();  // method reference
@Test public void testLogin() { }               // annotation
Pattern.compile("\\d+")                         // RegEx
Cú pháp lambda Ý nghĩa
x -> x * 2 1 tham số, biểu thức
(a, b) -> a + b nhiều tham số
d -> { ...; return true; } nhiều câu lệnh, cần return
ClassName::method method reference (viết gọn lambda gọi 1 method)

Biến cục bộ được dùng trong lambda phải là final hoặc effectively final (không được gán lại).

3. Ví dụ code

Ví dụ 1 — Generics

java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Main {
    // method generic: dùng được cho mọi kiểu T
    static <T> T firstOrNull(List<T> items) {
        return items.isEmpty() ? null : items.get(0);
    }

    public static void main(String[] args) {
        List<String> names = new ArrayList<>();
        names.add("user1");
        // names.add(5);              // ❌ lỗi biên dịch: List<String> chỉ nhận String
        String s = names.get(0);      // không cần ép kiểu

        Map<String, List<Integer>> scores = new HashMap<>();
        scores.put("login", List.of(1, 2, 3));

        System.out.println(s + " " + firstOrNull(names) + " " + firstOrNull(new ArrayList<Integer>()));
        System.out.println(scores.get("login").size());
    }
}
output
user1 user1 null
3

Ví dụ 2 — Lambda và Functional Interface

java
import java.util.function.Function;
import java.util.function.Predicate;

public class Main {
    public static void main(String[] args) {
        Predicate<String> isSecureUrl = url -> url.endsWith("/secure");
        Function<String, Integer> length = String::length;

        System.out.println(isSecureUrl.test("https://x.com/secure"));
        System.out.println(isSecureUrl.test("https://x.com/login"));
        System.out.println(length.apply("tomsmith"));

        Runnable step = () -> System.out.println("chạy một bước");
        step.run();
    }
}

Ví dụ 3 — Mô phỏng wait.until(lambda) (polling)

java
import java.util.function.Function;

public class Main {
    static int pollCount = 0;

    // mô phỏng Wait.until: lặp lại đến khi điều kiện trả truthy hoặc hết số lần
    static <T> T until(Function<String, T> condition, int maxPolls) {
        for (int i = 1; i <= maxPolls; i++) {
            T result = condition.apply("driver");
            if (result != null && !Boolean.FALSE.equals(result)) {
                System.out.println("điều kiện đạt ở lần poll " + i);
                return result;
            }
        }
        throw new IllegalStateException("Timeout sau " + maxPolls + " lần");
    }

    public static void main(String[] args) {
        Boolean ok = until(d -> {
            pollCount++;
            return pollCount >= 3;          // đạt ở lần thứ 3
        }, 5);
        System.out.println("kết quả = " + ok);
    }
}
output
điều kiện đạt ở lần poll 3
kết quả = true

Đây là cơ chế bên trong WebDriverWait.until(...): gọi lại hàm điều kiện theo chu kỳ cho tới khi trả giá trị truthy hoặc hết timeout.

Ví dụ 4 — Stream + method reference

java
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> captions = List.of("name: user1", "name: user2", "", "name: user3");

        List<String> upper = captions.stream()
                .filter(s -> !s.isEmpty())              // bỏ chuỗi rỗng
                .map(String::toUpperCase)               // đổi hoa
                .toList();
        System.out.println(upper);

        long count = captions.stream().filter(s -> s.startsWith("name")).count();
        System.out.println(count);
    }
}
output
[NAME: USER1, NAME: USER2, NAME: USER3]
3

Ví dụ 5 — Annotation tự định nghĩa (để hiểu cách TestNG/JUnit hoạt động)

java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.lang.reflect.Method;

public class Main {
    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.METHOD)
    @interface MyTest { String description() default ""; }

    @MyTest(description = "login ok")
    public void testLogin() { System.out.println("chạy testLogin"); }

    public void helper() { }

    public static void main(String[] args) throws Exception {
        Main instance = new Main();
        for (Method m : Main.class.getDeclaredMethods()) {
            MyTest a = m.getAnnotation(MyTest.class);
            if (a != null) {                               // "framework" thấy @MyTest
                System.out.println("tìm thấy test: " + m.getName() + " (" + a.description() + ")");
                m.invoke(instance);
            }
        }
    }
}
output
tìm thấy test: testLogin (login ok)
chạy testLogin

TestNG làm điều tương tự (quét @Test, @BeforeMethod, @AfterMethod bằng reflection rồi gọi đúng thứ tự).

Ví dụ 6 — RegEx cơ bản và ThreadLocal (giới thiệu)

java
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class Main {
    private static final ThreadLocal<String> DRIVER_NAME = new ThreadLocal<>();

    public static void main(String[] args) throws Exception {
        Matcher m = Pattern.compile("\\$(\\d+\\.\\d{2})").matcher("Due: $50.00");
        if (m.find()) System.out.println("số tiền = " + m.group(1));
        System.out.println("12345".matches("\\d+"));

        Thread t1 = new Thread(() -> { DRIVER_NAME.set("driver-A"); System.out.println("T1 thấy " + DRIVER_NAME.get()); });
        t1.start();
        t1.join();                                           // chờ t1 xong
        DRIVER_NAME.set("driver-main");
        System.out.println("main thấy " + DRIVER_NAME.get());
    }
}
output
số tiền = 50.00
true
T1 thấy driver-A
main thấy driver-main

Mỗi luồng thấy giá trị riêng của ThreadLocal — đó là lý do ThreadLocal<WebDriver> giúp chạy test song song an toàn.

5. Lỗi thường gặp

Lỗi Nguyên nhân Cách sửa
local variables referenced from a lambda expression must be final or effectively final Gán lại biến bên ngoài lambda Dùng biến final/sao chép giá trị
incompatible types với generics Gán List<Object> cho List<String> Khai báo đúng kiểu tham số
Dùng generic với kiểu nguyên thủy (List<int>) Generics chỉ nhận kiểu tham chiếu List<Integer>
Lambda có side effect khó đoán Điều kiện chờ gọi nhiều lần Giữ điều kiện đơn giản; side effect có chủ đích (như cuộn lặp) cần ghi chú
Quên @Test/sai import annotation Test không chạy org.testng.annotations.Test
static driver dùng chung khi song song Các luồng giẫm nhau ThreadLocal<WebDriver> + remove()
RegEx quên escape \\ Trong chuỗi Java phải viết "\\d" Dùng \\

💼 Interview Corner

1. What is a lambda expression and where do you use it in Selenium?

  • 🇻🇳 Dịch: Lambda là gì, dùng ở đâu trong Selenium?
  • Suggested answer (EN): A lambda is a concise anonymous function. In Selenium it is used in custom waits such as wait.until(d -> d.findElements(by).size() > n) and in streams over elements.
  • Giải thích (VI): Biến bắt vào lambda phải effectively final.
  • Follow-up: Why must captured variables be final?

2. Why use ThreadLocal for parallel tests?

  • 🇻🇳 Dịch: Vì sao ThreadLocal<WebDriver> cho test song song?
  • Suggested answer (EN): Each thread needs its own driver; a shared static driver would be overwritten by other threads. ThreadLocal gives each thread its own value, and I call remove() in teardown.
  • Giải thích (VI): Chỉ cần khi chạy song song.
  • Follow-up: What happens if you forget remove()?

📌 Lesson Summary

Kiến thức cần nhớ

  • Generics bắt lỗi kiểu lúc biên dịch
  • Lambda = hàm ẩn danh; wait.until(...) dùng Function
  • Annotation là metadata mà framework đọc bằng reflection

Method / lệnh cần biết

  • Predicate, Function, Supplier, stream().filter/map/toList(), ClassName::method, ThreadLocal.get/set/remove

Điểm dễ nhầm lẫn

  • Lambda ≠ method reference (cú pháp viết gọn)
  • List<int> không hợp lệ
  • static WebDriver ≠ ThreadLocal<WebDriver>

java
import java.util.function.Supplier;

public class Main {
    static int calls = 0;

    static int waitUntil(Supplier<Boolean> cond, int maxPolls) {
        for (int i = 1; i <= maxPolls; i++) {
            if (cond.get()) return i;
        }
        throw new IllegalStateException("Timeout");
    }

    public static void main(String[] args) {
        int polls = waitUntil(() -> ++calls >= 2, 5);
        System.out.println("đạt ở lần " + polls);
    }
}
output
đạt ở lần 2
