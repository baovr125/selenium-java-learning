7. Kiểm chứng

Môi trường: Windows 11, JDK 25.0.1 (biên dịch --release 21), Maven 3.9.16 qua Wrapper, Selenium 4.52.0, TestNG 7.10.2, Git 2.49.0, Chrome.

Việc kiểm tra Kết quả
Ví dụ Java của Phase 1 (biên dịch + chạy + so khớp khối output) 93/93 đạt (57 ví dụ trong bài + 36 lời giải bài tập). Trong quá trình viết đã bắt được 2 lỗi và sửa: printf("%.1f") ra 75,5 thay vì 75.5 trên máy locale Việt (đã thêm Locale.US và ghi chú bẫy locale vào bài), và một con số độ dài chuỗi
Lời giải Selenium/TestNG (biên dịch với classpath thật của dự án) 56/56 đạt (không chạy)
Chạy thật 36 lời giải Selenium (trích tự động thành một lớp test, chạy trên site demo) 28 đạt. 7 không chạy độc lập vì là minh hoạ cần ngữ cảnh (locator/file giả định, hoặc cố ý ném NoSuchElementException). 1 lỗi thật phát hiện: cuộn /infinite_scroll cho scrollY = 0 vì trang ban đầu (scrollHeight 707) thấp hơn cửa sổ (innerHeight 889) → bài tập được đổi sang /floating_menu (đo được scrollY = 4465) và ghi chú lý do
Đo thời gian Implicit Wait findElements rỗng: 17 ms (không implicit) vs 3050 ms (implicit 3 s) — số đo thật được dùng trong bài
Git (repo thử, Windows) Đã chạy: commit, check-ignore, conflict thật ở pom.xml, merge/rebase, --abort. Phát hiện: mvnw commit với mode 100644; cảnh báo LF→CRLF. Đã kiểm chứng cách sửa (update-index --chmod=+x → 100755; .gitattributes → attr/text eol=lf)
Liên kết Markdown (đường dẫn + anchor, tất cả file) Xem kết quả cuối mục này
Cấu trúc thư mục, file rỗng Không có file rỗng/ngắn dưới ngưỡng
Nội dung Maven Giữ nguyên bản đã kiểm chứng (lệnh -version, compile, test-compile, clean, package -DskipTests, dependency:tree, -Dtest=...)

Chưa kiểm chứng: ./mvnw trên Linux/macOS; ví dụ CI (GitHub Actions); maven-failsafe-plugin; Maven Profile; Log4j2/Extent/Allure; lệnh Git trên máy khác Windows. W3Schools: chỉ đọc được mục lục.
