Dự án đang dùng gì? (đã xác minh)

Mục Giá trị
Maven (qua Wrapper) 3.9.16
Wrapper 3.3.4, distributionType=only-script (không có maven-wrapper.jar, không có distributionSha256Sum)
Local Repository .mvn/repository (đặt bởi .mvn/maven.config)
Plugin maven-compiler-plugin 3.13.0, maven-surefire-plugin 3.5.2 (Failsafe: chưa dùng)
Dependency selenium-java 4.52.0, testng 7.10.2 (scope test)

Bảng lệnh nhanh (Windows PowerShell)

Mục đích Lệnh
Phiên bản .\mvnw.cmd -version
Xoá build cũ .\mvnw.cmd clean
Biên dịch code test .\mvnw.cmd test-compile
Chạy toàn bộ test (theo testng.xml) .\mvnw.cmd test
Sạch + test .\mvnw.cmd clean test
Một class .\mvnw.cmd test "-Dtest=Exercise01_LoginTest"
Một method .\mvnw.cmd test "-Dtest=Exercise01_LoginTest#testLoginSuccess"
Cây dependency .\mvnw.cmd dependency:tree
Đóng gói (có chạy test) .\mvnw.cmd package

Linux/macOS: ./mvnw (cần chmod +x).
