Khởi tạo dự án Selenium Java + Maven + TestNG

🧭 Phase 2 · Maven and Project Management · Chapter 09 · Mức ưu tiên: Essential ⬅️ Java: File Handling, Properties và Configuration · ➡️ Maven Fundamentals

Hướng dẫn dựng một dự án mới từ đầu (khuyến nghị đặt ở thư mục riêng, ví dụ B:\Fresher\SeleniumLab) để thực hành, không làm trên dự án gốc Selenium1. Liên quan: Trước: Môi trường · Maven POM · practice/01

Dự án Selenium1 chính là kết quả của quy trình này — hãy đối chiếu từng bước với nó.

🎯 Learning Objectives

Sau bài này bạn có thể:

  • Dựng cấu trúc thư mục Maven chuẩn cho dự án Selenium
  • Viết pom.xml tối thiểu và BaseTest đầu tiên
  • Chạy test đầu tiên bằng mvnw

📋 Prerequisites

  • Environment Setup
  • Java OOP Concepts

1. Chọn cách khởi tạo

Cách Khi dùng
A. Tự tạo thư mục + pom.xml (hướng dẫn dưới đây) Học để hiểu từng phần
B. mvn archetype:generate Cần Maven cài sẵn hoặc dùng mvnw đã có
C. Tạo qua IDE (New Maven Project) Nhanh, nhưng dễ sinh cấu hình thừa
D. Sao chép khung từ Selenium1 Nhóm đã chuẩn hoá

2. Cấu trúc thư mục chuẩn Maven

Maven theo nguyên tắc Convention over Configuration: đặt file đúng chỗ thì không cần cấu hình.

text
SeleniumLab/
├── pom.xml
└── src/
    ├── main/java/        # Mã sản phẩm (dự án Selenium1 để trống/không có)
    └── test/
        ├── java/         # Mã kiểm thử  ← code Selenium nằm ở đây
        └── resources/    # Tài nguyên cho test (config.properties, testdata.json)

🧩 Selenium1 chỉ có src/test/java (packages base, tests). Vì không có src/main, phase compile báo Nothing to compile; phải dùng test-compile/test.

Tạo nhanh bằng PowerShell:

powershell
mkdir SeleniumLab; cd SeleniumLab
mkdir src\test\java\base, src\test\java\tests, src\test\resources

3. Viết pom.xml

Bản tối thiểu tương đương Selenium1 (đã rút gọn comment):

xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.fresher</groupId>
    <artifactId>SeleniumLab</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <maven.compiler.release>21</maven.compiler.release>
        <selenium.version>4.52.0</selenium.version>
        <testng.version>7.10.2</testng.version>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.seleniumhq.selenium</groupId>
            <artifactId>selenium-java</artifactId>
            <version>${selenium.version}</version>
            <scope>test</scope>
        </dependency>
        <dependency>
            <groupId>org.testng</groupId>
            <artifactId>testng</artifactId>
            <version>${testng.version}</version>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.13.0</version>
            </plugin>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-surefire-plugin</artifactId>
                <version>3.5.2</version>
            </plugin>
        </plugins>
    </build>
</project>

Khác với Selenium1: ở đây bỏ suiteXmlFiles để Surefire tự quét class có đuôi *Test. Muốn dùng testng.xml như dự án gốc, thêm <configuration><suiteXmlFiles>.... Giải thích từng thẻ: maven/02.

4. Thêm Maven Wrapper cho dự án mới

Nếu máy có Maven (mvn -version chạy được):

powershell
mvn wrapper:wrapper -Dmaven=3.9.16 -Dtype=only-script

Lệnh tạo mvnw, mvnw.cmd, .mvn/wrapper/maven-wrapper.properties. Nếu không có Maven, cách đơn giản nhất là sao chép 3 mục này (mvnw, mvnw.cmd, thư mục .mvn/wrapper) từ Selenium1 sang. Chi tiết maven/03.

Lưu ý: tham số -Dtype=only-script tạo kiểu giống dự án gốc (không có maven-wrapper.jar). Hãy kiểm tra .mvn/wrapper/maven-wrapper.properties sau khi tạo để chắc distributionType=only-script.

5. Viết BaseTest

src/test/java/base/BaseTest.java (giống dự án gốc, rút gọn):

java
package base;

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.support.ui.WebDriverWait;
import org.testng.annotations.AfterMethod;
import org.testng.annotations.BeforeMethod;

import java.time.Duration;

public class BaseTest {
    protected WebDriver driver;
    protected WebDriverWait wait;

    @BeforeMethod
    public void setup() {
        driver = new ChromeDriver();
        driver.manage().window().maximize();
        driver.manage().timeouts().pageLoadTimeout(Duration.ofSeconds(30));
        wait = new WebDriverWait(driver, Duration.ofSeconds(15));
    }

    @AfterMethod
    public void tearDown() {
        if (driver != null) {
            driver.quit();
        }
    }
}

6. Viết test đầu tiên

src/test/java/tests/HomePageTest.java:

java
package tests;

import base.BaseTest;
import org.testng.Assert;
import org.testng.annotations.Test;

public class HomePageTest extends BaseTest {

    @Test
    public void shouldOpenHomePage() {
        driver.get("https://the-internet.herokuapp.com/");
        Assert.assertEquals(driver.getTitle(), "The Internet");
    }
}

7. Chạy

powershell
.\mvnw.cmd test

Kết quả mong đợi:

text
[INFO] Running tests.HomePageTest
[INFO] Tests run: 1, Failures: 0, Errors: 0, Skipped: 0
[INFO] BUILD SUCCESS

Chạy riêng class:

powershell
.\mvnw.cmd test "-Dtest=HomePageTest"

⚠️ Trong PowerShell nên đặt -D... trong dấu nháy kép; PowerShell 5.1 có thể tách tham số tại dấu chấm (README của dự án cũng cảnh báo điều này trong run-test.ps1).

9. Kiểm tra cấu hình bằng Maven

powershell
.\mvnw.cmd validate                      # pom hợp lệ?
.\mvnw.cmd dependency:tree               # cây thư viện
.\mvnw.cmd help:effective-pom            # pom sau khi gộp mặc định

10. Lỗi hay gặp khi khởi tạo

Lỗi Nguyên nhân Cách xử lý
No tests were executed / Tests run: 0 Class test không tên *Test hoặc *Tests/Test*, hoặc sai thư mục Đặt trong src/test/java, đặt tên theo quy ước
package org.openqa.selenium does not exist Dependency scope sai hoặc pom.xml chưa reload Kiểm tra <scope>test</scope> và code nằm trong src/test, không phải src/main
cannot find symbol WebDriverWait Thiếu selenium-support Đã nằm trong selenium-java (transitive); kiểm tra dependency
Test không chạy dù có @Test Quên extends BaseTest hoặc import nhầm org.junit.Test Dùng org.testng.annotations.Test
FileNotFoundException testng.xml Khai báo suiteXmlFile nhưng file không có Tạo file hoặc bỏ cấu hình

⚠️ Scope test cho selenium-java: chỉ đúng khi toàn bộ code Selenium nằm trong src/test. Nếu bạn đặt BasePage/DriverFactory trong src/main/java, phải để scope compile (mặc định), nếu không sẽ lỗi biên dịch.

✅ Knowledge Check

Câu 1. Mã kiểm thử Maven đặt ở thư mục nào?

  • A. src/main/java
  • B. src/test/java
  • C. target
  • D. resources
Xem đáp án

Đáp án: B. Code test: src/test/java; code sản phẩm: src/main/java.

Câu 2. Vì sao .\mvnw.cmd compile ở dự án Selenium1 báo Nothing to compile?

  • A. Lỗi cấu hình
  • B. Không có src/main (mọi code ở src/test)
  • C. Thiếu JDK
  • D. Do TestNG
Xem đáp án

Đáp án: B. compile chỉ biên dịch src/main; dùng test-compile/test.

Câu 3. Class test phải đặt tên thế nào để Surefire tự quét (khi không dùng suite XML)?

  • A. *Test/Test*/*Tests
  • B. Bất kỳ
  • C. Phải kết thúc Main
  • D. *Page
Xem đáp án

Đáp án: A. Mẫu mặc định: **/Test*.java, **/*Test.java, **/*Tests.java, **/*TestCase.java.

💼 Interview Corner

1. Explain the standard Maven directory layout.

  • 🇻🇳 Dịch: Giải thích cấu trúc thư mục chuẩn của Maven.
  • Suggested answer (EN): src/main/java for production code, src/test/java for tests, src/test/resources for test resources, and target for generated output; following the convention means no extra configuration.
  • Giải thích (VI): Convention over configuration.
  • Follow-up: Where would Page Objects go?

2. Why can a test-only project have no src/main?

  • 🇻🇳 Dịch: Vì sao dự án chỉ có test không cần src/main?
  • Suggested answer (EN): Maven does not require it; all framework and test code can live in src/test/java with test-scoped dependencies, which is how Selenium1 is organized.
  • Giải thích (VI): Hệ quả: compile không làm gì.
  • Follow-up: What breaks if Selenium is test-scoped but used in src/main?

📌 Lesson Summary

Kiến thức cần nhớ

  • Cấu trúc Maven chuẩn
  • pom.xml tối thiểu: GAV, properties, dependencies, plugins
  • Test chạy bằng mvnw test

Method / lệnh cần biết

  • validate, dependency:tree, test, -Dtest=

Điểm dễ nhầm lẫn

  • src/main ≠ src/test
  • scope test chỉ dùng được trong src/test
  • Tên class phải khớp mẫu quét
