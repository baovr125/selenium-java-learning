1. Maven Wrapper là gì?

1.1. Định nghĩa

📘 Maven Wrapper là một bộ script nhỏ nằm trong chính dự án (mvnw, mvnw.cmd, cùng thư mục .mvn/wrapper). Khi bạn chạy mvnw, script sẽ:

  1. Đọc xem dự án yêu cầu phiên bản Maven nào;
  2. Nếu máy chưa có đúng phiên bản đó thì tự tải về;
  3. Rồi chạy Maven đó với các tham số bạn truyền.

Nói ngắn gọn: "Wrapper = người đưa đúng Maven cho bạn, không cần bạn cài Maven."

1.2. Tại sao cần?

Hãy hình dung nhóm 4 người, mỗi người một kiểu:

Thành viên Maven trên máy
An Chưa cài
Bình 3.6.3 (cài từ lâu)
Chi 3.9.9
CI server 3.8.1

Dự án cần tính năng/hành vi của Maven 3.9.x. Kết quả: "máy tôi chạy được, máy bạn thì không" (works on my machine). Với Wrapper, mọi người đều chạy qua mvnw ⇒ cùng Maven 3.9.16, cấu hình nằm trong Git.

1.3. Giải quyết vấn đề gì khi làm việc nhóm?

Vấn đề Wrapper giải quyết thế nào
Thành viên mới chưa cài Maven Clone xong chạy mvnw ngay
Mỗi người một phiên bản Maven Phiên bản khoá trong maven-wrapper.properties (được commit)
CI phải cài Maven CI chỉ cần JDK + ./mvnw
Nâng cấp Maven Sửa 1 dòng distributionUrl, commit, mọi người nhận bản mới khi pull
Hướng dẫn onboarding dài dòng Chỉ còn "cài JDK, chạy mvnw"

1.4. Maven cài toàn hệ thống vs Maven Wrapper

Tiêu chí Maven cài sẵn (mvn) Maven Wrapper (mvnw)
Cài đặt Tự tải, giải nén, đặt PATH Không cần; tự tải khi chạy lần đầu
Phiên bản Tuỳ máy mỗi người Cố định theo dự án
Lệnh mvn test .\mvnw.cmd test / ./mvnw test
Dùng cho nhiều dự án Một bản cho tất cả Mỗi dự án có thể một bản (lưu cache chung ở ~/.m2/wrapper/dists)
Cần Internet lần đầu Chỉ khi tải thư viện Cần thêm để tải Maven
Cần JDK ✅ ✅ (Wrapper không thay thế JDK)

1.5. Vì sao dự án chạy Maven mà không cần cài Maven?

Đã kiểm chứng trên máy này: lệnh mvn -version báo command not found, nhưng .\mvnw.cmd -version in ra Apache Maven 3.9.16, Maven home: C:\Users\<tên>\.m2\wrapper\dists\apache-maven-3.9.16\0daed3be.... Tức Maven nằm trong thư mục cache của Wrapper chứ không phải trong PATH.

Cấu trúc thật của dự án (kiểm tra bằng Glob):

text

├── mvnw.cmd                               ← script batch+PowerShell (Windows)          8.481 byte

    ├── wrapper/
    │   └── maven-wrapper.properties       ← cấu hình phiên bản (3 dòng)
    ├── maven.config                       ← (không thuộc Wrapper) tham số Maven mặc định
    └── repository/                        ← (không thuộc Wrapper) Local Repository riêng, gitignore
File Vai trò Có trong dự án?
mvnw Script sh cho Linux, macOS (và Git Bash/WSL trên Windows) ✅
mvnw.cmd Script cho Windows (cmd/PowerShell). Là file .cmd có đoạn PowerShell nhúng bên trong ✅
.mvn/wrapper/maven-wrapper.properties Nói tải Maven nào, từ đâu ✅

.mvn/maven.config Tham số dòng lệnh Maven mặc định (mỗi lần chạy tự thêm) ✅ (không thuộc Wrapper)
.mvn/jvm.config Tham số JVM cho Maven (-Xmx...) ❌

2.1. maven-wrapper.properties — nội dung thật

properties
wrapperVersion=3.3.4
distributionType=only-script
distributionUrl=https://repo.maven.apache.org/maven2/org/apache/maven/apache-maven/3.9.16/apache-maven-3.9.16-bin.zip
Khoá Ý nghĩa
wrapperVersion Phiên bản của chính Maven Wrapper (script mvnw) — khác phiên bản Maven!
distributionType only-script = chỉ dùng script, không cần maven-wrapper.jar; các kiểu khác (source, bin) tuỳ phiên bản wrapper.
distributionUrl URL tải Maven. Số 3.9.16 trong URL chính là phiên bản Maven mà cả nhóm dùng
distributionSha256Sum (không khai báo) Nếu có, Wrapper kiểm tra checksum bản tải về
wrapperSha256Sum (không khai báo) Chỉ dùng với kiểu có maven-wrapper.jar

🧩 Hai con số dễ nhầm:

Giá trị Nghĩa
wrapperVersion 3.3.4 Phiên bản script wrapper
số trong distributionUrl 3.9.16 Phiên bản Maven thực sự chạy

2.2. mvnw và mvnw.cmd khác nhau thế nào?

mvnw mvnw.cmd
Hệ điều hành Linux, macOS, Git Bash, WSL Windows (cmd, PowerShell)
Ngôn ngữ POSIX sh Batch + PowerShell nhúng
Cách tải Maven wget, nếu không có thì curl, nếu không có cả hai thì chạy mã Java nguồn (khi đó mới cần JAVA_HOME) PowerShell System.Net.WebClient
Giải nén unzip, nếu thiếu thì tar PowerShell Expand-Archive
Gọi Maven exec "$MAVEN_HOME/bin/mvn" chạy "$MAVEN_HOME\bin\mvn.cmd" %*
Quyền thực thi Cần bit x (chmod +x mvnw) Không áp dụng

Dự án hiện lưu mvnw với quyền -rwxr-xr-x (có bit thực thi) trên máy Windows/Git Bash. Khi commit bằng Git trên Windows, cần chắc Git ghi nhận bit này — xem Maven Wrapper và Git.

3. Wrapper xác định và tải Maven như thế nào?

Luồng thực thi của mvnw.cmd (đọc từ script thật, version 3.3.4):

text
.\mvnw.cmd test
   │
   ├─1. Batch khởi động PowerShell và chạy chính nội dung file mvnw.cmd
   ├─2. Đọc distributionUrl trong .mvn/wrapper/maven-wrapper.properties
   ├─3. Tính thư mục đích:
   │      %USERPROFILE%\.m2\wrapper\dists\apache-maven-3.9.16\<SHA-256 của distributionUrl>
   ├─4. Thư mục đó đã có Maven chưa?
   │      ├─ CÓ  → bỏ qua tải
   │      └─ CHƯA → tải .zip (WebClient) → (nếu có distributionSha256Sum thì kiểm tra) → giải nén → di chuyển vào thư mục đích
   └─5. Chạy  <thư mục đích>\bin\mvn.cmd  với đúng tham số bạn đưa vào  (ví dụ: test)

Điểm đáng chú ý rút từ script:

  • Thư mục cache chung của cả máy (~/.m2/wrapper/dists), không nằm trong dự án ⇒ nhiều dự án cùng phiên bản dùng chung, tải một lần.
  • Phần <hash> là SHA-256 của distributionUrl ⇒ đổi URL (ví dụ đổi phiên bản) sẽ ra thư mục mới và tải bản mới.
  • Biến môi trường tuỳ chọn (đọc từ phần chú thích đầu script):
Biến Tác dụng
MVNW_REPOURL Đổi gốc URL tải Maven (dùng mirror nội bộ công ty)
MVNW_USERNAME, MVNW_PASSWORD Xác thực khi tải
MVNW_VERBOSE=true In chi tiết quá trình tải (rất hữu ích khi debug)
MAVEN_USER_HOME (bản mvnw sh) Đổi vị trí ~/.m2
JAVA_HOME Chọn JDK. Chỉ bắt buộc khi mvnw (sh) phải tải bằng mã Java

Sau khi Maven chạy, Maven đọc tiếp .mvn/maven.config (⇒ -Dmaven.repo.local=.mvn/repository) và dùng pom.xml để giải quyết thư viện.

Vì sao Wrapper không "cài" Maven vào PATH? Nó không cần. Nó trực tiếp gọi file mvn.cmd trong thư mục cache. Vì vậy mvn -version vẫn lỗi, còn mvnw -version thì chạy được.

4. Dùng mvnw trên Windows

Mở PowerShell tại thư mục chứa pom.xml (B:\Fresher\Selenium1). Phải có .\ vì PowerShell không chạy lệnh ở thư mục hiện tại nếu thiếu tiền tố.

Lệnh Giải thích Kết quả mong đợi (-version, compile, test-compile, clean, package -DskipTests, test -Dtest=... đã chạy thật; test toàn bộ lấy từ báo cáo lần chạy gần nhất)
.\mvnw.cmd -version In phiên bản Maven + Java + OS. Lần đầu sẽ tải Maven Apache Maven 3.9.16, Java version: 25.0.1, Maven home: C:\Users\...\.m2\wrapper\dists\...
.\mvnw.cmd clean Xoá thư mục target/ --- clean:3.2.0:clean --- rồi BUILD SUCCESS. Lần đầu phải có mạng để tải maven-clean-plugin 3.2.0 (đã tái hiện: chạy -o khi chưa tải sẽ BUILD FAILURE ... has not been downloaded from it before)
.\mvnw.cmd compile Biên dịch src/main Dự án chỉ có src/test ⇒ Nothing to compile - all classes are up to date + BUILD SUCCESS
.\mvnw.cmd test-compile Biên dịch cả src/test compiler:testCompile ... BUILD SUCCESS
.\mvnw.cmd test compile + test-compile + chạy test (Surefire theo testng.xml) Tests run: 10, Failures: 0, Errors: 0, Skipped: 0 + BUILD SUCCESS (mở Chrome 10 lần, ~90 giây)
.\mvnw.cmd clean test Xoá target/ rồi chạy toàn bộ từ đầu Giống trên, nhưng buộc biên dịch lại
.\mvnw.cmd package Chạy đến phase package (sau test) rồi tạo file jar Test chạy trước; sau đó --- jar:3.5.0:jar ---, cảnh báo JAR will be empty - no content was marked for inclusion! và sinh target/SeleniumPractice-1.0-SNAPSHOT.jar (~2 KB, vì không có src/main). Đã chạy thật với -DskipTests

⚠️ package chạy cả test (vì test nằm trước package trong lifecycle). Muốn bỏ qua test: -DskipTests. Xem 04.

Một số mẹo cho PowerShell:

powershell
.\mvnw.cmd test "-Dtest=Exercise01_LoginTest"      # đặt -D trong nháy kép
.\mvnw.cmd -q test                                  # -q: ít log
.\mvnw.cmd -o test-compile                          # -o: offline (không dùng mạng)
.\mvnw.cmd -B test                                  # -B: batch mode, log gọn cho CI
$env:MVNW_VERBOSE="true"; .\mvnw.cmd -version       # xem chi tiết wrapper

5. Dùng mvnw trên Linux/macOS

bash
chmod +x mvnw          # chỉ cần 1 lần nếu file chưa có quyền thực thi
./mvnw -version
./mvnw clean
./mvnw compile
./mvnw test
./mvnw clean test
./mvnw package

Khác biệt Windows ↔ Linux/macOS

Điểm Windows Linux/macOS
Lệnh .\mvnw.cmd ./mvnw
Quyền chạy Không cần Cần chmod +x mvnw; không có thì lỗi Permission denied
Nháy tham số -D Nên dùng "..." trong PowerShell Không bắt buộc
Xuống dòng trong script ` (PowerShell) \
Biến môi trường tạm $env:JAVA_HOME="..." export JAVA_HOME=...
Dấu phân cách classpath ; :
Thư mục cache Maven C:\Users\<tên>\.m2\wrapper\dists ~/.m2/wrapper/dists
Cần công cụ tải PowerShell (có sẵn) wget hoặc curl (+ unzip hoặc tar)
Kết thúc dòng file Không quan trọng LF bắt buộc cho mvnw; nếu bị chuyển thành CRLF sẽ lỗi /bin/sh^M: bad interpreter

Trên Windows có thể chạy ./mvnw trong Git Bash (file mvnw của dự án có quyền -rwxr-xr-x trong Git Bash; tài liệu này chưa chạy thử ./mvnw thật trên Linux/macOS — các lệnh ở mục 5 dựa trên đọc script mvnw và hành vi chuẩn của Wrapper 3.3.4).

💼 Interview Corner

1. What is Maven Wrapper and what problem does it solve?

  • 🇻🇳 Dịch: Maven Wrapper là gì, giải quyết vấn đề gì?
  • Suggested answer (EN): It is a set of scripts in the project that download and run the exact Maven version the project specifies, so everybody and CI use the same Maven without installing it.
  • Giải thích (VI): Tránh "máy tôi chạy được".
  • Follow-up: Where is the Maven stored?

2. Maven vs Maven Wrapper?

  • 🇻🇳 Dịch: Maven khác Maven Wrapper?
  • Suggested answer (EN): Maven is the build tool; the wrapper is a launcher that ensures the pinned Maven version exists and then calls it. The wrapper does not replace the JDK.
  • Giải thích (VI): Phiên bản Maven khoá trong file properties được commit.
  • Follow-up: How to upgrade Maven for the team?

📌 Lesson Summary

Kiến thức cần nhớ

  • Wrapper = script trong dự án, tải đúng Maven rồi chạy
  • Maven lưu ở ~/.m2/wrapper/dists/...
  • Windows .\mvnw.cmd, Linux/macOS ./mvnw (+ chmod +x)

Method / lệnh cần biết

  • .\mvnw.cmd -version/test/clean, MVNW_VERBOSE, MVNW_REPOURL

Điểm dễ nhầm lẫn

  • wrapperVersion ≠ phiên bản Maven
  • Wrapper ≠ JDK
  • mvn (cài sẵn) ≠ mvnw (qua Wrapper)
