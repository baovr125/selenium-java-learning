Cách ôn

  1. Đọc câu hỏi tiếng Anh, tự trả lời thành tiếng bằng tiếng Anh trước khi xem đáp án.
  2. Đối chiếu câu mẫu; đọc giải thích tiếng Việt để hiểu bản chất, không học thuộc.
  3. Luôn chuẩn bị một ví dụ từ dự án Selenium1 (có đường dẫn file) — thuyết phục hơn lý thuyết.
  4. Tập trả lời câu hỏi đào sâu.

Tự giới thiệu dự án (mẫu 30 giây)

"I built a Selenium practice project with Java 21, Selenium 4.52, TestNG and Maven. It covers 10 UI exercises on the-internet.herokuapp.com — login, checkboxes, tables, dropdowns, hover, dynamic elements, infinite scroll, modal and drag and drop. I use a shared BaseTest for the driver lifecycle, Explicit Waits only, and the Maven Wrapper so the project runs without installing Maven. I run the suite with mvnw.cmd clean test and the 10 tests pass. Next I plan to add Page Object Model, screenshots on failure and data-driven tests."
