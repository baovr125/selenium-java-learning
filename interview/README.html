Interview Preparation — Junior Automation Test Engineer

Quay lại README · Roadmap · Theo dõi ôn tập: progress/interview-preparation.md Đối tượng: Fresher / Junior Automation Tester (Selenium + Java + Maven + TestNG + Git). Học lý thuyết phỏng vấn trước, thực hành bổ sung sau: toàn bộ phần này đọc và luyện nói được không cần chạy code.

Ba lớp phỏng vấn

  1. Interview Corner — 2 câu ở cuối mỗi bài học (120 câu), bám sát nội dung bài vừa học.
  2. Bộ câu hỏi theo chủ đề — các file dưới đây, ôn tổng hợp trước ngày phỏng vấn (185 câu/tình huống).
  3. Tài liệu ôn nhanh — interview-cheatsheet.md: tóm tắt lý thuyết một trang.

Sau đó: mỗi ngày 5 câu ngẫu nhiên bằng tiếng Anh; tuần 1 mock. Khi học thực hành sau này, quay lại các câu đã trả lời và kiểm chứng bằng code.

Cách ôn

  1. Đọc câu hỏi tiếng Anh, tự trả lời thành tiếng bằng tiếng Anh trước khi xem đáp án.
  2. Đối chiếu câu mẫu; đọc giải thích tiếng Việt để hiểu bản chất, không học thuộc.
  3. Luôn chuẩn bị một ví dụ từ dự án Selenium1 (có đường dẫn file) — thuyết phục hơn lý thuyết.
  4. Tập trả lời câu hỏi đào sâu.
  5. Câu nào chưa nắm, ghi vào cột "Câu chưa chắc" của interview-preparation.md.

Tự giới thiệu dự án (mẫu 30 giây)

"I built a Selenium practice project with Java 21, Selenium 4.52, TestNG and Maven. It covers 10 UI exercises on a public demo website — login, checkboxes, tables, dropdowns, hover, dynamic elements, infinite scroll, modal and drag and drop. I use a shared BaseTest for the driver lifecycle, Explicit Waits only, and the Maven Wrapper so the project runs without installing Maven. I run the suite with mvnw.cmd clean test and the 10 tests pass. Next I plan to add Page Object Model, screenshots on failure and data-driven tests."

(Mọi chi tiết khớp dự án thật.) Mẫu tự giới thiệu đầy đủ (kèm nền tảng testing/API/SQL, kế hoạch học Playwright) ở behavioral-and-english-interview.md.
