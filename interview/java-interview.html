Phần A. Java trong Selenium (Q1–Q10)

Q1. Why do we declare WebDriver driver = new ChromeDriver() and not ChromeDriver driver = ...?

Dịch: Vì sao khai báo kiểu WebDriver?

Sample answer: WebDriver is an interface, so this uses polymorphism: my code depends on the interface and I can switch to FirefoxDriver by changing one line. It also keeps the code independent of browser-specific methods.

Giải thích: Lập trình hướng interface. Khi cần API riêng (ví dụ DevTools) mới dùng class cụ thể.

Ví dụ: protected WebDriver driver; trong BaseTest.

Đào sâu: How do you use JavaScript Executor then? → ép kiểu (JavascriptExecutor) driver (Ex7).

Q2. What is inheritance and how is it used in your framework?

Dịch: Kế thừa là gì, dùng thế nào?

Sample answer: Inheritance lets a class reuse the fields and methods of a parent class. All my test classes extend BaseTest, which owns the driver and wait and the setup and teardown methods, so I do not repeat that code.

Giải thích: Quan hệ "là một". TestNG tự gọi @BeforeMethod kế thừa.

Ví dụ: Exercise01_LoginTest extends BaseTest.

Đào sâu: Composition vs inheritance? → ưu tiên composition cho component (Header) trong Page.

Q3. What is the difference between an interface and an abstract class?

Dịch: Interface khác abstract class?

Sample answer: An interface defines a contract with no state; a class can implement many. An abstract class can have fields, constructors and partial implementation, but a class can extend only one. WebDriver is an interface; BasePage is often an abstract class.

Giải thích: Interface = "làm được gì"; abstract class = khung chung.

Ví dụ: ChromeDriver implement cả WebDriver và JavascriptExecutor.

Đào sâu: Can an interface have default methods? → Có (Java 8+).

Q4. Explain access modifiers and why driver is protected.

Dịch: Access modifier; vì sao driver là protected?

Sample answer: public is visible everywhere, protected to the package and subclasses, default to the package, private to the class. driver is protected so subclasses in other packages, like tests, can use it without exposing it publicly.

Giải thích: BaseTest ở package base, test ở package tests ⇒ cần protected (default sẽ không truy cập được).

Ví dụ: private static final String LOGIN_URL chỉ dùng trong class.

Đào sâu: What if it were private? → lỗi biên dịch ở class con.

Q5. What is the difference between static and non-static members?

Dịch: static khác non-static?

Sample answer: Static members belong to the class and are shared; non-static belong to each object. A static WebDriver shared between tests is dangerous in parallel runs because tests overwrite each other's driver. I use an instance field, or ThreadLocal for parallel execution.

Giải thích: main() là static nên phải tạo đối tượng rồi gọi setup().

Ví dụ: Exercise01_LoginTest test = new Exercise01_LoginTest(); test.setup(); trong main.

Đào sâu: What is ThreadLocal?

Q6. What is the difference between List, Set and Map? Give Selenium examples.

Dịch: List, Set, Map khác nhau? Ví dụ trong Selenium.

Sample answer: List is ordered and allows duplicates, like the result of findElements. Set has no duplicates, like getWindowHandles(). Map stores key-value pairs, such as form data or configuration.

Giải thích: findElements trả list rỗng khi không thấy; Set không đảm bảo thứ tự.

Ví dụ: Ex3 dùng List<String> so sánh cả hàng của bảng; Ex2 dùng List<WebElement>.

Đào sâu: How do you get the text of all elements? → stream map(WebElement::getText).

Q7. What is exception handling and when would you catch an exception in a test?

Dịch: Xử lý exception; khi nào catch trong test?

Sample answer: I use try/catch/finally. Selenium exceptions are unchecked. I catch only for a clear purpose, such as an optional element (a cookie banner), a limited retry for stale elements, or cleanup in finally. I never swallow exceptions silently, since that makes tests pass falsely.

Giải thích: finally luôn chạy; checked vs unchecked.

Ví dụ: main() trong Exercise: try { setup(); test(); } finally { tearDown(); }.

Đào sâu: Checked vs unchecked?

Q8. What is a lambda expression and where do you use it in Selenium?

Dịch: Lambda là gì, dùng ở đâu?

Sample answer: A lambda is a short anonymous function. In Selenium I use it for custom waits, like wait.until(d -> d.findElements(by).size() > n), and for streams over elements. Variables captured must be effectively final.

Giải thích: until nhận Function<WebDriver, V>.

Ví dụ: Ex7 wait.until(d -> { scrollToBottom(jsExecutor); return d.findElements(...).size() > countBeforeScroll; }).

Đào sâu: Why must the captured variable be final?

Q9. What are generics? Give an example in Selenium.

Dịch: Generics là gì? Ví dụ.

Sample answer: Generics let classes and methods work with type parameters and give compile-time type safety. Examples are List<WebElement> and Wait<WebDriver>; also until returns a type depending on the condition: a WebElement for visibility, a Boolean for invisibility.

Giải thích: WebDriverWait extends FluentWait<WebDriver>.

Ví dụ: Boolean closed = wait.until(ExpectedConditions.invisibilityOfElementLocated(By.id("modal"))); (Ex8).

Đào sâu: What is the diamond operator?

Q10. What are constructors and how are they used in Page Objects?

Dịch: Constructor; dùng thế nào trong Page Object?

Sample answer: A constructor initializes an object. In a Page Object the constructor receives the WebDriver and stores it, so the page can interact with the browser. this.driver = driver assigns the parameter to the field.

Giải thích: Constructor không có kiểu trả về. Dùng super(driver) để truyền lên BasePage.

Ví dụ: public LoginPage(WebDriver driver) { super(driver); }.

Đào sâu: What if the parent has no default constructor? → class con phải gọi super(...) tường minh.

Phần B. Java bản chất (Q11–Q31)

Các câu thường bị hỏi trực tiếp ở vòng phỏng vấn Junior, ngoài việc "dùng thế nào trong Selenium". Học thuộc ý chính, không học thuộc câu chữ. Q27–Q29 là câu viết code tại chỗ.

Q11. What is the difference between JDK, JRE and JVM?

Dịch: JDK, JRE, JVM khác nhau thế nào?

Sample answer: The JVM is the virtual machine that runs Java bytecode, which makes Java platform independent. The JRE is the JVM plus the standard libraries needed to run a program. The JDK is the JRE plus development tools such as the compiler javac. To compile and run my tests I need a JDK.

Giải thích: JDK ⊃ JRE ⊃ JVM. Máy dev cần JDK; môi trường chỉ chạy mới cần runtime.

Ví dụ: pom.xml đặt maven.compiler.release=21 ⇒ cần JDK 21 trở lên để build.

Đào sâu: What is bytecode and who creates it? → javac biên dịch .java thành .class (bytecode) cho JVM chạy.

Q12. What is the difference between == and equals()?

Dịch: == khác equals()?

Sample answer: For primitives == compares values. For objects == compares references, meaning whether both variables point to the same object. equals() compares logical content when a class overrides it, as String does. The default Object.equals() behaves like ==. So I compare strings with equals(), and new String("a") == "a" is false while new String("a").equals("a") is true.

Giải thích: Lỗi kinh điển của người mới: dùng == cho chuỗi. Chuỗi literal giống nhau có thể trùng tham chiếu do String pool nên đôi khi == "đúng ngẫu nhiên".

Ví dụ: actualMessage.contains(...)/equals(...) trong Exercise01; Assert.assertEquals(other, reference) dùng equals.

Đào sâu: Which method does Assert.assertEquals use for objects? → equals().

Q13. Why is String immutable? What are StringBuilder and StringBuffer?

Dịch: Vì sao String bất biến? StringBuilder, StringBuffer là gì?

Sample answer: Once created, a String cannot change; every "modification" returns a new object. Immutability allows the string pool to share instances, makes strings thread-safe, lets the hash code be cached, and makes them safe as HashMap keys. When I build text in a loop I use StringBuilder, which is mutable and fast but not thread-safe. StringBuffer is the synchronized older version, rarely needed.

Giải thích: Hệ quả hay gặp: s.trim(); một mình không làm gì — phải gán s = s.trim();.

Ví dụ: getText().trim() trả chuỗi mới; code chỉ gọi element.getText().trim(); mà không dùng kết quả là lỗi.

Đào sâu: What is the String pool and intern()? → vùng nhớ chia sẻ các literal; intern() trả về bản trong pool.

Q14. What is the difference between overloading and overriding?

Dịch: Overloading khác overriding?

Sample answer: Overloading means several methods with the same name but different parameter lists in the same class; it is resolved at compile time, and changing only the return type is not enough. Overriding means a subclass provides its own implementation of a parent method with the same signature; it is resolved at runtime, which is how polymorphism works. I use @Override so the compiler checks it.

Giải thích: Overload = nhiều dạng gọi; override = thay hành vi của lớp cha.

Ví dụ: BasePage.click(By) và click(WebElement) là overloading; ghi đè toString() là overriding.

Đào sâu: Can you override a static or private method? → xem Q24.

Q15. Explain the four OOP pillars with examples from an automation framework.

Dịch: Bốn trụ cột OOP, ví dụ trong framework automation.

Sample answer: Encapsulation: a page class keeps its locators private and exposes actions like loginAs(user, pass). Inheritance: all test classes extend BaseTest to reuse driver setup and teardown. Polymorphism: I declare WebDriver driver and assign ChromeDriver or FirefoxDriver, so tests do not change when the browser changes. Abstraction: tests call loginPage.loginAs(...) without knowing which locators or waits are used.

Giải thích: Luôn đưa ví dụ cụ thể từ project, không chỉ định nghĩa.

Ví dụ: Exercise01_LoginTest extends BaseTest; protected WebDriver driver.

Đào sâu: Composition vs inheritance for a header component? → ưu tiên composition (Page có Header).

Q16. What is the difference between final, finally and finalize?

Dịch: final, finally, finalize khác nhau?

Sample answer: final makes a variable a constant, a method non-overridable, or a class non-extendable. finally is a block after try/catch that runs whether or not an exception occurs, used for cleanup. finalize() was a hook called by the garbage collector; it is deprecated and should not be used.

Giải thích: Ba từ giống nhau nhưng khác hoàn toàn. finally không chạy khi JVM bị dừng đột ngột (System.exit, crash).

Ví dụ: try { test.testLogin(); } finally { test.tearDown(); } trong main() các Exercise; hằng số private static final String LOGIN_URL.

Đào sâu: Does finally run if try has return? → Có, finally chạy trước khi method trả về.

Q17. Checked vs unchecked exceptions? What are throw and throws?

Dịch: Checked/unchecked exception; throw và throws.

Sample answer: Checked exceptions extend Exception but not RuntimeException; the compiler forces me to catch them or declare them with throws, for example IOException. Unchecked exceptions extend RuntimeException or Error; the compiler does not force handling, for example NullPointerException. throw actually raises an exception object; throws declares what a method may raise. Selenium exceptions are unchecked.

Giải thích: Vì Selenium exception là unchecked nên không bị buộc try/catch — dễ quên xử lý.

Ví dụ: Config ném IllegalStateException khi thiếu config.properties (Lab 08); TimeoutException của Wait.

Đào sâu: When do you write a custom exception? → khi cần nhóm lỗi nghiệp vụ, kế thừa RuntimeException, kèm thông điệp rõ.

Q18. What is the difference between ArrayList and LinkedList?

Dịch: ArrayList khác LinkedList?

Sample answer: ArrayList is backed by a resizable array: random access by index is fast, adding at the end is amortized constant time, and inserting or removing in the middle is slow. LinkedList is a doubly linked list: inserting or removing at a known position is cheap but access by index is slow. In practice I use ArrayList by default.

Giải thích: Test automation hầu như chỉ duyệt và truy cập theo chỉ số ⇒ ArrayList.

Ví dụ: List<WebElement> rows = driver.findElements(...); rows.get(1).

Đào sâu: What does List.of(...) return? → danh sách bất biến; thêm phần tử sẽ ném UnsupportedOperationException.

Q19. How does HashMap work? Why do equals() and hashCode() matter?

Dịch: HashMap hoạt động thế nào? Vì sao cần equals/hashCode?

Sample answer: A HashMap stores entries in buckets. It computes key.hashCode() to choose a bucket, then uses equals() to find the exact key inside the bucket. The contract is: equal objects must have equal hash codes. If I override equals() without hashCode(), objects that are equal may land in different buckets and lookups or HashSet duplicates break. It allows one null key and is not thread-safe.

Giải thích: Collision được xử lý trong cùng bucket (danh sách liên kết, chuyển sang cây khi dài — chi tiết triển khai). Không dùng key có thể thay đổi.

Ví dụ: Map<String,String> cho dữ liệu test (user → password); dùng chuỗi làm key vì String đã cài đúng equals/hashCode.

Đào sâu: What happens if two keys have the same hash code? → vẫn lưu được, phân biệt bằng equals().

Q20. Compare HashSet/LinkedHashSet/TreeSet and HashMap/LinkedHashMap/TreeMap.

Dịch: So sánh các loại Set và Map.

Sample answer: The Hash* classes have no guaranteed order and offer average constant-time operations. The LinkedHash* classes keep insertion order. The Tree* classes keep elements sorted, cost O(log n), and need Comparable elements or a Comparator. Hashtable is a legacy synchronized map that rejects nulls; ConcurrentHashMap is the modern thread-safe map.

Giải thích: Chọn theo nhu cầu thứ tự/sắp xếp/an toàn luồng.

Ví dụ: driver.getWindowHandles() trả Set<String>; khử trùng lặp giữ thứ tự → LinkedHashSet.

Đào sâu: Which one for test data that must keep the file order? → LinkedHashMap/List.

Q21. What are wrapper classes and autoboxing? What is the Integer cache pitfall?

Dịch: Wrapper class, autoboxing; bẫy cache của Integer?

Sample answer: Wrapper classes such as Integer and Boolean are objects representing primitives; collections and generics need them. Autoboxing converts int to Integer automatically, and unboxing the other way; unboxing a null throws NullPointerException. Integer values from -128 to 127 are cached, so == can be true for small values but false for larger ones, therefore I use equals().

Giải thích: Integer a = 127, b = 127; a == b → true; với 128 → false.

Ví dụ: List<Integer>; executeScript("return window.scrollY") trả về Number (thường Long) chứ không phải int (Exercise 7).

Đào sâu: Default value of int vs Integer fields? → 0 vs null.

Q22. Is Java pass-by-value or pass-by-reference?

Dịch: Java truyền tham trị hay tham chiếu?

Sample answer: Always pass-by-value. For objects the value that is copied is the reference, so a method can change the state of the object the caller passed, but it cannot make the caller's variable point to a different object.

Giải thích: Vì vậy hàm swap(a, b) cho hai đối tượng không hoán đổi được biến của người gọi.

Ví dụ: Truyền driver vào constructor LoginPage(driver) ⇒ Page và test dùng chung một trình duyệt.

Đào sâu: What happens if you pass null? → tham chiếu null được sao chép; truy cập thành viên ⇒ NullPointerException.

Q23. What do this and super do? What is constructor chaining?

Dịch: this, super; constructor chaining.

Sample answer: this refers to the current object, and this(...) calls another constructor of the same class. super(...) calls a parent constructor and must be the first statement in the constructor. If the parent has no no-argument constructor, the child must call super(args) explicitly. A default constructor is generated only when a class declares no constructors.

Giải thích: Lỗi hay gặp khi viết Page: BasePage có constructor nhận driver mà lớp con quên super(driver) ⇒ lỗi biên dịch.

Ví dụ: public LoginPage(WebDriver driver) { super(driver); }.

Đào sâu: Can a constructor be static or final? → Không.

Q24. Can you override static, private or final methods?

Dịch: Có ghi đè được method static, private, final không?

Sample answer: No. final methods cannot be overridden. private methods are not inherited, so a subclass method with the same name is a new, unrelated method. A static method belongs to the class, so redeclaring it in a subclass hides the parent method instead of overriding it, and the call is resolved by the reference type. A static method also cannot use this or instance fields.

Giải thích: Ghi đè cần dispatch lúc chạy theo đối tượng; static gắn với lớp nên không có.

Ví dụ: DriverFactory.create(...) là static (factory method); main là static để JVM gọi mà không cần tạo đối tượng.

Đào sâu: Why must a static method not use instance fields? → Không có đối tượng cụ thể để đọc.

Q25. Interface features since Java 8, and what is a functional interface?

Dịch: Interface từ Java 8; functional interface là gì?

Sample answer: Since Java 8 interfaces can have default and static methods; private methods were added in Java 9. An abstract class can have constructors and instance state, and a class can extend only one class but implement many interfaces. A functional interface has exactly one abstract method and can be implemented with a lambda; @FunctionalInterface documents that.

Giải thích: Đây là lý do wait.until(d -> ...) viết được bằng lambda.

Ví dụ: Trong Selenium 4, ExpectedCondition<T> kế thừa Function<WebDriver, T>; until(...) nhận một hàm như vậy.

Đào sâu: Give a built-in functional interface. → Function, Predicate, Supplier, Consumer, Runnable.

Q26. How does try-with-resources work, and what if finally contains return?

Dịch: try-with-resources hoạt động thế nào; return trong finally?

Sample answer: Any object implementing AutoCloseable declared in the try (...) header is closed automatically in reverse order, even when an exception occurs; exceptions during closing are attached as suppressed exceptions. finally runs even when try returns. A return inside finally overrides the earlier return or swallows an exception, so I avoid it.

Giải thích: Dùng cho file/stream; cùng tinh thần với việc luôn quit() driver trong finally/@AfterMethod.

Ví dụ: Đọc config.properties bằng try (InputStream in = ...) (Lab 08).

Đào sâu: In what order are multiple resources closed? → ngược thứ tự khai báo.

Q27. Coding: reverse a string and check whether it is a palindrome.

Dịch: Viết code đảo chuỗi và kiểm tra palindrome.

Sample answer:

java
static String reverse(String s) {
    return new StringBuilder(s).reverse().toString();
}
static boolean isPalindrome(String s) {
    String clean = s.toLowerCase();
    int i = 0, j = clean.length() - 1;
    while (i < j) {
        if (clean.charAt(i++) != clean.charAt(j--)) return false;
    }
    return true;
}

I would also mention edge cases: null, empty string, and spaces or punctuation if the requirement says to ignore them.

Giải thích: Nói ra độ phức tạp (O(n)) và các trường hợp biên — interviewer chấm phần này nhiều hơn cú pháp.

Ví dụ: Cùng kỹ thuật dùng để chuẩn hoá getText() trước khi so sánh.

Đào sâu: Do it without StringBuilder. → vòng lặp hai con trỏ như trên.

Q28. Coding: count the frequency of each character, and find duplicates in a list.

Dịch: Đếm tần suất ký tự; tìm phần tử trùng trong list.

Sample answer:

java
Map<Character, Integer> freq = new LinkedHashMap<>();
for (char c : word.toCharArray()) {
    freq.merge(c, 1, Integer::sum);
}

Set<String> seen = new HashSet<>();
Set<String> duplicates = new LinkedHashSet<>();
for (String s : list) {
    if (!seen.add(s)) duplicates.add(s);   // add() returns false if already present
}

Giải thích: merge gộp "nếu chưa có thì 1, nếu có thì cộng thêm"; Set.add trả false khi đã tồn tại.

Ví dụ: Đếm số hàng theo trạng thái PASS/FAIL/SKIP (bài tập 04-control-flow).

Đào sâu: Time complexity? → O(n) trung bình.

Q29. Coding: find the second largest number in an array without sorting.

Dịch: Tìm số lớn thứ hai trong mảng, không sắp xếp.

Sample answer:

java
int max = Integer.MIN_VALUE, second = Integer.MIN_VALUE;
for (int n : a) {
    if (n > max) { second = max; max = n; }
    else if (n > second && n != max) { second = n; }
}

One pass, O(n) time and O(1) space. Edge cases: fewer than two distinct values (then second stays Integer.MIN_VALUE), so I would check and report that.

Giải thích: Điều kiện n != max để bỏ qua giá trị trùng với số lớn nhất.

Ví dụ: Kỹ thuật theo dõi "tốt nhất đến hiện tại" dùng khi so thời gian tải trang.

Đào sâu: What if duplicates should count as separate values? → bỏ điều kiện n != max.

Q30. What is ThreadLocal and why is it used with WebDriver in parallel tests?

Dịch: ThreadLocal là gì; vì sao dùng với WebDriver khi chạy song song?

Sample answer: ThreadLocal<T> gives each thread its own independent copy of a value. WebDriver is not thread-safe, and a shared static driver would let parallel tests interfere with each other's browser. With ThreadLocal<WebDriver> each thread sets and reads its own driver; I call remove() at the end of the test to avoid leaks when threads are reused.

Giải thích: Trong dự án driver là field instance, đúng khi chạy tuần tự; song song cần cấu trúc riêng.

Ví dụ: BaseTest của Lab 08 dùng ThreadLocal<WebDriver>, DRIVER.set(...) ở @BeforeMethod, DRIVER.remove() ở @AfterMethod.

Đào sâu: Why remove()? → thread trong pool được tái sử dụng; không xoá thì giữ tham chiếu và có thể dùng nhầm driver cũ.

Q31. What is the Stream API? Give a Selenium example.

Dịch: Stream API là gì? Ví dụ với Selenium.

Sample answer: A stream is a pipeline over a collection: a source, intermediate operations such as filter and map, and a terminal operation such as collect or count. It is lazy and does not modify the source. For example, I can collect the visible text of all links:

java
List<String> names = driver.findElements(By.cssSelector("li a")).stream()
        .map(WebElement::getText)
        .filter(t -> !t.isBlank())
        .collect(Collectors.toList());

For a Junior role a plain for loop is acceptable; I use streams when they make the code clearer.

Giải thích: Cẩn thận: nếu DOM đổi giữa chừng thì các WebElement trong stream có thể bị StaleElementReferenceException.

Ví dụ: Lấy danh sách tiêu đề cột bảng (#table1 th) rồi so sánh với danh sách kỳ vọng.

Đào sâu: map vs filter? → map biến đổi từng phần tử; filter giữ phần tử thoả điều kiện.
