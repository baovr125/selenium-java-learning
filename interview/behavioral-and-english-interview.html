Behavioral & English — Interview (giới thiệu, hành vi, tiếng Anh)

Phần lớn ứng viên Fresher/Junior rớt vì không kể được về mình và project, không phải vì thiếu kiến thức. Phần này không cần chạy code — chỉ cần chuẩn bị và nói thành tiếng. Quay lại: Interview README ⚠️ Nguyên tắc trung thực: các mẫu bên dưới có chỗ trống [...]. Chỉ điền những điều có thật về bạn. Interviewer đào sâu rất nhanh; câu chuyện bịa sẽ sụp ở câu hỏi thứ hai.

1. Tự giới thiệu (Self-introduction)

1.1. Cấu trúc 4 ý (Present → Past → Skill → Future)

  1. Hiện tại: bạn là ai, đang học/làm gì.
  2. Quá khứ ngắn: nền tảng liên quan (OOP Java ở đại học, kiến thức testing/API/SQL).
  3. Kỹ năng + bằng chứng: Selenium Java, project cụ thể.
  4. Mục tiêu: vì sao vị trí này, bạn sẽ học thêm gì.

1.2. Mẫu 30 giây (điền chỗ trống)

"Hi, I'm [name]. I'm looking for a Junior Automation Tester role. I have a background in [testing fundamentals, API testing and SQL], and I studied Java and OOP at university. Recently I've focused on UI automation with Selenium, Java, TestNG and Maven. I built a practice project that automates [10] scenarios on a public demo site, with explicit waits only, a shared base test and the Maven Wrapper. I'm now learning Page Object Model and I plan to learn Playwright next. I'd like to join a team where I can grow my automation skills."

1.3. Mẫu 2 phút (thêm chi tiết kỹ thuật)

Thêm sau ý 3, mỗi ý 1–2 câu và chọn 2 trong 3: (a) một vấn đề đồng bộ hoá đã gặp và cách bạn xử lý (ví dụ thông báo cũ → textToBe); (b) vì sao bạn không dùng Implicit Wait; (c) bạn tổ chức project thế nào (BaseTest, testng.xml, mvnw). Kết thúc bằng câu mục tiêu.

2. Câu hỏi hành vi thường gặp (12 câu)

Dùng khung STAR: Situation (bối cảnh) → Task (nhiệm vụ) → Action (bạn đã làm gì) → Result (kết quả/bài học). Mỗi câu trả lời 60–90 giây.

B1. Tell me about yourself.

Dùng mục 1. Tránh: đọc lại CV, kể tuổi thơ.

B2. Why do you want to be an automation tester?

Sample answer: "I enjoy understanding how software can fail and I like building tools that check it reliably. Automation lets me combine testing thinking with programming. I also like that a good automated suite gives the whole team fast feedback." Ghi chú: nêu lý do thật; liên hệ cả hai nửa: kiểm thử và lập trình.

B3. Walk me through your project.

Cấu trúc: mục tiêu → công nghệ (Java 21, Selenium 4.52.0, TestNG, Maven Wrapper) → cấu trúc (BaseTest, 10 Test class, testng.xml) → một thử thách kỹ thuật (flaky/Wait) → bạn sẽ cải thiện gì (POM, config, screenshot, CI). Ghi chú: chuẩn bị bản 3 phút và bản 10 phút. Xem AC15.

B4. Tell me about a bug you found / a test that failed for a surprising reason.

Mẫu STAR: S: "In my dynamic controls test the assertion passed too early." T: "I needed it to be reliable." A: "I found the old message 'It's gone!' was still visible, so waiting for visibility returned immediately; I changed the wait to textToBe for the exact new text." R: "The test became stable, and I learned to wait for a condition specific to the new state." Ghi chú: chỉ dùng nếu đúng với những gì bạn đã làm (Exercise 10); nếu không, dùng một lỗi bạn thật sự đã gặp.

B5. Describe a time you were stuck. How did you get unstuck?

Sample answer: "I read the exact exception first, reproduced it in a small test, checked the element in browser DevTools, searched the official docs, and only then asked for help with what I had tried. [Example: ...]" Ghi chú: thể hiện quy trình tự giải quyết rồi mới hỏi.

B6. How do you learn a new technology?

Sample answer: "I learn the core concepts, then rebuild something I already know with the new tool. For example, I'm learning Selenium with Java and plan to rewrite my 10 Selenium exercises in Playwright to compare them." Ghi chú: nhất quán với kế hoạch của bạn.

B7. Tell me about a disagreement with a teammate.

Khung: nêu bất đồng về kỹ thuật (không công kích cá nhân) → bạn lắng nghe, đưa dữ liệu/thử nghiệm → kết quả và bài học. Nếu chưa có kinh nghiệm làm việc, dùng ví dụ từ dự án nhóm ở trường và nói rõ.

B8. How do you handle a tight deadline or many tasks?

Sample answer: "I clarify priorities, split the work into small deliverables, do the highest-risk or highest-value part first, and tell the team early if something will slip."

B9. What is your biggest weakness?

Sample answer: "I'm still building hands-on experience in large frameworks. To address it I work on a small framework with Page Objects and CI, and I review my own failures to find root causes." Ghi chú: điểm yếu thật + hành động khắc phục; tránh "I'm a perfectionist".

B10. What are your strengths?

Sample answer: "I'm methodical when diagnosing problems: I reproduce, form a hypothesis and verify it, instead of adding sleeps. I also have a testing and API/SQL background, so I think about what is worth automating." Ghi chú: mỗi điểm mạnh kèm bằng chứng.

B11. Where do you see yourself in a few years?

Sample answer: "I want to become a reliable automation engineer who can design maintainable frameworks and contribute to quality across API and UI levels."

B12. Do you have any questions for us?

Luôn có 2–3 câu hỏi. Gợi ý: What does the current automation suite look like and what tools do you use? · How are flaky tests handled in your team? · How is automation integrated with CI? · What would the first 3 months look like for this role? · How does the team review test code?

3. Khi bạn chưa biết hoặc chưa làm

Tình huống Cách nói
Chưa dùng công cụ đó "I haven't used Selenium Grid in a project, but I understand the idea: a hub distributes tests to nodes to run in parallel on different browsers. I'd start by reading the docs and trying a local setup."
Quên đáp án "I don't remember the exact name, but here's how I would find out / how I think it works…"
Câu hỏi không rõ "Just to confirm, do you mean…?"
Cần thời gian nghĩ "Let me think for a moment."
Mới học Playwright "I haven't used it in a project yet. I know it auto-waits and uses browser contexts, and I plan to learn it after my Selenium foundation."

Không nên: nói "I know everything about…", đoán bừa như thật, im lặng quá lâu, chê công cụ/công ty cũ.

4. Ngân hàng cụm từ tiếng Anh

4.1. Giải thích code/quy trình

Mục đích Cụm từ
Mở đầu "Let me walk you through…" · "The goal of this test is…"
Mô tả luồng "First…, then…, finally…" · "After the click, the test waits until…"
Giải thích lý do "The reason is…" · "I chose X over Y because…"
Nêu trade-off "The advantage is…, but the downside is…"
Mô tả lỗi "The test failed with a StaleElementReferenceException because the page was refreshed."
Mô tả cách sửa "I replaced the fixed sleep with an explicit wait for…"
Chưa chắc "As far as I know…" · "I believe…, but I'd like to double-check."

4.2. Mẫu giải thích ngắn thường dùng

  • Locator: "A locator tells Selenium how to find an element on the page, for example by id, CSS selector or XPath. I prefer stable attributes like id or a test id."
  • Explicit wait: "An explicit wait pauses the test until a specific condition is true or a timeout expires, so it never waits longer than needed."
  • Page Object Model: "I keep locators and page actions in a class per page, so tests read like steps and a UI change needs a fix in one place."
  • Maven Wrapper: "It pins the Maven version for the project, so anyone can run mvnw without installing Maven."
  • Flaky test: "A flaky test sometimes passes and sometimes fails without any code change, usually because of timing, data or environment."

4.3. Phát âm thuật ngữ hay nói sai (gợi ý, hãy nghe lại với từ điển)

locator · XPath ("ex-path") · iframe ("eye-frame") · Selenium · stale · ExpectedConditions · asynchronous · parameter · dependency · repository · Maven · TestNG ("test-en-gee") · Javadoc.

5. Cách luyện (không cần máy tính)

  1. Viết ra 3 câu chuyện thật của bạn (một lỗi, một lúc bị kẹt, một điều bạn đã học nhanh), mỗi câu theo STAR.
  2. Luyện tự giới thiệu 30 giây và 2 phút cho đến khi nói trơn; ghi âm bằng điện thoại, nghe lại để bắt từ đệm ("um", "like").
  3. Mỗi ngày trả lời 5 câu từ các bộ phỏng vấn bằng tiếng Anh thành tiếng; mỗi tuần 1 buổi mock với người khác.
  4. Tự đánh giá mỗi buổi theo 4 tiêu chí (0–4): rõ ràng · có cấu trúc · có ví dụ · nêu trade-off.
