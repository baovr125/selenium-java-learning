# Selenium Java — học từng bài

Giáo trình tự học Selenium Java cho vị trí Junior Automation Test Engineer: Java, Maven & Maven Wrapper, Selenium, Wait, TestNG, Page Object Model, Git, phỏng vấn (song ngữ Anh–Việt).

Website tĩnh (HTML/CSS/JS thuần, không cần server). Mở `index.html` để học offline, hoặc xem bản online qua GitHub Pages.

- Tìm kiếm toàn văn, theo dõi tiến độ, kiểm tra kiến thức tương tác, giao diện sáng/tối, dùng được trên điện thoại.
- Tiến độ học lưu trong trình duyệt của bạn (có xuất/nhập JSON).
