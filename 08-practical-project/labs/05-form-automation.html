Bài 6. Tự động hoá chức năng Login

Mục tiêu: Viết bộ test Login có đường đi đúng + đường đi sai, dùng @DataProvider, Explicit Wait và assert tốt.

Kiến thức cần dùng: sendKeys, clear, click, getText, getCurrentUrl, visibilityOfElementLocated, @DataProvider.

Yêu cầu: trên /login (tài khoản đúng: tomsmith / SuperSecretPassword!):

  1. Đăng nhập đúng ⇒ URL kết thúc /secure, flash chứa You logged into a secure area!.
  2. Mật khẩu sai ⇒ vẫn ở /login, flash báo mật khẩu sai.
  3. Username sai ⇒ flash báo username sai.
  4. Sau khi login đúng, bấm Logout ⇒ về /login, flash báo đã đăng xuất.
  5. Dùng @DataProvider cho các trường hợp sai.

Code tham khảo

java
package tests;

import base.BaseTest;
import org.openqa.selenium.By;
import org.openqa.selenium.support.ui.ExpectedConditions;
import org.testng.Assert;
import org.testng.annotations.DataProvider;
import org.testng.annotations.Test;

public class LoginPracticeTest extends BaseTest {

    private static final String URL = "https://the-internet.herokuapp.com/login";
    private static final By USER = By.id("username");
    private static final By PASS = By.id("password");
    private static final By SUBMIT = By.cssSelector("button[type='submit']");
    private static final By FLASH = By.id("flash");

    private void login(String user, String pass) {
        driver.get(URL);
        driver.findElement(USER).clear();
        driver.findElement(USER).sendKeys(user);
        driver.findElement(PASS).clear();
        driver.findElement(PASS).sendKeys(pass);
        driver.findElement(SUBMIT).click();
    }

    private String flashText() {
        return wait.until(ExpectedConditions.visibilityOfElementLocated(FLASH)).getText();
    }

    @Test
    public void loginSuccess() {
        login("tomsmith", "SuperSecretPassword!");
        String msg = flashText();
        Assert.assertTrue(msg.contains("You logged into a secure area!"), "Thực tế: " + msg);
        Assert.assertTrue(driver.getCurrentUrl().endsWith("/secure"));
    }

    @DataProvider(name = "invalid")
    public Object[][] invalid() {
        return new Object[][] {
            {"tomsmith", "wrong-password", "Your password is invalid!"},
            {"nobody",   "SuperSecretPassword!", "Your username is invalid!"},
            {"",         "",                    "Your username is invalid!"}
        };
    }

    @Test(dataProvider = "invalid")
    public void loginFails(String user, String pass, String expected) {
        login(user, pass);
        String msg = flashText();
        Assert.assertTrue(msg.contains(expected), "Kỳ vọng chứa '" + expected + "' nhưng thực tế: " + msg);
        Assert.assertTrue(driver.getCurrentUrl().endsWith("/login"), "Phải ở lại trang login");
    }

    @Test
    public void logout() {
        login("tomsmith", "SuperSecretPassword!");
        wait.until(ExpectedConditions.elementToBeClickable(By.cssSelector("a.button.secondary"))).click();
        Assert.assertTrue(flashText().contains("You logged out of the secure area!"));
        Assert.assertTrue(driver.getCurrentUrl().endsWith("/login"));
    }
}

✅ Đã chạy thật: 5 test của Bài 6 pass (thông báo lỗi và locator nút Logout a.button.secondary khớp trang tại thời điểm viết). Nếu trang đổi, hãy in flash thực tế và chỉnh kỳ vọng.

Kết quả mong đợi

Tests run: 5 (1 + 3 + 1), xanh 3 lần liên tiếp. Mỗi lần chạy mở/đóng Chrome (@BeforeMethod).

7B. Alert — /javascript_alerts

java
@Test
public void jsAlerts() {
    driver.get("https://the-internet.herokuapp.com/javascript_alerts");
    By result = By.id("result");

    // JS Alert
    driver.findElement(By.cssSelector("button[onclick='jsAlert()']")).click();
    Alert alert = wait.until(ExpectedConditions.alertIsPresent());
    Assert.assertEquals(alert.getText(), "I am a JS Alert");
    alert.accept();
    Assert.assertEquals(driver.findElement(result).getText(), "You successfully clicked an alert");

    // JS Confirm — Cancel
    driver.findElement(By.cssSelector("button[onclick='jsConfirm()']")).click();
    wait.until(ExpectedConditions.alertIsPresent()).dismiss();
    Assert.assertEquals(driver.findElement(result).getText(), "You clicked: Cancel");

    // JS Prompt — nhập chữ
    driver.findElement(By.cssSelector("button[onclick='jsPrompt()']")).click();
    Alert prompt = wait.until(ExpectedConditions.alertIsPresent());
    prompt.sendKeys("Selenium");
    prompt.accept();
    Assert.assertEquals(driver.findElement(result).getText(), "You entered: Selenium");
}

7C. Frame — /iframe

java
@Test
public void iframeEditor() {
    driver.get("https://the-internet.herokuapp.com/iframe");
    wait.until(ExpectedConditions.frameToBeAvailableAndSwitchToIt(By.id("mce_0_ifr")));
    WebElement body = driver.findElement(By.id("tinymce"));
    Assert.assertEquals(body.getText(), "Your content goes here.");        // nội dung mặc định
    body.click();                                                          // focus vào editor
    body.sendKeys(Keys.chord(Keys.CONTROL, "a"), "Xin chao iframe");       // chọn hết rồi gõ đè
    Assert.assertEquals(body.getText(), "Xin chao iframe");
    driver.switchTo().defaultContent();                                    // QUAN TRỌNG
    Assert.assertTrue(driver.findElement(By.tagName("h3")).isDisplayed());
}

(Cần import org.openqa.selenium.Keys;.)

✅ Đã kiểm chứng khi chạy thật (Selenium 4.52.0, Chrome): phiên bản đầu của bài này dùng body.clear(); body.sendKeys(...) thất bại (expected [Xin chao iframe] but found []). Với trình soạn thảo TinyMCE, sendKeys mà không focus trước thì không ghi nhận chữ. Cách đúng là click() rồi Ctrl+A và gõ. Bài học: editor WYSIWYG khác <input> thường — luôn kiểm chứng kết quả bằng assertion.

7D. Window — /windows (mở rộng)

Viết test: bấm Click Here → numberOfWindowsToBe(2) → chuyển sang tab mới → kiểm tra getTitle() / h3 là New Window → close() → quay về mainHandle.
