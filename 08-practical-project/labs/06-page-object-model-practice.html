Bài 10. Xây dựng Page Object Model

Mục tiêu: Refactor test Login (kiểu Exercise01) sang POM; cảm nhận lợi ích khi đổi locator.

Kiến thức cần dùng: class, constructor, kế thừa, By private, Explicit Wait, method trả về Page tiếp theo.

Yêu cầu: trong SeleniumLab:

  1. Tạo pages/BasePage.java với waitVisible, click, type, text.
  2. Tạo pages/LoginPage.java và pages/SecureAreaPage.java.
  3. Viết tests/LoginPomTest.java dùng POM (không có By trong test).
  4. Viết test fail có chủ ý: login sai ⇒ LoginPage trả lỗi (getFlashMessage()).
  5. Thí nghiệm bảo trì: đổi một locator (ví dụ By.id("username") → By.name("username")) chỉ trong LoginPage; chạy lại — mọi test vẫn pass.

Các bước

  1. Cấu trúc:
text
src/test/java/
├── base/BaseTest.java
├── pages/BasePage.java, LoginPage.java, SecureAreaPage.java
└── tests/LoginPomTest.java
  1. BasePage, LoginPage, SecureAreaPage: lấy khung ở framework-design/01 mục 3.
  2. Test:
java
package tests;

import base.BaseTest;
import org.testng.Assert;
import org.testng.annotations.Test;
import pages.LoginPage;
import pages.SecureAreaPage;

public class LoginPomTest extends BaseTest {

    @Test
    public void validLogin() {
        SecureAreaPage secure = new LoginPage(driver).open().loginAs("tomsmith", "SuperSecretPassword!");
        Assert.assertTrue(secure.getFlashMessage().contains("You logged into a secure area!"));
        Assert.assertTrue(secure.isAtSecureArea());
    }

    @Test
    public void invalidLoginStaysOnLogin() {
        LoginPage login = new LoginPage(driver).open().loginWithInvalid("tomsmith", "bad");
        Assert.assertTrue(login.getFlashMessage().contains("Your password is invalid!"));
    }
}

LoginPage đã có getFlashMessage() (đọc #flash có chờ) trong mã mẫu ở framework-design/01, vì trang sai vẫn ở /login.

  1. Mở rộng POM cho 3 Exercise khác của dự án gốc: DropdownPage (Ex4), AddRemovePage (Ex6), DynamicControlsPage (Ex10). Gợi ý method ở framework-design/01 mục 9.

Kết quả mong đợi

  • .\mvnw.cmd clean test xanh; test không chứa By., WebElement, Thread.sleep.
  • Sau thí nghiệm bảo trì, chỉ một file thay đổi.

Tự đánh giá thiết kế

Câu hỏi Có/Không
Locator trong Page là private?
Page có assertion? (nên không)
Method có tên nghiệp vụ?
Wait nằm trong BasePage?
Test độc lập, chạy lẻ được?

Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
NullPointerException ở Page Quên truyền driver cho constructor new LoginPage(driver)
package pages does not exist Sai thư mục/ package src/test/java/pages + package pages;
Assert trong Page Thói quen cũ Trả dữ liệu, assert ở test
Lưu WebElement làm field Stale Lưu By
