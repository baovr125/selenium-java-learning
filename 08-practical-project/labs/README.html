⚠️ Quy tắc làm bài

  1. Không làm trên dự án gốc Selenium1. Tạo thư mục thực hành riêng, ví dụ B:\Fresher\SeleniumLab (xem bài 1).
  2. Dự án gốc dùng làm tham chiếu đối chiếu: src/test/java/..., pom.xml, testng.xml.
  3. Tự viết trước, đối chiếu code tham khảo sau.
  4. Mỗi bài kết thúc bằng .\mvnw.cmd clean test xanh và ghi vào LEARNING_PROGRESS.md.
  5. Trang luyện tập: https://the-internet.herokuapp.com (bên thứ ba; nếu giao diện đổi, hãy tự điều chỉnh locator).
