Bài 3. Sử dụng Maven Wrapper

Mục tiêu: Hiểu và quan sát Maven Wrapper hoạt động; tự tạo Wrapper cho dự án mới.

Kiến thức cần dùng: mvnw, mvnw.cmd, .mvn/wrapper/maven-wrapper.properties, ~/.m2/wrapper/dists.

Phần A. Quan sát Wrapper của Selenium1

powershell
cd B:\Fresher\Selenium1
Get-Content .mvn\wrapper\maven-wrapper.properties
mvn -version              # kỳ vọng: lỗi "not recognized" (nếu máy bạn chưa cài Maven)
.\mvnw.cmd -version       # kỳ vọng: Apache Maven 3.9.16

Trả lời (viết ra):

  1. wrapperVersion và phiên bản Maven là hai con số nào?
  2. distributionType=only-script nghĩa là gì? Vì sao không có maven-wrapper.jar?
  3. Maven được lưu ở đâu trên máy bạn? (dòng Maven home:)
  4. Dự án có distributionSha256Sum không? Hệ quả?

Phần B. Quan sát tải Maven lần đầu (tuỳ chọn)

Đổi tên thư mục cache để mô phỏng "máy mới" (không xoá):

powershell
Rename-Item "$HOME\.m2\wrapper\dists\apache-maven-3.9.16" "apache-maven-3.9.16.bak"
$env:MVNW_VERBOSE = "true"
.\mvnw.cmd -version        # sẽ thấy quá trình tải
Remove-Item Env:MVNW_VERBOSE

Sau khi xong, có thể xoá thư mục .bak nếu bản mới đã tải đủ, hoặc đổi tên lại. Yêu cầu có Internet.

Phần C. Tạo Wrapper cho SeleniumLab

Cách 1 (đã có mvnw trong Selenium1): chép mvnw, mvnw.cmd, .mvn\wrapper sang SeleniumLab.

powershell
Copy-Item B:\Fresher\Selenium1\mvnw, B:\Fresher\Selenium1\mvnw.cmd B:\Fresher\SeleniumLab\
Copy-Item B:\Fresher\Selenium1\.mvn\wrapper B:\Fresher\SeleniumLab\.mvn\wrapper -Recurse
cd B:\Fresher\SeleniumLab
.\mvnw.cmd -version

(Nếu thư mục .mvn chưa tồn tại, tạo trước: mkdir .mvn.)

Cách 2 (tạo bằng Maven): .\mvnw.cmd wrapper:wrapper "-Dmaven=3.9.16" "-Dtype=only-script" (cần chạy ở thư mục có pom.xml).

Kết quả mong đợi

  • .\mvnw.cmd -version trong SeleniumLab in Maven 3.9.16.
  • Bạn trả lời được 4 câu hỏi Phần A.

Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
'.\mvnw.cmd' is not recognized Sai thư mục/ thiếu .\ cd; dùng .\
Tải Maven thất bại Mạng/proxy maven/08

Bài 4. Chạy Selenium Test bằng mvnw.cmd

Mục tiêu: Chạy test ở nhiều mức (toàn bộ, 1 class, 1 method), đọc kết quả, phân biệt 5 trạng thái.

Các bước

powershell
cd B:\Fresher\Selenium1

# 1. Biên dịch, không mở Chrome
.\mvnw.cmd test-compile

# 2. Chạy 1 class không có trong testng.xml
.\mvnw.cmd test "-Dtest=EnvironmentCheckTest"

# 3. Chạy 1 method
.\mvnw.cmd test "-Dtest=Exercise02_CheckboxesTest#testSelectBothCheckboxes"

# 4. Chạy 1 nhóm bằng wildcard
.\mvnw.cmd test "-Dtest=Exercise0*"

# 5. Chạy toàn bộ suite (theo testng.xml)
.\mvnw.cmd clean test

# 6. Đọc kết quả
Get-Content target\surefire-reports\TestSuite.txt
Start-Process target\surefire-reports\emailable-report.html

Bảng quan sát (điền)

Lệnh Tests run Có mở Chrome? Thời gian Nhận xét
test-compile
-Dtest=EnvironmentCheckTest
-Dtest=...#testSelectBothCheckboxes
-Dtest=Exercise0*
clean test

Thí nghiệm "Tests run: 0"

powershell
.\mvnw.cmd test "-Dtest=NoSuchTest"

Ghi lại: Tests run: ? và BUILD ?. Giải thích vì sao nguy hiểm trong CI và cách phát hiện.

Thí nghiệm lifecycle

powershell
.\mvnw.cmd package "-DskipTests"
Get-ChildItem target\*.jar

Ghi lại: log có dòng Tests are skipped.? Có JAR will be empty? Vì sao jar chỉ ~2 KB?

Kết quả mong đợi

  • -Dtest=EnvironmentCheckTest: Tests run: 1 ... BUILD SUCCESS.
  • clean test: Tests run: 10, Failures: 0, Errors: 0, Skipped: 0.
  • -Dtest=NoSuchTest: Tests run: 0 ... BUILD SUCCESS (cảnh báo bẫy).

Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
PowerShell tách tham số tại dấu . Thiếu nháy "-Dtest=..."
-o clean lỗi has not been downloaded Chưa từng tải plugin clean Bỏ -o (cần mạng một lần)
Tests run: 10 nhưng không mở Chrome Chrome ẩn/ nền Kiểm tra thời gian ~90 s
Test fail do mạng the-internet chậm Chạy lại; xem report

⚠️ clean xoá target/ của dự án bạn đang thực hành. Với Selenium1 gốc, báo cáo mẫu 10/10 vẫn còn trong ket-qua/; vẫn nên thực hành trên bản sao.
