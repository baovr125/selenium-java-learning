Lab 07: Test Suite với TestNG và chạy bằng Maven (Bài 11)

Liên quan: Mục lục bài tập · testing-framework/01 · maven/06 Đối chiếu: testng.xml, pom.xml (suiteXmlFile), AllExercisesTest

Bài 11. Tạo Test Suite bằng TestNG

Mục tiêu: Tạo nhiều suite (smoke, regression) bằng testng.xml và groups, chạy qua Maven; hiểu chính xác Surefire chọn test nào.

Kiến thức cần dùng: testng.xml, groups, @Test(groups=...), Surefire suiteXmlFiles, -Dtest, systemPropertyVariables.

Phần A. Gắn nhóm

Trong SeleniumLab, đặt nhóm cho test:

java
@Test(groups = {"smoke"})       public void validLogin() { ... }
@Test(groups = {"regression"})  public void invalidLogin() { ... }
@Test(groups = {"regression"})  public void dropdownSelectsEachOption() { ... }

Phần B. Tạo ba file suite

smoke.xml:

xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE suite SYSTEM "https://testng.org/testng-1.0.dtd">
<suite name="Smoke">
  <test name="Smoke tests">
    <groups><run><include name="smoke"/></run></groups>
    <packages><package name="tests"/></packages>
  </test>
</suite>

regression.xml: tương tự, include name="regression".

all.xml: liệt kê trực tiếp các class (như testng.xml của dự án gốc).

Phần C. Cho phép chọn suite khi chạy

Trong pom.xml của SeleniumLab:

xml
<properties>
    <suiteFile>all.xml</suiteFile>
</properties>
...
<plugin>
    <artifactId>maven-surefire-plugin</artifactId>
    <version>3.5.2</version>
    <configuration>
        <suiteXmlFiles>
            <suiteXmlFile>${suiteFile}</suiteXmlFile>
        </suiteXmlFiles>
    </configuration>
</plugin>

Chạy:

powershell
.\mvnw.cmd test                          # all.xml (mặc định)
.\mvnw.cmd test "-DsuiteFile=smoke.xml"
.\mvnw.cmd test "-DsuiteFile=regression.xml"

Phần D. Quan sát và ghi lại

Lệnh Tests run Class/Method chạy
test
-DsuiteFile=smoke.xml
-DsuiteFile=regression.xml
-Dtest=LoginPracticeTest (suite có được dùng không?)

Phần E. So sánh với dự án gốc

Trả lời:

  1. Selenium1 chạy AllExercisesTest.main() khác gì mvnw test? Báo cáo nằm ở đâu (test-output/ vs target/surefire-reports/)?
  2. Vì sao EnvironmentCheckTest không chạy khi mvnw test?
  3. Làm sao chạy EnvironmentCheckTest bằng Maven?
Đáp án gợi ý
  1. main() dùng API TestNG trực tiếp, không qua Surefire, báo cáo vào test-output/. mvnw test qua Surefire, báo cáo vào target/surefire-reports/.
  2. Không có trong testng.xml, mà Surefire dùng suiteXmlFile.
  3. .\mvnw.cmd test "-Dtest=EnvironmentCheckTest" (bỏ qua suite file).

Phần F. Kiểm tra "Tests run"

Chạy .\mvnw.cmd test "-DsuiteFile=khong-ton-tai.xml" ⇒ ghi lại kết quả (kỳ vọng: lỗi vì file suite không có — khác với -Dtest=NoSuchTest im lặng). So sánh hai trường hợp và rút ra quy tắc kiểm tra CI.

Kết quả mong đợi

  • smoke.xml chạy số test nhỏ; regression.xml chạy phần còn lại; all.xml chạy tất cả.
  • Bạn giải thích được thứ tự ưu tiên giữa -Dtest và suiteXmlFiles.
