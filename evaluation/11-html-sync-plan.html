2. Mục tiêu

  1. Bản HTML phản ánh 100% Markdown hiện tại, chạy build thoát mã 0, không lỗi bảng mã.
  2. Các tính năng tương tác (điều hướng, tìm kiếm, tiến độ, quiz, copy code, sáng/tối) hoạt động với nội dung mới.
  3. Quyết định rõ về evaluation/ trên bản web.
  4. (Tuỳ chọn, cần người dùng đồng ý) đẩy bản online.

3. Các bước thực hiện

Bước 0 — Chuẩn bị (5 phút)

  • Đọc nhanh 10-changes-applied.md và mục 1 của file này.
  • Sao lưu site/ hiện tại ra thư mục tạm (nếu muốn so sánh): cp -r docs/selenium-learning/site <scratchpad>/site-before.
  • Kiểm tra phụ thuộc: python -c "import markdown, pygments" (đã có ở phiên trước).

Bước 1 — Sửa lỗi bảng mã của script build (10 phút)

Nguyên nhân: print(f"Đã sinh …") ở cuối main() trong tools/build_site.py (khoảng dòng 334) ghi tiếng Việt ra console cp1252. Cách làm, chọn một:

  • Ưu tiên (ít rủi ro): luôn chạy với PYTHONIOENCODING=utf-8 — đã có trong tools/publish.ps1; chỉ cần ghi rõ vào tools/README.md lệnh đúng: PowerShell: $env:PYTHONIOENCODING="utf-8"; python docs\selenium-learning\tools\build_site.py
  • Hoặc thêm ở đầu build_site.py: sys.stdout.reconfigure(encoding="utf-8") (an toàn với Python 3.7+).

Kiểm chứng: chạy lại và xác nhận exit code 0 (echo $? hoặc $LASTEXITCODE).

Bước 2 — Build lại và đối chiếu số lượng (10 phút)

powershell
cd B:\Fresher\Selenium1
$env:PYTHONIOENCODING = "utf-8"
python docs\selenium-learning\tools\build_site.py

Kiểm tra bằng script (đã dùng ở phiên trước, viết lại nếu cần):

  1. Mỗi *.md (trừ site/, tools/, README.md gốc) có site/<cùng đường dẫn>.html; không có HTML mồ côi (xoá nếu có — do đổi tên/xoá Markdown).
  2. Mọi liên kết nội bộ trong HTML trỏ tới file tồn tại (đổi .md → .html, kể cả anchor). Lưu ý: anchor có tiếng Việt/ký tự đặc biệt (ví dụ #1-tự-giới-thiệu-self-introduction trong interview/README.md) — kiểm tra id thực tế do script sinh.
  3. assets/nav.js chứa đủ 11 tài liệu phỏng vấn và nhóm evaluation/ (nếu giữ).
  4. assets/search-index.js tìm được một cụm chỉ có ở nội dung mới (ví dụ ThreadLocal, Integer cache, STAR).

Bước 4 — Dọn các sai khác phát hiện được (tuỳ kết quả)

Bước 5 — Quyết định về thư mục evaluation/ trên bản web
