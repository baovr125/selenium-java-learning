06 · Lộ trình học đề xuất (tinh gọn, thiên về thực hành)

Quay lại README đánh giá · Trước: 05 Phỏng vấn · Tiếp: 07 Đề xuất cuối

1. Giả định & nguyên tắc

Mục Giá trị
Người học Mới/gần mới, bán thời gian ~10–12 giờ/tuần (≈ 1,5 giờ/ngày + 1 buổi cuối tuần), có thời gian thực hành & ôn tập
Mục tiêu Mức 3 "Ứng tuyển Junior Automation Tester" (05 §3.2); điểm dừng sớm: mức 2 "Fresher" sau Phase 6
Hệ số an toàn Đã cộng thời gian làm lại/ôn; không ước lượng theo "1–2 giờ/bài" của lộ trình cũ (01 §5.1)

Nguyên tắc thiết kế:

  1. Thực hành đi cùng bài: mỗi Phase kết thúc bằng Lab/Exit Criteria đo được, không phải "đã đọc".
  2. Chạm trình duyệt sớm (~giờ thứ 43 thay vì ~giờ 60–75 của lộ trình cũ, ước lượng).
  3. Git từ ngày 1: mọi bài làm đều commit/push lên GitHub thật.
  4. Wait là xương sống: dành 3 tuần + Lab chẩn đoán flaky; thêm chuẩn bị phỏng vấn Wait ở mọi Phase sau.
  5. Testing Fundamentals chạy song song (Track T, ~14 giờ rải đều).
  6. Phỏng vấn xuyên suốt: mock 20 phút cuối mỗi Phase (05 §5).
  7. Cắt những gì Junior chưa cần (xem §4) để khỏi lan man.

2. Tổng quan

Phase Nội dung Tuần Giờ Priority Mốc
0 Môi trường + Git Lite W1 10 Essential Repo GitHub đầu tiên
1 Java Core A (01–08) + Track T1–T2 W2–4 33 Essential
2 Maven Lite + TestNG Core + Selenium Basics (+Java 09–10, T3–T4) W5–9 55 Essential Lần đầu mở trình duyệt: W5
3 Selenium Interactions + Exceptions + Debugging (+T5–T6) W10–11 22 Essential
4 Wait & Synchronization (+ Lambda/Generics) W12–14 33 Essential — ưu tiên cao
5 TestNG Advanced + Maven Deep W15–17 33 Essential/Important
6 POM & Framework Design (+File/Config, Logging) W18–20 33 Essential Mức 2 – Fresher (xem Exit)
7 Git Team Workflow + CI cơ bản W21–22 20 Essential/Important
8 Bổ trợ: HTTP/API/Postman/REST Assured + SQL W23–25 30 Important
9 Capstone (mô phỏng dự án thật) W26–29 44 Essential Mức 3 – Junior
10 Interview Sprint + Exit Exam W30–31 20 Essential
Tổng ≈ 31 tuần (~7 tháng) ≈ 333

Biến thể: đã có Java nền → bỏ Phase 1 (−3 tuần) còn ~28 tuần; học toàn thời gian (~25 giờ/tuần) → ~13–14 tuần; 6 giờ/tuần → ~55 tuần. Nếu phải rút gọn tối đa, giữ nguyên Phase 2–4, 6, 9 và rút Phase 8 xuống HTTP+Postman+SQL SELECT (~14 giờ).

3. Chi tiết từng Phase

Phase 0 — Khởi động & Git Lite (W1 · ~10 giờ · Essential)

Nội dung Yêu cầu
Mục tiêu Máy chạy được Java + Chrome; có repo GitHub; commit/push thành thạo cho mọi bài sau
Kiến thức Environment Setup; Git Lite: init/add/commit/status/log/push, branch cơ bản, .gitignore (rút từ Git 01, Git 04)
Prerequisites Không
Thực hành Tạo repo GitHub automation-learning; commit tài liệu ghi chú; chạy .\mvnw.cmd -version trên một bản sao Selenium1
Interview Không (làm quen thuật ngữ)
Exit Criteria ✔ java -version ≥ 21, Chrome cài; ✔ ≥ 5 commit có message rõ trên GitHub; ✔ giải thích working tree / staging / commit bằng lời

Phase 1 — Java Core A + Testing Fundamentals T1–T2 (W2–4 · ~33 giờ · Essential)

Nội dung Yêu cầu
Mục tiêu Đọc/viết chương trình Java có biến, điều kiện, vòng lặp, mảng, method, class/OOP; hiểu nền tảng kiểm thử
Kiến thức Java 01–08 (đã cắt phần Optional: recursion, float/byte/short, inner class); T1 Nguyên tắc kiểm thử + SDLC/STLC + Test Levels/Types; T2 Scenario/Test Case/Test Plan/RTM (chuyển từ Phase 8/01)
Prerequisites Phase 0
Thực hành 15 kata Java (chuỗi, mảng, method, class); Mini-project A: TestCase/TestResult + in tóm tắt PASS/FAIL; đọc BaseTest.java và giải thích từng dòng; viết 10 test case cho trang Login
Interview J1–J7, ST1–ST6 (05 §4)
Exit Criteria ✔ 15 kata chạy đúng (commit); ✔ mini-project A chạy; ✔ giải thích BaseTest không cần tra từ khoá; ✔ trả lời ≥ 60% J1–J7 + ST1–ST6 bằng lời

Phase 2 — Maven Lite + TestNG Core + Selenium Basics (W5–9 · ~55 giờ · Essential)

Nội dung Yêu cầu
Mục tiêu Tự dựng dự án Maven, chạy test Selenium bằng mvnw; tìm phần tử ổn định; làm lại Exercise 1–5 không nhìn đáp án
Kiến thức Selenium Smoke (1–2 giờ, tuần đầu W5) → Selenium 01–06 (Intro, WebDriver, Locators, WebElement, Navigation, Interactions + Dropdown); Maven Lite: Project Init, Fundamentals, pom.xml, Maven Wrapper ⭐; TestNG Core (annotations, Assert, testng.xml, chạy bằng mvnw) tách từ TestNG 01; Java 09 Collections, 10 Exceptions; T3 EP + BVA, T4 Decision Table + State Transition
Prerequisites Phase 1 (Java 01–08)
Thực hành Lab 01 (dự án mới + HomePageTest), Lab 02, Lab 04; 12 "kata" Selenium trên 3 site (site demo + 1 site có form/giỏ hàng + 1 site có bảng); làm lại Exercise 1–5; Mini-project B: đọc CSV test case → in
Interview J8–J15, S1–S11, M1–M5, ST7–ST10
Exit Criteria ✔ Dự án mới mvnw clean test xanh 3 lần liên tiếp và push lên GitHub; ✔ viết CSS/XPath cho 8 phần tử khó ≥ 7/8 ổn định; ✔ Exercise 1–5 tự viết lại không nhìn; ✔ thiết kế 20 test case bằng BVA/EP cho 2 chức năng; ✔ giải thích Wrapper + file nào commit

Phase 3 — Selenium Interactions, Exceptions & Debugging (W10–11 · ~22 giờ · Essential)

Nội dung Yêu cầu
Mục tiêu Xử lý Alert/Frame/Window, Actions, JS Executor; đọc stacktrace; sửa lỗi Selenium phổ biến
Kiến thức Selenium 07–11 (Exceptions đọc trước các bài còn lại nếu cần); screenshot, headless/ChromeOptions, cookie, upload; T5 Defect lifecycle + Severity/Priority + Bug report; T6 Smoke/Sanity/Regression + Agile/Scrum
Prerequisites Phase 2
Thực hành Lab 05 (Login, Dropdown, Alert, Frame, Window); "Locator Refactor" (10 locator giòn → ổn định); viết 3 bug report cho lỗi cho sẵn
Interview S12–S20, ST11–ST14
Exit Criteria ✔ Lab 05 xanh 3/3; ✔ phân biệt đúng NoSuchElement/Stale/NotInteractable/ClickIntercepted trên 6 stacktrace cho sẵn; ✔ 3 bug report đạt checklist; ✔ phân biệt smoke/sanity/regression

Phase 4 — Wait & Synchronization (W12–14 · ~33 giờ · Essential — ưu tiên cao)

Nội dung Yêu cầu
Mục tiêu Chọn đúng loại Wait cho tình huống thật; chẩn đoán và sửa test flaky có hệ thống
Kiến thức Java 11a Lambda & Generics cơ bản; Wait 01–08: Core (Intro, Explicit, ExpectedConditions, So sánh, 15 tình huống) → Advanced (Implicit, Fluent/Custom, Best Practices); bổ sung: page-ready (document.readyState) và chờ AJAX theo điều kiện UI
Prerequisites Phase 3, TestNG Core, lambda cơ bản
Thực hành Lab 03; "Flaky Clinic" — 6 test cho sẵn lỗi (sleep cứng, stale, overlay/spinner, thông báo cũ, iframe chậm, tab mới); đo thời gian Implicit vs Explicit; viết 2 custom wait
Interview W1–W15 + SC1, SC2, SC9
Exit Criteria ✔ Flaky Clinic: mỗi ca ghi triệu chứng → nguyên nhân → sửa → chạy 5/5 xanh; ✔ không còn Thread.sleep hay Implicit Wait; ✔ trả lời ≥ 80% W1–W15 không nhìn đáp án; ✔ giải thích Exercise 7 (custom wait) và Exercise 10 (textToBe)

Phase 5 — TestNG Advanced + Maven Deep (W15–17 · ~33 giờ · Essential/Important)

Nội dung Yêu cầu
Mục tiêu Test dữ liệu đa bộ, nhóm smoke/regression, chạy song song cơ bản; hiểu build/dependency đủ để debug
Kiến thức TestNG: DataProvider, Parameters, Groups, soft assert, Parallel + ThreadLocal, Listener/Retry (khái niệm) — 05-testing-framework 03–06; Maven Deep (gộp 3 bài): Lifecycle + Surefire, Dependency Management/Conflict, Troubleshooting — nguồn 02-maven 04–09 (bỏ Failsafe/Profile); JUnit chỉ đọc 1 giờ
Prerequisites Phase 4
Thực hành Lab 07; data-driven login (DataProvider từ CSV); smoke.xml + -Dgroups; "Broken Build": 5 lỗi Maven cho sẵn (dependency conflict, -Dtest gõ sai → Tests run: 0, sai JDK, mất mvnw mode, XML sai)
Interview T1–T6, M6–M10, SC5, SC6
Exit Criteria ✔ 3 cách chạy suite khác nhau cho 3 kết quả khác nhau; ✔ sửa được 5/5 "Broken Build"; ✔ giải thích vì sao BUILD SUCCESS vẫn có thể Tests run: 0; ✔ chạy song song 2 luồng không giẫm driver

Phase 6 — POM & Framework Design (W18–20 · ~33 giờ · Essential)

Nội dung Yêu cầu
Mục tiêu Tự dựng framework nhỏ sạch: POM, BasePage, DriverFactory, Config, screenshot, logging
Kiến thức POM 01–05 (PageFactory → Optional); Java 12 File/Properties; SLF4J/Log4j2 cơ bản; Surefire + screenshot khi fail (Extent/Allure Optional)
Prerequisites Phase 5, Java OOP
Thực hành Lab 06; refactor 10 Exercise gốc → POM + DriverFactory + Config (không cho code sẵn: chỉ spec + tiêu chí); thí nghiệm bảo trì: đổi 1 locator → chỉ sửa 1 file
Interview T7–T10, SC3, SC4, SC10
Exit Criteria ✔ Tests run ≥ 15, mọi By chỉ nằm trong Page; ✔ -Dheadless=true hoạt động; ✔ screenshot tự sinh khi fail; ✔ README đủ để người lạ chạy chỉ với JDK; ✔ giải thích framework bằng tiếng Anh trong 3 phút. → Đạt mức 2 (Fresher): có thể bắt đầu nộp CV Fresher song song học tiếp.

Phase 7 — Git Team Workflow + CI cơ bản (W21–22 · ~20 giờ · Essential/Important)

Nội dung Yêu cầu
Mục tiêu Làm việc với repo chung: nhánh, PR, conflict, review; chạy test trên CI
Kiến thức Git 02–03 (branch/merge, rebase cơ bản, conflict, PR, review); quy ước commit/branch; GitHub Actions chạy ./mvnw -B clean test (+ upload report) — thực chạy, không chỉ đọc; rebase nâng cao → Optional
Prerequisites Phase 6
Thực hành ≥ 3 PR thật vào repo của chính mình (nhờ người/AI review, sửa theo góp ý); tạo conflict thật ở pom.xml và giải quyết; workflow CI xanh trên repo
Interview Git Q1–Q10, SC5, SC6
Exit Criteria ✔ 3 PR đã merge, có review comment; ✔ conflict pom.xml giải quyết đúng và mvnw test xanh; ✔ badge CI xanh; ✔ giải thích fetch vs pull, merge vs rebase, vì sao commit mvnw mode 100755

Phase 8 — Bổ trợ: HTTP/API/Postman/REST Assured + SQL (W23–25 · ~30 giờ · Important)

Nội dung Yêu cầu
Mục tiêu Hiểu HTTP/REST, kiểm thử API cơ bản bằng Postman và Java; truy vấn SQL đủ để kiểm chứng dữ liệu
Kiến thức Bài mới: HTTP (methods, status, headers, JSON); REST; Postman (collection, biến, assertion); REST Assured cơ bản (GET/POST + assertThat); SQL: SELECT/WHERE/ORDER/JOIN/GROUP BY; kiểm tra dữ liệu sau thao tác UI (ý tưởng; JDBC Optional)
Prerequisites Phase 6 (Maven, TestNG, JSON cơ bản)
Thực hành Collection Postman cho 1 API công khai (≥ 8 request, có assertion); 3 test REST Assured trong repo; 15 truy vấn SQL trên DB mẫu
Interview Thêm 8–10 câu HTTP/API/SQL (bổ sung ngân hàng câu hỏi)
Exit Criteria ✔ phân biệt 200/201/204/400/401/403/404/500; ✔ viết test REST Assured xanh; ✔ giải 15 truy vấn SQL ≥ 12 đúng; ✔ giải thích khi nào dùng API thay UI (ví dụ đăng nhập nhanh)

Phase 9 — Capstone (W26–29 · ~44 giờ · Essential)

Nội dung Yêu cầu
Mục tiêu Hoàn thành một dự án Automation có nghiệp vụ, đủ 11 bước thực tế, đưa được vào CV
Kiến thức Tổng hợp; đặc tả chi tiết ở 04 §6.2 (requirement mơ hồ → test case EP/BVA/Decision Table → chọn automation → framework → CI → bug report → PR → thay đổi UI giữa chừng → trình bày)
Prerequisites Phase 6–8
Thực hành ≥ 25 test case, 12–15 test tự động, ≥ 3 bug report, ≥ 4 PR, CI xanh, README + video 5 phút bằng tiếng Anh
Interview SC7–SC10; giải thích project 3 phút/10 phút
Exit Criteria ✔ Rubric Capstone ≥ 70% (04 §6.2); ✔ mvnw clean test 3/3 xanh trên CI; ✔ xử lý được thay đổi UI giữa chừng bằng sửa một Page. → Đạt mức 3 (Junior) nếu đạt thêm Exit Exam ở Phase 10.

Phase 10 — Interview Sprint + Exit Exam (W30–31 · ~20 giờ · Essential)

Nội dung Yêu cầu
Mục tiêu Chuyển kiến thức thành phản xạ trả lời; vá lỗ hổng cuối
Kiến thức Ôn bộ 95 câu (05 §4); luyện tự giới thiệu + giải thích project; tìm hiểu 5–10 JD thật để đối chiếu
Prerequisites Phase 9
Thực hành 3 mock đầy đủ 90 phút (ghi âm, tiếng Anh) + Exit Exam 3 giờ (05 §2.3); sửa 3 câu yếu nhất
Interview Toàn bộ
Exit Criteria ✔ Exit Exam ≥ 70%; ✔ 2 mock liên tiếp ≥ 70% điểm (thang 0/1/2 mỗi câu; ngân hàng đầy đủ 95 câu = 190 điểm → ≥ 133 điểm, mock rút gọn thì tính theo tỷ lệ); ✔ không nhóm nào < 3 trong bảng năng lực mức Junior
