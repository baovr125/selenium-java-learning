1. Lớp Actions

Actions dùng để mô phỏng thao tác chuột/bàn phím phức tạp mà click()/sendKeys() đơn giản không làm được (hover, kéo thả, chuột phải, nhấn giữ phím).

java
import org.openqa.selenium.interactions.Actions;

Actions actions = new Actions(driver);        // 🧩 Ex5, Ex9
actions.moveToElement(element).perform();

Nguyên tắc quan trọng: Actions hoạt động theo kiểu xây chuỗi (builder) rồi thực thi. Các method chỉ ghi lại hành động; perform() mới thực sự chạy. Quên .perform() ⇒ không có gì xảy ra và không báo lỗi.

java
actions.moveToElement(el).click().build().perform();   // build() có thể bỏ; perform() gọi build()

Dùng lại Actions: sau perform(), chuỗi đã được xoá, có thể tạo chuỗi mới trên cùng đối tượng (🧩 Ex5 dùng lại actions trong vòng lặp).

2. Mouse Actions

Method Ý nghĩa
moveToElement(el) Di chuột (hover) vào tâm phần tử
moveToElement(el, xOffset, yOffset) Hover với độ lệch (Selenium 4: offset tính từ tâm)
click(), click(el) Click trái
doubleClick(el) Click đúp
contextClick(el) Click phải
clickAndHold(el) / release() Nhấn giữ / thả
dragAndDrop(source, target) Kéo thả (🧩 Ex9)
dragAndDropBy(source, x, y) Kéo theo toạ độ
scrollToElement(el) Selenium 4: cuộn đến phần tử

2.1. Hover (🧩 Ex5)

java
actions.moveToElement(currentFigure).perform();                       // hover
WebElement caption = currentFigure.findElement(By.cssSelector(".figcaption h5"));
wait.until(ExpectedConditions.visibilityOf(caption));                 // caption hiện sau hover
String info = caption.getText();                                      // "name: user1"

Ứng dụng: menu thả xuống mở khi hover; tooltip. Luôn chờ phần tử hiện sau hover.

2.2. Drag & Drop (🧩 Ex9)

java
actions.dragAndDrop(columnA, columnB).perform();

Cách tương đương, kiểm soát từng bước:

java
actions.clickAndHold(columnA)
       .moveToElement(columnB)
       .release()
       .perform();

⚠️ Độ tin cậy: trang the-internet dùng HTML5 Drag & Drop. Trên một số tổ hợp Chrome/Selenium, dragAndDrop có thể không kích hoạt sự kiện HTML5 ⇒ không đổi chỗ. Dự án chạy 10/10 pass trên môi trường hiện tại, nhưng đây là loại thao tác dễ flaky. Phương án dự phòng:

  1. clickAndHold → moveToElement → release (có thể cần thêm moveByOffset nhỏ);
  2. Mô phỏng sự kiện dragstart/dragover/drop bằng JavaScript (08);
  3. Với thư viện kéo thả dùng chuột (không phải HTML5 DnD), Actions thường chạy tốt.

Kiểm chứng kết quả bằng nội dung (🧩 Ex9 so header của #column-a = "B"), không chỉ "không lỗi".

3. Keyboard Actions

3.1. sendKeys với Keys

java
import org.openqa.selenium.Keys;

input.sendKeys("Selenium", Keys.ENTER);                       // gõ rồi Enter
input.sendKeys(Keys.chord(Keys.CONTROL, "a"));                // Ctrl+A
input.sendKeys(Keys.chord(Keys.CONTROL, "c"));                // Ctrl+C

macOS dùng Keys.COMMAND thay cho Keys.CONTROL — tránh phụ thuộc hệ điều hành bằng cách chọn khoá theo System.getProperty("os.name").

3.2. Actions với bàn phím

Method Ý nghĩa
sendKeys(CharSequence...) Gõ vào phần tử đang focus
sendKeys(el, text) Gõ vào phần tử cụ thể
keyDown(Keys.SHIFT) Nhấn giữ phím
keyUp(Keys.SHIFT) Nhả phím
java
actions.keyDown(Keys.SHIFT)
       .sendKeys("selenium")          // gõ chữ HOA
       .keyUp(Keys.SHIFT)
       .perform();

actions.keyDown(Keys.CONTROL).click(item1).click(item2).keyUp(Keys.CONTROL).perform();   // chọn nhiều mục

Phím hay dùng: ENTER, TAB, ESCAPE, BACK_SPACE, DELETE, ARROW_DOWN/UP, PAGE_DOWN, HOME, END, SPACE, F5.

5. Actions vs click() thường

element.click() Actions
Hover ❌ ✅ moveToElement
Kéo thả ❌ ✅
Chuột phải/đúp ❌ ✅
Phím kết hợp Hạn chế ✅
Tự cuộn đến phần tử ✅ Thường ✅ (moveToElement)
Độ đơn giản ✅ Dài hơn

✅ Best Practices

  1. Luôn perform().
  2. Sau hover/kéo thả, chờ thay đổi UI rồi mới assert.
  3. Kiểm chứng kết quả thực sự (nội dung/vị trí) thay vì tin "không lỗi".
  4. Tách thành hàm dùng lại (hover(By), dragAndDrop(By, By)).
  5. Có phương án dự phòng JS cho thao tác dễ flaky (và ghi chú rõ).

⚠️ Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
Hover không có tác dụng Quên perform(); chuột đang ở ngoài viewport perform(); cuộn vào view
MoveTargetOutOfBoundsException Toạ độ/offset ra ngoài Dùng moveToElement(el) không offset hoặc cuộn trước
Menu hover biến mất khi di chuyển Chuột "đi qua" vùng trống Di chuyển tuần tự: hover cha → hover/click con
Kéo thả không đổi chỗ HTML5 DnD Xem mục 2.2
StaleElementReferenceException sau hover DOM vẽ lại Tìm lại phần tử

💼 Interview Corner

1. How do you perform a hover in Selenium?

  • 🇻🇳 Dịch: Thực hiện hover?
  • Suggested answer (EN): Create Actions, call moveToElement(element).perform() and then wait for the revealed element to be visible.
  • Giải thích (VI): Dự án Exercise05.
  • Follow-up: Why is perform() required?

2. Drag and drop is flaky. What do you do?

  • 🇻🇳 Dịch: Kéo thả hay flaky?
  • Suggested answer (EN): Verify the result by content, try clickAndHold/moveToElement/release, and as a last documented fallback dispatch drag events via JavaScript.
  • Giải thích (VI): HTML5 DnD khó với WebDriver.
  • Follow-up: Why avoid JS as the first choice?

📌 Lesson Summary

Kiến thức cần nhớ

  • Actions là builder; perform() mới thực thi
  • Luôn chờ UI thay đổi sau hover/kéo thả
  • Kiểm chứng kết quả bằng nội dung

Method / lệnh cần biết

  • moveToElement, dragAndDrop, clickAndHold, release, keyDown/keyUp, Keys.chord

Điểm dễ nhầm lẫn

  • Actions.click ≠ WebElement.click
  • HTML5 DnD ≠ drag bằng chuột thường
  • perform() ≠ build()

Lời giải Exercise 1
java
// (đặt trong một @Test — có sẵn driver và wait từ BaseTest)
driver.get("https://the-internet.herokuapp.com/hovers");
WebElement first = driver.findElements(By.className("figure")).get(0);
new Actions(driver).moveToElement(first).perform();
WebElement caption = first.findElement(By.cssSelector(".figcaption h5"));
wait.until(ExpectedConditions.visibilityOf(caption));
Assert.assertEquals(caption.getText(), "name: user1");

driver.get("https://the-internet.herokuapp.com/key_presses");
driver.findElement(By.id("target")).sendKeys("A");
Assert.assertEquals(driver.findElement(By.id("result")).getText(), "You entered: A");
Lời giải Exercise 3
java
// (đặt trong một @Test — có sẵn driver và wait từ BaseTest)
driver.get("https://the-internet.herokuapp.com/drag_and_drop");
WebElement a = driver.findElement(By.id("column-a"));
WebElement b = driver.findElement(By.id("column-b"));
new Actions(driver).dragAndDrop(a, b).perform();
Assert.assertEquals(driver.findElement(By.cssSelector("#column-a header")).getText().trim(), "B");
Assert.assertEquals(driver.findElement(By.cssSelector("#column-b header")).getText().trim(), "A");

Nếu HTML5 drag & drop không hoạt động trên môi trường của bạn: thử clickAndHold → moveToElement → release hoặc mô phỏng sự kiện bằng JavaScript (có chú thích lý do).
