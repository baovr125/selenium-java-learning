1. Interface WebDriver — các nhóm method

Nhóm Method Ghi chú
Điều hướng get(url), navigate(), getCurrentUrl(), getTitle(), getPageSource() 03
Tìm phần tử findElement(By), findElements(By) 02
Quản lý manage() → window(), timeouts(), getCookies()... Mục 3

Cửa sổ getWindowHandle(), getWindowHandles() 06

Các interface mở rộng mà ChromeDriver cũng implement: JavascriptExecutor, TakesScreenshot, HasDevTools, Interactive...

2. Khởi tạo trình duyệt

🧩 Trong dự án (BaseTest.setup()):

java
driver = new ChromeDriver();                                   // 1. mở Chrome
driver.manage().window().maximize();                           // 2. phóng to
driver.manage().timeouts().pageLoadTimeout(Duration.ofSeconds(30)); // 3. giới hạn load trang
wait = new WebDriverWait(driver, Duration.ofSeconds(15));      // 4. explicit wait

Điều gì xảy ra ở new ChromeDriver():

  1. Selenium Manager (nhúng trong selenium-manager-4.52.0.jar) xác định phiên bản Chrome đã cài, tải ChromeDriver tương ứng vào cache (~/.cache/selenium), trả đường dẫn driver.
  2. Khởi động process chromedriver.
  3. Gửi New Session → Chrome được mở với một profile tạm.
  4. Trả về đối tượng ChromeDriver giữ sessionId.

⚠️ Lần chạy đầu tiên có thể chậm hơn vì tải driver; thiếu Internet ⇒ SessionNotCreatedException/NoSuchDriverException.

Các trình duyệt khác

java
WebDriver driver = new FirefoxDriver();   // geckodriver
WebDriver driver = new EdgeDriver();      // msedgedriver

Chọn theo cấu hình ⇒ DriverFactory (framework-design/03).

3. Cấu hình Browser: ChromeOptions

java
import org.openqa.selenium.chrome.ChromeOptions;

ChromeOptions options = new ChromeOptions();
options.addArguments("--start-maximized");          // thay cho window().maximize()
options.addArguments("--headless=new");             // chạy không giao diện (Chrome mới)
options.addArguments("--window-size=1920,1080");    // headless nên đặt kích thước
options.addArguments("--disable-notifications");
options.addArguments("--incognito");
options.setPageLoadStrategy(PageLoadStrategy.EAGER);  // NORMAL (mặc định) | EAGER | NONE
WebDriver driver = new ChromeDriver(options);
Option Tác dụng Dùng khi
--headless=new Không mở cửa sổ CI, server không có màn hình
--window-size=W,H Kích thước cố định Headless; test responsive
--incognito Không dùng cache/cookie cũ Test độc lập
--disable-notifications Tắt popup xin quyền Trang đòi thông báo
PageLoadStrategy Khi nào get() coi là "xong" Trang tải chậm vì quảng cáo

🧩 Dự án chưa dùng ChromeOptions (mặc định hoàn toàn). Đề xuất: thêm option để chạy CI headless.

Page Load Strategy

Giá trị get() trả về khi Ghi chú
NORMAL (mặc định) document.readyState = "complete" Chờ cả ảnh, CSS
EAGER "interactive" (DOM sẵn sàng) Nhanh hơn
NONE Ngay sau khi nhận phản hồi đầu Bạn phải tự Wait

4. Timeouts (3 loại)

driver.manage().timeouts() cấu hình 3 giới hạn thời gian khác nhau hoàn toàn:

Timeout Method Mặc định Ý nghĩa Trong dự án
Page load pageLoadTimeout(Duration) 300 s Tối đa chờ get()/navigate() ✅ 30 s
Implicit wait implicitlyWait(Duration) 0 Thời gian findElement(s) thử lại ❌ cố ý không dùng
Script scriptTimeout(Duration) 30 s Chờ executeAsyncScript ❌ mặc định

Khi page load vượt giới hạn ⇒ TimeoutException từ driver.get().

WebDriverWait (15 s trong dự án) không phải loại timeout nào trong 3 loại trên: nó là cơ chế chờ ở phía test code. Xem 05.

5. Quản lý cửa sổ

java
driver.manage().window().maximize();                  // 🧩 dự án dùng
driver.manage().window().minimize();
driver.manage().window().fullscreen();
driver.manage().window().setSize(new Dimension(1280, 720));
driver.manage().window().setPosition(new Point(0, 0));
Dimension size = driver.manage().window().getSize();

Lưu ý: maximize() trong chế độ headless có thể không có hiệu quả như mong đợi → dùng --window-size.

6. Cookie

java
driver.manage().addCookie(new Cookie("name", "value"));
Cookie c = driver.manage().getCookieNamed("name");
driver.manage().deleteAllCookies();

Ứng dụng: đăng nhập một lần rồi dùng lại cookie phiên cho các test sau (tránh login UI lặp lại).

7. Browser Session

  • Session = một "cuộc hội thoại" giữa test và browser; giữ cookie, localStorage, cửa sổ, timeout.
  • driver.getSessionId() có trên RemoteWebDriver/ChromeDriver (không có trong interface WebDriver).
  • Mỗi new ChromeDriver() là một session và một process Chrome riêng ⇒ 10 test = 10 lần mở Chrome (🧩 @BeforeMethod).
  • Kết thúc session đúng cách: quit(). Nếu test bị kill giữa chừng thì process mồ côi — xem maven/08 #17.

8. Vòng đời đúng của driver trong test

java
@BeforeMethod  public void setup()   { driver = new ChromeDriver(); ... }
@Test          public void test()    { driver.get(...); ... }
@AfterMethod   public void tearDown(){ if (driver != null) driver.quit(); }
  • Kiểm tra null vì nếu setup() fail (ví dụ không tải được driver) thì driver vẫn null và tearDown sẽ ném NullPointerException, che mất lỗi gốc.
  • ⚠️ Không dùng static WebDriver rồi chạy song song: các test giẫm lên nhau. Dùng ThreadLocal.

9. Phiên bản và API cần cẩn thận (Selenium 4.x)

Cũ (đã bỏ/deprecated) Dùng thay thế
new WebDriverWait(driver, 10) (số giây long) new WebDriverWait(driver, Duration.ofSeconds(10)) ✅ (🧩 dự án)
implicitlyWait(10, TimeUnit.SECONDS) implicitlyWait(Duration.ofSeconds(10))
System.setProperty("webdriver.chrome.driver", "...") Không cần: Selenium Manager tự xử lý (vẫn dùng được nếu cần chỉ định cụ thể)
DesiredCapabilities cho Chrome ChromeOptions
findElementsBy... findElements(By...)
WebDriverManager.chromedriver().setup() Không bắt buộc từ Selenium 4.6+

10. Best Practices

  1. Khai báo WebDriver, khởi tạo trong setup, quit() trong teardown.
  2. Mỗi test độc lập; mở browser mới hoặc dọn cookie.
  3. Không Thread.sleep() thay cho Wait.
  4. Cấu hình browser qua Options, đọc từ file/-D.
  5. Đặt kích thước cửa sổ cố định khi chạy CI.

11. Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
SessionNotCreatedException Chrome/driver không khớp, Chrome bị chặn Cập nhật Chrome, kiểm tra mạng
NoSuchDriverException Selenium Manager không tải được driver Mạng/proxy; hoặc tải driver thủ công và dùng System.setProperty
WebDriverException: unknown error: Chrome failed to start: crashed Thiếu --no-sandbox trên Linux container, thiếu RAM Thêm option phù hợp môi trường Docker/CI
NullPointerException ở driver.get() driver chưa khởi tạo (quên @BeforeMethod/ không extends BaseTest) Kiểm tra kế thừa
Cửa sổ nhỏ nên phần tử bị che Không maximize/size maximize()/--window-size

💼 Interview Corner

1. How do you run Chrome in headless mode?

  • 🇻🇳 Dịch: Chạy Chrome headless thế nào?
  • Suggested answer (EN): Pass --headless=new and an explicit --window-size through ChromeOptions to new ChromeDriver(options).
  • Giải thích (VI): Cần cho CI.
  • Follow-up: Why set the window size?

2. What are the different timeouts in Selenium?

  • 🇻🇳 Dịch: Các loại timeout?
  • Suggested answer (EN): Page load, implicit wait and script timeouts in manage().timeouts(); explicit waits are separate and controlled by WebDriverWait.
  • Giải thích (VI): Dự án: pageLoad 30 s + WebDriverWait 15 s, không implicit.
  • Follow-up: What happens when page load times out?

📌 Lesson Summary

Kiến thức cần nhớ

  • WebDriver là interface; ChromeDriver là hiện thực
  • ChromeOptions cấu hình browser
  • 3 timeout + WebDriverWait là việc khác nhau

Method / lệnh cần biết

  • manage().window().maximize(), manage().timeouts().pageLoadTimeout(Duration), ChromeOptions, quit()

Điểm dễ nhầm lẫn

  • pageLoadTimeout ≠ WebDriverWait
  • Số giây long (cũ) ≠ Duration
  • Không dùng var cho driver

Lời giải Exercise 3
java
public final class DriverFactory {
    private DriverFactory() {}

    public static WebDriver create(String browser, boolean headless) {
        return switch (browser.toLowerCase()) {
            case "chrome" -> {
                ChromeOptions o = new ChromeOptions();
                if (headless) o.addArguments("--headless=new", "--window-size=1920,1080");
                yield new ChromeDriver(o);
            }
            case "firefox" -> new FirefoxDriver();
            case "edge" -> new EdgeDriver();
            default -> throw new IllegalArgumentException("Không hỗ trợ: " + browser);
        };
    }
}
