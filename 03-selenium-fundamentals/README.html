Bản đồ nhanh: muốn làm X, dùng API nào?

Mục tiêu API
Mở trang driver.get(url)
Tìm 1 / nhiều phần tử findElement(by) / findElements(by)
Nhập chữ / bấm sendKeys / click
Chờ phần tử hiện / bấm được / biến mất visibilityOfElementLocated / elementToBeClickable / invisibilityOfElementLocated (Wait)
Dropdown new Select(el).selectByVisibleText(..)
Alert / iframe / tab mới switchTo().alert() / switchTo().frame(..) / switchTo().window(..)
Hover / kéo thả new Actions(driver).moveToElement(..) / dragAndDrop(a, b)
Cuộn trang ((JavascriptExecutor) driver).executeScript("window.scrollTo(0, document.body.scrollHeight)")
Chụp màn hình ((TakesScreenshot) driver).getScreenshotAs(OutputType.FILE)
