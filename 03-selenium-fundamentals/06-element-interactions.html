1. Điều kiện để Selenium tương tác được

Trước khi click()/sendKeys(), Selenium kiểm tra phần tử có thể tương tác không (actionability):

Điều kiện Nếu không thoả
Có trong DOM NoSuchElementException
Hiển thị (visible) ElementNotInteractableException
Bật (enabled) ElementNotInteractableException (với sendKeys/clear trên phần tử disabled) hoặc click không tác dụng
Không bị phần tử khác che ElementClickInterceptedException
Kích thước > 0, trong viewport (Selenium tự cuộn vào view) MoveTargetOutOfBoundsException...

⇒ Phần lớn lỗi "không bấm được" là vấn đề đồng bộ hoá: phần tử chưa sẵn sàng. Giải pháp: Wait (05).

2. click()

java
driver.findElement(By.xpath("//button[@type='submit']")).click();   // 🧩 Ex 1
  • Cuộn phần tử vào vùng nhìn (nếu cần), click vào tâm phần tử.
  • Nếu một phần tử khác nằm đè (modal, banner, cookie bar) ⇒ ElementClickInterceptedException (thông báo nói rõ phần tử nào che).
  • Chờ tốt nhất: wait.until(ExpectedConditions.elementToBeClickable(by)).click();

🧩 Exercise02: click checkbox và kiểm tra isSelected() đổi trạng thái (không click mù).

Phương án dự phòng (cẩn thận, vì bỏ qua kiểm tra người dùng thật): ((JavascriptExecutor) driver).executeScript("arguments[0].click();", el) — chỉ dùng khi hiểu rõ (xem 08).

3. sendKeys()

java
WebElement user = driver.findElement(By.id("username"));
user.sendKeys("tomsmith");                         // gõ chữ
user.sendKeys(Keys.TAB);                           // phím đặc biệt
user.sendKeys(Keys.chord(Keys.CONTROL, "a"));      // tổ hợp phím (Ctrl+A)
fileInput.sendKeys("C:\\data\\avatar.png");        // upload: input type=file, đường dẫn tuyệt đối
  • Gõ nối vào nội dung hiện có (không xoá cũ) ⇒ nên clear() trước. 🧩 Ex 1 làm đúng: usernameTextbox.clear(); usernameTextbox.sendKeys(...).
  • Keys.ENTER có thể thay cho click nút submit trong một số form.
  • Upload file: không mở hộp thoại hệ điều hành; gửi trực tiếp đường dẫn vào <input type="file">.

4. clear()

java
usernameTextbox.clear();
  • Chỉ dùng cho phần tử input/textarea có thể nhập, đang enabled.
  • Một số ô (React controlled input, ô có mask) không phản ứng với clear(). Cách thay thế: sendKeys(Keys.chord(Keys.CONTROL, "a"), Keys.BACK_SPACE).

5. getText()

java
String actual = successMessageElement.getText();    // 🧩 Ex 1, 8, 10
  • Trả văn bản hiển thị cho người dùng: đã chuẩn hoá khoảng trắng, phần tử ẩn trả "", theo text-transform của CSS (ví dụ nếu CSS chuyển hoa, nhận chữ HOA).
  • 🧩 Exercise08 dùng .toUpperCase() khi so tiêu đề vì lý do này.
  • 🧩 Exercise05: caption ẩn cho tới khi hover ⇒ nếu getText() quá sớm sẽ rỗng; dự án chờ visibilityOf(captionHeader) trước.
  • Lấy text bất kể ẩn hay không: getAttribute("textContent") (hoặc getDomProperty("textContent")).
  • Nên trim() khi so sánh để tránh khoảng trắng thừa (🧩 dự án làm).

6. getAttribute(), getDomAttribute(), getDomProperty()

HTML <input value="abc"> — attribute value là giá trị khởi tạo; property value là giá trị hiện tại (sau khi người dùng gõ).

Method Trả về
getAttribute("value") Ưu tiên property hiện tại, nếu không có thì attribute (hành vi "gộp", tiện nhưng dễ nhầm)
getDomProperty("value") Property của DOM (giá trị hiện tại)
getDomAttribute("value") Chỉ attribute viết trong HTML
java
input.sendKeys("Selenium Dynamic Controls OK");
input.getAttribute("value");     // 🧩 Ex 10 — giá trị đã gõ
input.getDomAttribute("value");  // null/"" nếu HTML gốc không có value
input.getDomProperty("value");   // giá trị đã gõ

✅ getAttribute vẫn dùng được trong Selenium 4.52 (🧩 dự án dùng); getDomAttribute/getDomProperty rõ nghĩa hơn khi cần phân biệt.

Các thuộc tính hay đọc: value, href, src, class, disabled, checked, placeholder, title.

7. isDisplayed(), isEnabled(), isSelected()

Method Dùng cho Lưu ý
isDisplayed() Mọi phần tử false nếu display:none, visibility:hidden, kích thước 0, hoặc <input type=hidden>
isEnabled() Control (input, button, option...) false nếu có thuộc tính disabled
isSelected() checkbox, radio, option Trả trạng thái chọn hiện tại

🧩 Ex 10: Assert.assertFalse(textInput.isEnabled()) trước khi bấm Enable, assertTrue sau khi bấm. 🧩 Ex 4: option.isEnabled() để loại placeholder bị disabled.

⚠️ Chúng chỉ trả trạng thái tức thời. Đừng viết assertTrue(el.isDisplayed()) ngay sau hành động bất đồng bộ; hãy wait.until(visibility...) rồi mới assert.

8. submit(), getTagName(), getCssValue()

java
form.submit();                              // ít dùng; ưu tiên click nút
el.getTagName();                            // "input"
el.getCssValue("background-color");         // "rgba(...)" — dùng kiểm tra giao diện
el.getRect();                               // x, y, width, height

9. Tương tác với bảng (Web Table)

🧩 Exercise03 là mẫu tốt:

java
WebElement row = driver.findElement(By.xpath("//table[@id='table1']/tbody/tr[last()-1]"));
List<WebElement> cells = row.findElements(By.tagName("td"));     // tìm CON của row
for (int i = 0; i < cells.size() - 1; i++) {                      // bỏ cột Action cuối
    data.add(cells.get(i).getText().trim());
}

Mẹo: lấy cả bảng thành List<List<String>> (dùng stream) để dễ assert và sắp xếp.

10. Làm việc với danh sách

java
List<WebElement> checkboxes = driver.findElements(By.cssSelector("#checkboxes input[type='checkbox']"));
for (WebElement cb : checkboxes) { if (!cb.isSelected()) cb.click(); }   // idempotent: chỉ click khi cần

Với Java Stream:

java
List<String> names = driver.findElements(By.cssSelector(".figcaption h5"))
        .stream().map(WebElement::getText).toList();

⚠️ Danh sách WebElement có thể stale nếu DOM thay đổi trong lúc duyệt ⇒ lấy dữ liệu (chuỗi) trước, như 🧩 Ex 4.

11. Mẫu hành động "an toàn"

java
public void safeType(By by, String text) {
    WebElement el = wait.until(ExpectedConditions.visibilityOfElementLocated(by));
    el.clear();
    el.sendKeys(text);
}

public void safeClick(By by) {
    wait.until(ExpectedConditions.elementToBeClickable(by)).click();
}

Đây chính là các Reusable Method của BasePage — framework-design/03.

✅ Best Practices

  1. Chờ phần tử sẵn sàng trước khi tương tác; không Thread.sleep().
  2. clear() trước sendKeys() khi ghi đè.
  3. Assert trạng thái trước và sau hành động (như Ex 2).
  4. trim() khi so sánh text.
  5. Dùng getAttribute("value") cho input, không getText().

⚠️ Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
ElementNotInteractableException Ẩn/disabled/ngoài viewport Chờ elementToBeClickable; cuộn vào view
ElementClickInterceptedException Bị che bởi modal/overlay Đóng overlay/ chờ invisibilityOfElementLocated
getText() rỗng với input Dùng sai method getAttribute("value")
Click checkbox đã tick ⇒ bỏ tick Không kiểm tra trạng thái Kiểm tra isSelected()
StaleElementReferenceException DOM đổi Tìm lại
Gõ bị nối vào chữ cũ Quên clear() clear() trước

Dropdown (<select>) và Multi-select

Dropdown 1. Lớp Select

java
import org.openqa.selenium.support.ui.Select;

Select dropdown = new Select(driver.findElement(By.id("dropdown")));   // 🧩 Ex4

Select chỉ bọc thẻ <select> thật. Truyền phần tử khác ⇒ UnexpectedTagNameException.

Method Ý nghĩa
selectByVisibleText("Option 1") Chọn theo chữ hiển thị (🧩 Ex4) — dễ đọc nhất
selectByValue("1") Chọn theo thuộc tính value — ổn định khi chữ đổi ngôn ngữ
selectByIndex(1) Chọn theo vị trí (0-based) — mong manh nếu danh sách đổi
getOptions() List<WebElement> mọi option
getFirstSelectedOption() Option đang chọn (🧩 Ex4)
getAllSelectedOptions() Dành cho multi-select
isMultiple() Có phải <select multiple>
deselectAll(), deselectByValue/Index/VisibleText Chỉ với multi-select

Dropdown 2. Phân tích Ex4

java
String defaultSelected = dropdown.getFirstSelectedOption().getText().trim();   // placeholder
for (WebElement option : dropdown.getOptions()) {
    if (option.isEnabled()) {                          // bỏ "Please select an option" (disabled)
        optionTexts.add(option.getText().trim());
        optionValues.add(option.getAttribute("value"));
    }
}
dropdown.selectByVisibleText(expectedText);            // chọn
dropdown.getFirstSelectedOption().getText();            // kiểm chứng

Điểm hay: thu thập text/value dạng chuỗi trước, rồi mới thao tác ⇒ không bị stale.

Dropdown 3. Dropdown "tự chế" (không phải <select>)

Nhiều site dùng <div>/<ul> làm dropdown (Bootstrap, React-Select). Select không dùng được. Cách làm: click mở → chờ danh sách hiện → click mục.

java
driver.findElement(By.cssSelector(".dropdown-toggle")).click();
wait.until(ExpectedConditions.visibilityOfElementLocated(By.cssSelector(".dropdown-menu")));
driver.findElement(By.xpath("//ul[@class='dropdown-menu']//a[text()='Option 2']")).click();

Dropdown 4. Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý
UnexpectedTagNameException Không phải <select> Xử lý như dropdown tự chế
NoSuchElementException: Cannot locate option with text Sai chữ/dư khoảng trắng/ngôn ngữ getOptions() in text ra kiểm tra; dùng selectByValue
Chọn option disabled Kiểm tra isEnabled()

💼 Interview Corner

1. How do you handle a dropdown in Selenium?

  • 🇻🇳 Dịch: Xử lý dropdown?
  • Suggested answer (EN): For a native <select> I use the Select class with selectByVisibleText, selectByValue or selectByIndex; for custom dropdowns I click to open, wait for the list and click the item.
  • Giải thích (VI): Ưu tiên text/value hơn index.
  • Follow-up: What if it is not a select tag?

2. How do you make a checkbox step idempotent?

  • 🇻🇳 Dịch: Làm bước tick checkbox idempotent thế nào?
  • Suggested answer (EN): Check isSelected() first and click only if the state differs from the desired one.
  • Giải thích (VI): Dự án Exercise02 còn kiểm chứng trạng thái đổi sau click.
  • Follow-up: Why verify the state change?

📌 Lesson Summary

Kiến thức cần nhớ

  • Nhập: clear() + sendKeys
  • Checkbox: kiểm tra isSelected() trước khi click
  • Select chỉ cho <select>
  • Bảng: row.findElements(By.tagName("td"))

Method / lệnh cần biết

  • Select.selectByVisibleText/Value/Index, getOptions, getFirstSelectedOption, isMultiple

Điểm dễ nhầm lẫn

  • <select> ≠ dropdown tự chế
  • Click mù ≠ đặt trạng thái mong muốn
  • getOptions gồm cả option bị disabled
