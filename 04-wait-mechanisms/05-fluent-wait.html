1. Fluent Wait

FluentWait cho phép cấu hình đầy đủ:

java
import org.openqa.selenium.support.ui.FluentWait;
import org.openqa.selenium.support.ui.Wait;

Wait<WebDriver> fluent = new FluentWait<>(driver)
        .withTimeout(Duration.ofSeconds(30))
        .pollingEvery(Duration.ofMillis(500))
        .ignoring(NoSuchElementException.class)
        .ignoring(StaleElementReferenceException.class)
        .withMessage("Không thấy nút Download");

WebElement btn = fluent.until(d -> d.findElement(By.id("download")));

Dùng khi:

  • Cần bỏ qua thêm exception (ví dụ StaleElementReferenceException).
  • Cần polling riêng cho từng điều kiện.
  • Điều kiện chờ viết bằng lambda tuỳ biến.
  • Cần thông báo lỗi rõ.

WebDriverWait là FluentWait<WebDriver> đã đặt sẵn mặc định ⇒ trong thực tế WebDriverWait + .ignoring(...) + .pollingEvery(...) đã làm được mọi thứ FluentWait làm.

🧩 Dự án chưa dùng FluentWait trực tiếp; Ex 7 dùng wait.until(lambda) — là custom wait đúng tinh thần Fluent.

2. Custom Wait

Khi ExpectedConditions không có điều kiện bạn cần, viết bằng lambda hoặc ExpectedCondition:

java
// 1. Lambda (🧩 Ex7 dùng cách này)
wait.until(d -> d.findElements(By.className("jscroll-added")).size() > before);

// 2. ExpectedCondition tường minh, có toString cho thông báo lỗi dễ đọc
ExpectedCondition<Boolean> moreItems = new ExpectedCondition<>() {
    @Override public Boolean apply(WebDriver d) {
        return d.findElements(By.className("jscroll-added")).size() > before;
    }
    @Override public String toString() { return "nhiều hơn " + before + " đoạn văn"; }
};
wait.until(moreItems);

// 3. Điều kiện trên giá trị Java thuần (ví dụ file tải xong)
Path file = Path.of("downloads", "report.pdf");
new FluentWait<>(file).withTimeout(Duration.ofSeconds(30)).pollingEvery(Duration.ofSeconds(1))
        .until(Files::exists);

Quy tắc viết:

  1. Trả true/đối tượng khi đạt; false/null khi chưa đạt.
  2. Không để lọt exception không mong muốn (hoặc ignoring(...)).
  3. Gọn, không side effect nếu có thể.

🧩 Ex7 là trường hợp đặc biệt có side effect có chủ đích: việc cuộn đặt bên trong until, vì plugin jScroll bỏ qua sự kiện scroll khi đang tải dở; cuộn một lần có thể "mất" sự kiện ⇒ nội dung không bao giờ tăng ⇒ TimeoutException (trước đây test này đã từng fail — test-output/testng-failed.xml). Cuộn lặp lại trong vòng chờ cho tới khi số đoạn văn tăng — tuân theo triết lý "retry cho đến khi điều kiện đúng".

java
wait.until(d -> {
    scrollToBottom(jsExecutor);                                   // hành động lặp lại
    return d.findElements(PARAGRAPH_LOCATOR).size() > countBeforeScroll;   // điều kiện
});

✅ Knowledge Check

Câu 1. WebDriverWait so với FluentWait?

  • A. Không liên quan
  • B. WebDriverWait extends FluentWait<WebDriver> với mặc định sẵn
  • C. FluentWait chỉ cho alert
  • D. Giống hệt Thread.sleep
Xem đáp án

Đáp án: B. Có thể thêm ignoring/pollingEvery cho WebDriverWait.

Câu 2. Điều kiện chờ trả false/null nghĩa là?

  • A. Dừng với lỗi
  • B. Chưa đạt, thử lại
  • C. Đạt
  • D. Bỏ qua
Xem đáp án

Đáp án: B. Truthy mới thoả.

Câu 3. Biến dùng trong lambda của điều kiện phải?

  • A. static
  • B. final/effectively final
  • C. public
  • D. Không giới hạn
Xem đáp án

Đáp án: B. Quy tắc lambda của Java.

💼 Interview Corner

1. How do you write a custom wait?

  • 🇻🇳 Dịch: Viết Custom Wait thế nào?
  • Suggested answer (EN): Pass a lambda or an ExpectedCondition to wait.until(...) that returns true or a non-null object when satisfied and false or null otherwise.
  • Giải thích (VI): Ex7 là ví dụ thực.
  • Follow-up: Why must captured variables be final?

2. When would you choose FluentWait?

  • 🇻🇳 Dịch: Khi nào chọn FluentWait?
  • Suggested answer (EN): When I need custom polling, extra ignored exceptions, a custom message, or a condition that is not about a WebDriver such as a file download.
  • Giải thích (VI): WebDriverWait đã cover phần lớn.
  • Follow-up: Can FluentWait wait on a Path?

📌 Lesson Summary

Kiến thức cần nhớ

  • FluentWait = timeout + polling + ignoring + message
  • Custom wait = lambda/ExpectedCondition
  • Có thể chờ điều kiện không phải DOM

Method / lệnh cần biết

  • withTimeout, pollingEvery, ignoring, withMessage, until

Điểm dễ nhầm lẫn

  • FluentWait ≠ chờ cố định
  • Side effect trong điều kiện cần ghi chú
  • WebDriverWait + ignoring đã đủ cho nhiều trường hợp
