So sánh các cơ chế chờ (và Thread.sleep)

🎯 Learning Objectives

Sau bài này bạn có thể:

  • So sánh Thread.sleep, Implicit, Explicit, Fluent
  • Chọn Wait theo tình huống bằng sơ đồ quyết định
  • Đo chênh lệch thời gian giữa sleep và Explicit Wait

📋 Prerequisites

  • Fluent Wait
  • Implicit Wait

1. Thread.sleep()

java
Thread.sleep(5000);   // ngủ cứng 5 giây
Thread.sleep Explicit Wait
Thời gian Luôn đủ 5 s Dừng ngay khi điều kiện đúng (tối đa timeout)
Phần tử sẵn sàng sau 1 s Phí 4 s Chỉ 1 s
Phần tử mất 6 s Fail (sleep ngắn) Pass (nếu timeout ≥ 6 s)
Kiểm tra điều kiện Không Có
Exception Checked InterruptedException Unchecked

Tác hại: làm bộ test chậm (100 test × 5 s = 8 phút lãng phí), vẫn flaky (mạng chậm hơn 5 s thì fail), che dấu vấn đề.

Chỉ chấp nhận trong trường hợp hiếm: debug tạm thời (xem trình duyệt), demo, hoặc chờ tín hiệu không thể quan sát được từ DOM — và nên có chú thích lý do. 🧩 Dự án không có Thread.sleep nào.

2. Chiến lược chọn Wait

text
Bạn đang chờ cái gì?
 ├─ Một phần tử xuất hiện để ĐỌC ............... visibilityOfElementLocated
 ├─ Một phần tử để TƯƠNG TÁC (click) ........... elementToBeClickable (+ chờ overlay biến mất)
 ├─ Phần tử biến mất / spinner tắt ............. invisibilityOfElementLocated / numberOfElementsToBe(by, 0)
 ├─ Text/giá trị đổi ........................... textToBe / textToBePresentInElement / attributeToBe
 ├─ Điều hướng xong ............................ urlContains / titleIs
 ├─ DOM được vẽ lại ............................ stalenessOf rồi tìm lại
 ├─ Alert / Frame / Window ..................... alertIsPresent / frameToBeAvailable... / numberOfWindowsToBe
 └─ Điều kiện đặc thù .......................... Custom Wait (lambda) / FluentWait

Thứ tự ưu tiên: Explicit Wait theo điều kiện > Fluent Wait > (không dùng Implicit) > (Thread.sleep chỉ để debug).

💼 Interview Corner

1. Compare Thread.sleep, implicit and explicit waits.

  • 🇻🇳 Dịch: So sánh sleep, implicit, explicit.
  • Suggested answer (EN): Thread.sleep waits a fixed time, implicit is a global presence-only retry for finds, and explicit waits for a specific condition and returns as soon as it is true; I use explicit waits.
  • Giải thích (VI): Có bảng so sánh.
  • Follow-up: Why is sleep flaky?

2. How would you choose a wait for a spinner followed by a click?

  • 🇻🇳 Dịch: Chọn wait cho spinner rồi click?
  • Suggested answer (EN): Wait for the spinner to be invisible, then wait for the button to be clickable and click.
  • Giải thích (VI): clickable không biết overlay.
  • Follow-up: What if the spinner never shows?

📌 Lesson Summary

Kiến thức cần nhớ

  • Explicit là mặc định; Fluent khi cần tinh chỉnh
  • Implicit tránh; sleep chỉ debug
  • Chọn Wait theo điều kiện cần chờ

Method / lệnh cần biết

  • Bảng so sánh, sơ đồ quyết định

Điểm dễ nhầm lẫn

  • Dừng sớm vs chờ cố định
  • Presence-only (implicit) vs điều kiện bất kỳ (explicit)
  • sleep che nguyên nhân
