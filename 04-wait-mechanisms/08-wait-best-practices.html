1. Best Practices và lỗi thường gặp

✅ Best Practices

  1. Chỉ dùng Explicit Wait; implicit = 0.
  2. Chờ điều kiện thực (visible, clickable, text), không chờ "thời gian".
  3. Một WebDriverWait dùng chung trong BaseTest; tạo Wait riêng khi cần thời gian khác.
  4. Ưu tiên bản dùng By (tìm lại mỗi vòng) để tránh stale.
  5. Sau hành động bất đồng bộ: chờ → rồi mới assert.
  6. Viết withMessage(...) để lỗi dễ đọc.
  7. Gom hàm chờ vào BasePage (framework-design/03).
  8. Không catch (TimeoutException) để "nuốt"; nếu bắt, phải có hành động rõ ràng.

⚠️ Lỗi thường gặp

Lỗi Nguyên nhân Cách xử lý

Pass nhưng đọc dữ liệu cũ Chờ điều kiện đã đúng từ trước (như T6) Chờ điều kiện đặc trưng cho trạng thái mới (textToBe, stalenessOf)

💼 Interview Corner

1. What are your best practices for waits?

  • 🇻🇳 Dịch: Best practices về Wait?
  • Suggested answer (EN): Use explicit waits on specific conditions with implicit wait left at zero, no Thread.sleep, one shared WebDriverWait with helper methods in the base page, wait for conditions specific to the new state, and use clear timeout messages.
  • Giải thích (VI): Tóm tắt đầy đủ.
  • Follow-up: How do you handle slow operations?

2. A test passes sometimes and fails sometimes. How do you investigate?

  • 🇻🇳 Dịch: Test lúc pass lúc fail?
  • Suggested answer (EN): Rerun in isolation, read the exception, check the locator in DevTools, replace sleeps with a specific condition, check dependencies and environment, fix the root cause and rerun repeatedly instead of hiding it with retries.
  • Giải thích (VI): Quy trình có hệ thống.
  • Follow-up: When is retry acceptable?

📌 Lesson Summary

Kiến thức cần nhớ

  • Explicit mặc định; implicit = 0; không sleep
  • Wait trong BasePage; điều kiện đặc trưng trạng thái mới
  • Không nuốt TimeoutException

Method / lệnh cần biết

  • BasePage.waitVisible/click/type/text, withMessage

Điểm dễ nhầm lẫn

  • Tăng timeout ≠ sửa lỗi
  • Retry ≠ sửa
  • clickable ≠ không bị che

Lời giải Exercise 2
java
public abstract class BasePage {
    protected final WebDriver driver;
    protected final WebDriverWait wait;

    protected BasePage(WebDriver driver) {
        this.driver = driver;
        this.wait = new WebDriverWait(driver, Duration.ofSeconds(15));
    }
    protected WebElement waitVisible(By by) { return wait.until(ExpectedConditions.visibilityOfElementLocated(by)); }
    protected WebElement waitClickable(By by) { return wait.until(ExpectedConditions.elementToBeClickable(by)); }
    protected void click(By by) { waitClickable(by).click(); }
    protected void type(By by, String text) { WebElement el = waitVisible(by); el.clear(); el.sendKeys(text); }
    protected String text(By by) { return waitVisible(by).getText().trim(); }
}
