Learning Checklist — "Tôi có thể..."

Quay lại progress/ · Rút từ mục 🎯 Learning Objectives của từng bài. Chỉ tick khi tự làm được không nhìn tài liệu.

Phase 1: Java Fundamentals

Cài đặt môi trường — ⬜ Not Started

  • Cài và kiểm tra JDK (≥ 21) cùng Chrome
  • Phân biệt JAVA_HOME, PATH, JDK và JRE
  • Chạy mvnw.cmd -version và test kiểm tra môi trường mà không cần cài Maven

Java: Getting Started (Introduction, Syntax, Output, Comments) — ⬜ Not Started

  • Giải thích Java, JDK, JRE, JVM bằng lời của mình
  • Viết và chạy chương trình Hello với main
  • Dùng println, print, printf và comments đúng cách
  • Biết cách chạy một chương trình Java (java File.java, javac, Maven)

Java: Variables, Data Types và Type Casting — 🟡 In Progress

  • Khai báo biến, hằng (final) với đúng kiểu dữ liệu
  • Phân biệt primitive và non-primitive
  • Ép kiểu (casting) và chuyển đổi String ↔ số an toàn
  • Nhận ra vì sao dự án dùng long, Number, boolean, String, List

Java: Operators, Strings, Math và Booleans — 🟡 In Progress

  • Dùng toán tử số học, so sánh, logic đúng thứ tự ưu tiên
  • Thao tác String với các method thường dùng trong assertion
  • So sánh chuỗi bằng equals thay vì ==
  • Dùng StringBuilder, Math và boolean trong điều kiện

Java: Control Flow (If...Else, Switch, Loops, Break/Continue) — 🟡 In Progress

  • Rẽ nhánh với if/else, switch
  • Lặp với for, for-each, while, do-while
  • Dùng break, continue và viết vòng retry có giới hạn
  • Ánh xạ vòng lặp sang việc duyệt danh sách WebElement

Java: Arrays (mảng) — ⬜ Not Started

  • Khai báo, truy cập và duyệt mảng
  • Dùng Arrays.toString, Arrays.sort, split trả mảng
  • Hiểu mảng hai chiều Object[][] của @DataProvider
  • Biết khi nào dùng List thay mảng

Java: Methods (tham số, giá trị trả về, overloading, scope, recursion) — 🟡 In Progress

  • Viết method có tham số và giá trị trả về
  • Dùng overloading và varargs
  • Hiểu scope của biến
  • Nhận ra method là nền tảng của Reusable Method / Page Method

Java: Classes và Objects (attributes, methods, constructors, this, modifiers, static) — 🟡 In Progress

  • Tạo class, object, attribute, method, constructor
  • Dùng this, private, public, protected
  • Phân biệt static và non-static
  • Mô phỏng một Page Object bằng class thường

Java: OOP Concepts (Encapsulation, Inheritance, Polymorphism, Abstraction, Interface, Packages) — 🟡 In Progress

  • Áp dụng Encapsulation, Inheritance, Polymorphism, Abstraction
  • Phân biệt interface và abstract class
  • Dùng package/import đúng
  • Giải thích vì sao khai báo WebDriver driver = new ChromeDriver()

Java: Collections (List, Set, Map, Iterator, Wrapper Classes) — 🟡 In Progress

  • Dùng ArrayList, HashSet, HashMap đúng mục đích
  • Hiểu wrapper class và autoboxing
  • Duyệt và xoá phần tử an toàn
  • Giải thích vì sao findElements trả List<WebElement>

Java: Exception Handling (try/catch/finally, throw/throws, try-with-resources) — 🟡 In Progress

  • Dùng try/catch/finally, throw, throws
  • Phân biệt checked và unchecked exception
  • Dùng try-with-resources
  • Nhận biết khi nào được/không được catch trong test

Java: Generics, Lambda, Annotations, RegEx và Threads (mức cần cho Selenium) — 🟡 In Progress

  • Đọc hiểu và viết lambda, method reference
  • Hiểu generics trong List<WebElement>, Wait<WebDriver>
  • Biết annotation là gì và TestNG đọc chúng thế nào
  • Hiểu ThreadLocal để chạy song song

Java: File Handling, Properties và Configuration — ⬜ Not Started

  • Đọc/ghi file văn bản với Path và Files
  • Đọc cấu hình bằng Properties với giá trị mặc định
  • Đọc CSV đơn giản làm dữ liệu test
  • Hiểu thứ tự ưu tiên -D > file > mặc định

Phase 2: Maven and Project Management

Khởi tạo dự án Selenium Java + Maven + TestNG — 🟡 In Progress

  • Dựng cấu trúc thư mục Maven chuẩn cho dự án Selenium
  • Viết pom.xml tối thiểu và BaseTest đầu tiên
  • Chạy test đầu tiên bằng mvnw

Maven Fundamentals — ⬜ Not Started

  • Giải thích Maven là gì và vì sao cần
  • Phân biệt Local, Central, Remote Repository
  • Mô tả quy trình Maven tải dependency
  • Chỉ ra Local Repository riêng của dự án (.mvn/repository)

pom.xml và Dependencies — ⬜ Not Started

  • Đọc từng khối của pom.xml thật của dự án
  • Giải thích properties, dependencies, scope, plugins
  • Biết dependencyManagement, profiles, repositories dùng khi nào

Maven Wrapper (mvnw, mvnw.cmd) — 🟡 In Progress

  • Giải thích Maven Wrapper là gì, vì sao cần
  • Phân biệt mvnw, mvnw.cmd, maven-wrapper.properties
  • Giải thích Wrapper xác định và tải Maven ở đâu
  • Chạy Wrapper trên Windows và Linux/macOS

Maven Wrapper: làm việc nhóm, Git và lỗi thường gặp — ⬜ Not Started

  • Mô tả quy trình làm việc nhóm với Wrapper từ clone đến push
  • Biết file nào commit, file nào không
  • Xử lý các lỗi Wrapper thường gặp
  • Biết cách nâng phiên bản Maven cho cả nhóm

Commands và Build Lifecycle — ⬜ Not Started

  • Liệt kê các phase của default lifecycle theo thứ tự
  • Phân biệt clean, compile, test, package, verify, install
  • Giải thích Maven thực thi phase theo thứ tự
  • Biết -DskipTests, -o, -q, -B

Dependency Management — ⬜ Not Started

  • Đọc dependency:tree thật của dự án
  • Phân biệt direct và transitive dependency
  • Giải quyết xung đột phiên bản
  • Thêm dependency theo quy trình an toàn

Build và chạy Automation Test bằng Maven — 🟡 In Progress

  • Chạy toàn bộ suite, một class, một method bằng Maven
  • Hiểu Surefire/Failsafe và -Dtest bỏ qua testng.xml
  • Đọc kết quả trong target/surefire-reports
  • Phân biệt 5 trạng thái: pass, skipped, fail, error, không có test

Quy trình làm việc với Maven trong team — ⬜ Not Started

  • Thực hiện quy trình 9 bước từ clone đến khi đồng đội pull
  • Đọc nhanh một dự án Maven lạ
  • Thêm/cập nhật dependency an toàn
  • Dùng checklist trước khi push

Troubleshooting — ⬜ Not Started

  • Áp dụng phương pháp 5 bước để đọc lỗi Maven
  • Nhận diện nhóm lỗi theo plugin/goal
  • Tra bảng nguyên nhân – kiểm tra – khắc phục
  • Biết khi nào và xoá gì trong cache

Phase 3: Selenium Fundamentals

Selenium là gì? — 🟡 In Progress

  • Giải thích Selenium, WebDriver, Browser Driver, Browser
  • Mô tả kiến trúc Test → HTTP/JSON (W3C) → Driver → Browser

WebDriver Fundamentals — 🟡 In Progress

  • Khởi tạo ChromeDriver và cấu hình ChromeOptions
  • Phân biệt ba loại timeout của manage().timeouts() và WebDriverWait
  • Hiểu vòng đời driver trong BaseTest
  • Biết API cũ đã bị loại bỏ

Selenium: Locators (cách tìm phần tử) — 🟡 In Progress

  • Viết 8 loại locator
  • Viết CSS Selector và XPath (tương đối, trục, vị trí)
  • Chọn locator ổn định, dễ bảo trì

Selenium: WebElement API — 🟡 In Progress

  • Dùng findElement/findElements đúng
  • Dùng click, sendKeys, clear, getText, getAttribute

Browser Navigation — 🟡 In Progress

  • Dùng getTitle, getCurrentUrl, getPageSource
  • Phân biệt close() và quit()
  • Đợi điều hướng bằng điều kiện thay vì đọc ngay

Web Element Interactions — 🟡 In Progress

  • Nhập liệu, click, tick checkbox/radio, xử lý form
  • Dùng Select cho dropdown và multi-select
  • Xử lý phần tử động bằng Explicit Wait

Browser Interactions: Alert, Frame/iFrame, Window/Tab — ⬜ Not Started

  • Chuyển giữa cửa sổ/tab

Keyboard và Mouse Actions — 🟡 In Progress

  • Dùng Actions cho hover, kéo thả, phím tổ hợp
  • Nhớ perform()
  • Chờ thay đổi UI sau hover/kéo thả

JavaScript Executor — 🟡 In Progress

  • Dùng JavascriptExecutor.executeScript
  • Cuộn trang và đọc scrollY đúng kiểu Number

Exception Handling — ⬜ Not Started

Phase 4: Wait and Synchronization

Wait Introduction: vì sao Selenium cần Wait? — ⬜ Not Started

  • Giải thích vì sao Selenium cần Wait (vấn đề đồng bộ hoá)
  • Kể tên 3 cơ chế chờ và phạm vi của chúng
  • Tái hiện lỗi do thiếu Wait và nhận ra triệu chứng flaky

Implicit Wait — 🟡 In Progress

  • Cài và hiểu phạm vi của Implicit Wait
  • Giải thích vì sao dự án cấm Implicit Wait
  • Đo được tác hại của findElements rỗng khi có implicit wait
  • Giải thích vì sao không trộn Implicit và Explicit

Explicit Wait và WebDriverWait — 🟡 In Progress

  • Dùng WebDriverWait.until(ExpectedConditions...)
  • Cấu hình timeout, polling interval, ignored exceptions, message
  • Đọc TimeoutException để debug
  • Giải thích Wait đang dùng trong Selenium1

ExpectedConditions (và Presence vs Visibility vs Clickability) — 🟡 In Progress

  • Chọn đúng ExpectedConditions cho từng tình huống
  • Phân biệt Presence, Visibility, Clickability
  • Biết bẫy của invisibilityOfElementLocated và textToBe
  • Dùng stalenessOf, numberOfWindowsToBe, frameToBeAvailableAndSwitchToIt, alertIsPresent

Fluent Wait và Custom Wait — 🟡 In Progress

  • Cấu hình FluentWait đầy đủ
  • Viết custom wait bằng lambda hoặc ExpectedCondition
  • Dùng FluentWait cho điều kiện không thuộc DOM (file tải xong)
  • Hiểu vì sao Exercise 7 đặt cuộn trong điều kiện chờ

So sánh các cơ chế chờ (và Thread.sleep) — ⬜ Not Started

  • So sánh Thread.sleep, Implicit, Explicit, Fluent
  • Chọn Wait theo tình huống bằng sơ đồ quyết định
  • Đo chênh lệch thời gian giữa sleep và Explicit Wait

Wait: 15 tình huống thực tế — ⬜ Not Started

  • Áp dụng Wait cho 15 tình huống thực tế
  • Nhận ra mẫu "thông báo cũ" và "spinner che nút"
  • Viết wait cho alert, tab mới, iframe, stale

Wait Best Practices — ⬜ Not Started

  • Áp dụng 8 best practices cho Wait
  • Review một đoạn code test về đồng bộ hoá
  • Tự trả lời 20 câu hỏi Wait
  • Gom hàm chờ vào BasePage
